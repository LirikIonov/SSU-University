## 0\. Arkane в одном абзаце { #0-arkane }




Arkane появилась в Лионе в 1999 году, потому что Рафаэль Колантонио хотел делать игры в духе **Ultima Underworld**, а крупные компании такую возможность ему не давали. Первая Arx Fatalis уже сформулировала почти всю философию студии: правдоподобное место, физические предметы, системные правила, несколько способов решать задачи и минимум искусственного разделения между «уровнем» и «миром». Dark Messiah добавила к этому физический first-person action и идею «сама комната — оружие». Отменённые Ravenholm, The Crossing и LMNO научили Arkane production-art, альтернативной истории, системному multiplayer и работе с поведением NPC, но едва не разорили компанию. В 2010 ZeniMax купила студию и дала ей возможность несколько лет делать одну большую собственную игру — Dishonored. После успеха Dishonored Arkane раскололась на две полноценные производственные ветви: **Lyon** пошла по линии Dishonored → Deathloop, а **Austin** по линии Arx/System Shock → Prey → Mooncrash. Austin затем попыталась сделать более массовый open-world co-op Redfall, потеряла значительную часть ветеранов Prey, выпустила провальную игру и была закрыта Microsoft в 2024 году. Исходная Arkane Lyon продолжает существовать и на сентябрь 2026 года официально разрабатывает **Marvel’s Blade**.

## 1\. Ключевая организационная схема { #1 }




### 1999–2006: одна Arkane { #19992006-arkane }




**Arkane Studios Lyon** основана в 1999 году. До появления американского офиса слово «Arkane» фактически означает именно французскую студию.




Основные проекты периода:




- Arx Fatalis;

- ранний Arx Fatalis 2;

- Dark Messiah of Might and Magic.





### 2006: появляется Arkane Austin { #2006-arkane-austin }




Американский офис открывается в **Остине, штат Техас, в 2006 году**. Колантонио переезжает в США.




Почему именно Austin:




- исторический центр Origin / Looking Glass / Ion Storm;

- там находились Warren Spector, Harvey Smith, Ricardo Bare и множество разработчиков школы Ultima/System Shock/Deus Ex;

- американский офис упрощал переговоры с издателями и поиск контрактов/сотрудников.





Важно: Austin сначала не был «студией Prey». Он был второй площадкой одной компании и частично деловым мостом Arkane к американской индустрии.




### 2010: ZeniMax покупает всю Arkane { #2010-zenimax-arkane }




Покупка включает Lyon и Austin.




### 2012: Dishonored делает общая Arkane { #2012-dishonored-arkane }




Первый Dishonored — последняя крупная игра, которую корректно воспринимать как единый трансатлантический production Lyon + Austin.




### После Dishonored: две самостоятельные линии { #dishonored }




**Arkane Lyon**
\- Dishonored 2;
\- Death of the Outsider;
\- Wolfenstein: Youngblood / Cyberpilot;
\- Deathloop;
\- Marvel’s Blade.




**Arkane Austin**
\- Prey;
\- Mooncrash;
\- Typhon Hunter / TranStar VR;
\- Redfall;
\- закрыта Microsoft 7 мая 2024 года.




### Сегодня { #_2 }




После закрытия Austin бренд Arkane фактически снова означает исходную французскую студию — **Arkane Lyon**. Официальный сайт в 2026 году по-прежнему указывает Lyon и Marvel’s Blade как текущий проект.

## 3\. Истоки Arkane и Arx Fatalis { #3-arkane-arx-fatalis }




### Период { #_3 }




1999–2003.




### Офис { #_4 }




Lyon.




### Ключевые люди { #_5 }




- Raphaël Colantonio — основатель Arkane, creative lead;

- маленькая исходная команда Arkane, порядка единиц/низких десятков человек.





### Исходная идея: сделать Ultima Underworld 3 { #ultima-underworld-3 }




Arkane появилась не потому, что Колантонио хотел «свою компанию» как бизнес-цель. Он хотел делать игры типа **Ultima Underworld**, а крупные издатели не давали ему такую игру вести.




Первоначальный проект по сути и был попыткой сделать официальный **Ultima Underworld 3**. Arkane собрала демо, вышла через сообщество Looking Glass на Doug Church и Paul Neurath и пыталась договориться с EA, владевшей Ultima.




EA не приняла проект в том виде, в каком Arkane хотела его делать. В результате студия отказалась от лицензии и превратила основу в собственную игру.




### Arx Fatalis — 2002 { #arx-fatalis-2002 }




#### Что хотели { #_6 }




Не просто «RPG от первого лица», а:
\- ограниченный, но свободно исследуемый мир;
\- физическое присутствие игрока в пространстве;
\- предметы и системы, которые ведут себя по правилам мира;
\- минимум абстракции между действием игрока и действием персонажа.




#### Структура мира { #_7 }




Весь мир находится под землёй после катастрофы, погасившей солнце. Люди, гоблины, тролли и другие общества живут на разных уровнях подземного комплекса.




Ключевой принцип — это **не последовательность одноразовых уровней**. Игрок постоянно возвращается в знакомые области, запоминает, как они связаны, открывает новые проходы и постепенно строит карту мира у себя в голове.




Именно эта структура спустя 15 лет напрямую отзовётся в Prey: Talos I будет тем же принципом «одно место, которое изучаешь как физическую систему», только вместо подземелья — космическая станция.




#### Системность { #_8 }




Примеры того, что уже было в первой игре Arkane:




- еду можно готовить у огня;

- ингредиенты можно комбинировать;

- предметы физически занимают место;

- свет важен для stealth;

- звук шагов зависит от поверхности/снаряжения;

- предметами можно воздействовать на нажимные плиты;

- есть алхимия, инструменты и физическое окружение.





Главная ранняя формула Arkane:




> **не делай кнопку «решить головоломку» — дай игроку предметы и правила.**




#### Магия { #_9 }




Заклинания состоят из комбинаций рун. Игрок не просто выбирает spell icon, а мышью рисует соответствующие символы.




Это неудобно по современным UX-меркам, но идеально показывает раннюю философию Arkane: интерфейс может быть менее удобным, если действие из-за этого ощущается физическим действием персонажа внутри мира.




#### Что не получилось { #_10 }




- melee ещё довольно грубый;

- UI и inventory тяжёлые;

- игра местами плохо направляет;

- много backtracking;

- баги и технические проблемы;

- коммерчески игра оказалась слишком нишевой.





#### Релизная ситуация { #_11 }




2002 год — Morrowind, Neverwinter Nights и другие огромные RPG. Arx выходит почти без сильного маркетинга на фоне проблем издателя.




Критики игру в основном понимают. Денег она почти не приносит.




Здесь впервые формируется повторяющийся сюжет Arkane:




> **очень необычная системная игра → критики/жанровая аудитория любят → коммерчески намного слабее ожидаемого.**




Позже тот же нерв будет у Prey.




### Xbox-версия Arx Fatalis — 2003 { #xbox-arx-fatalis-2003 }




Arx показывает, что сложную PC-RPG можно перенести на консоль, если адаптировать интерфейс и управление, а не уничтожать фундаментальную структуру игры.




Этот пример позже полезен в нашем обсуждении Deus Ex: консоль сама по себе не обязана убивать сложность — вопрос в том, **что именно команда готова пожертвовать**.




### Arx Fatalis 2 { #arx-fatalis-2 }




После первой игры Arkane естественно начинает Arx 2.




Основная ранняя идея:
\- город;
\- осада орками;
\- более современная технология;
\- переход на middleware вместо нового собственного движка.




Студия рассматривает Source.




Главная проблема — первая Arx продалась слишком слабо. Издатели не хотят финансировать прямой сиквел.




Arkane снова оказывается почти без денег.




#### Что произошло дальше { #_12 }




Ubisoft, только что получившая права на Might &amp; Magic, видит прототип и предлагает:




> оставить фундамент игры, но сделать её частью Might &amp; Magic.




Arx Fatalis 2 постепенно превращается в **Dark Messiah of Might and Magic**.

## 4\. Dark Messiah of Might and Magic { #4-dark-messiah-of-might-and-magic }




### Период { #_13 }




Примерно 2004–2006.




### Офис { #_14 }




Преимущественно Lyon. Austin открывается уже на финальной стадии проекта.




### Ключевые люди { #_15 }




- Raphaël Colantonio — Creative Director;

- Sébastien Mitton — приходит в Arkane в 2004 году;

- Christophe Carrier — level design;

- Randy Smith — внешний design consultant;

- расширившаяся Arkane-команда.





### Технология { #_16 }




**Source Engine.**




Это фундаментальный производственный поворот.




После Arx Колантонио считает создание собственного движка ошибкой для маленькой студии. Вместо того чтобы тратить годы на renderer/editor/basic tech, Arkane берёт готовую технологию Valve.




### Из Arx 2 в Might &amp; Magic { #arx-2-might-magic }




Изначально Mitton ещё застал проект именно как **Arx 2**.




После сделки с Ubisoft:
\- сеттинг встраивают в новый мир Ashan;
\- Ubisoft контролирует lore-фрейм;
\- RPG-часть становится компактнее;
\- экшен выходит на первый план.




### Главная дизайнерская задача { #_17 }




Arkane хочет решить проблему:




> **как сделать ближний бой от первого лица действительно телесным и приятным?**




Не «меч прошёл перед камерой, враг получил -20 HP», а:
\- дистанция;
\- масса;
\- импульс;
\- парирование;
\- толчок;
\- окружение;
\- попадание, которое ощущается верным, даже если физическая геометрия клинка несовершенна.




Команда много экспериментирует с FOV, анимацией, hit detection и видимым телом игрока.




### Рождение «ноги» { #_18 }




Пинок становится не просто дополнительной атакой, а главной системной кнопкой.




Игрок начинает смотреть на комнату так:




- где шипы;

- где обрыв;

- где огонь;

- где тяжёлый предмет;

- где лестница;

- что можно сломать.





Вопрос меняется с:




> «какое оружие сильнее?»




на:




> **«что в комнате можно превратить в убийство?»**




Это один из важнейших моментов формирования Arkane DNA.




### Source как соавтор дизайна { #source }




Half-Life 2 показала физику как игровую систему. Arkane делает следующий шаг:
\- физический объект — не головоломка ради физики;
\- физика становится частью боя.




Примеры:
\- оборвать опору и сбросить груз;
\- перерезать верёвку;
\- сбить противника в ловушку;
\- использовать лёд/огонь/телекинез;
\- взаимодействовать с объектами арены.




### RPG отходит назад { #rpg }




По сравнению с Arx:
\- мир становится линейнее;
\- меньше backtracking;
\- progression проще;
\- есть warrior/mage/stealth направления;
\- магазины в процессе разработки вырезали, потому что они ломали темп.




Arkane впервые явно ставит **темп action-игры выше полноты RPG-симуляции**.




### Важный урок производства { #_19 }




Финальная хорошая версия combat появилась слишком поздно.




К моменту, когда команда поняла, насколько сильно игра должна строиться вокруг пинка/физики, значительная часть уровней уже существовала.




Колантонио позже считал это ошибкой:




> core mechanic надо находить раньше, чтобы весь level design вырос вокруг неё.




Этот урок станет важным при создании Dishonored: сначала определить player verbs/powers, потом строить мир под них.




### Визуальная проблема { #_20 }




Mitton воспринимал Dark Messiah как слишком generic fantasy:
\- орки;
\- гоблины;
\- замки;
\- знакомая fantasy-иконография.




После проекта у Arkane усиливается желание:




> следующий мир должен иметь **очень конкретную авторскую визуальную идентичность**.




Это напрямую ведёт к The Crossing, а затем Dishonored.




### Randy Smith { #randy-smith }




После Looking Glass / Thief / Ion Storm Randy Smith консультирует Arkane по:
\- level design;
\- combat;
\- общей design structure.




Это один из прямых мостов школы Looking Glass в Arkane ещё до прихода Harvey Smith.




### Релиз и приём { #_21 }




PC-версия выходит в 2006 году.




Критика смешанная:
\- часть прессы любит физический melee и системность;
\- часть считает сюжет/RPG слишком простыми;
\- технический релиз страдает от крэшей и других проблем.




Со временем репутация игры становится заметно лучше. Для игроков главным наследием остаются:
\- пинок;
\- физика;
\- environmental kills;
\- очень непосредственный first-person melee.




### Elements — 2008 { #elements-2008 }




Консольная версия для Xbox 360 — **Dark Messiah of Might &amp; Magic: Elements**, в основном работа Ubisoft Annecy с материалами/участием Arkane.




Она:
\- сильнее фиксирует классы;
\- хуже технически;
\- заметно слабее принята.




В исторической линии Arkane основной Dark Messiah — это **PC-версия 2006 года**.




### Что перешло дальше { #_22 }




Из Dark Messiah в будущую Arkane:
\- environment as weapon;
\- first-person body/melee;
\- abilities как глаголы, а не просто damage modifiers;
\- идея «дизайнер готовит возможность, игрок должен чувствовать, что придумал её сам»;
\- пинок, который буквально вернётся в Deathloop.

## 5\. Открытие Arkane Austin — 2006 { #5-arkane-austin-2006 }




### Зачем { #_23 }




Austin создаётся:
\- для американских контактов и сделок;
\- для доступа к большому пулу талантов Origin / Looking Glass / Ion Storm;
\- как второй производственный и деловой центр компании.




Raphaël Colantonio переезжает в Austin.




### Важно { #_24 }




Dark Messiah остаётся в основном Lyon-проектом. Не нужно ретроспективно описывать её как совместную двухофисную игру.




Настоящая трансатлантическая Arkane начинает складываться **после** Dark Messiah.

## 6\. Return to Ravenholm / отменённый Half-Life Arkane { #6-return-to-ravenholm-half-life-arkane }




### Период { #_25 }




Примерно 2006–2007.




### Офис { #_26 }




Arkane; проект строится на Source.




### Предыстория: Junction Point { #junction-point }




До Arkane над Ravenholm-направлением работала **Junction Point Уоррена Спектора**.




Их версия:
\- должна была рассказать о Ravenholm до состояния, в котором его увидел Gordon Freeman;
\- подробнее раскрыть Father Grigori;
\- экспериментировала с **Magnet Gun**, позволявшим использовать металлические объекты как физическое оружие.




Valve закрыла эту версию, но сама идея внешнего Half-Life-проекта не умерла.




### Почему проект передали Arkane { #arkane_1 }




Arkane идеально подходила:
\- только что выпустила Dark Messiah на Source;
\- умела работать с Havok/physics;
\- любила системные first-person взаимодействия;
\- уже была знакома Valve;
\- имела опыт физического боя и environmental tools.




### Arkane-версия — это уже другая игра { #arkane- }




Не прямое продолжение проекта Junction Point.




#### Главный герой { #_27 }




**Adrian Shephard** из Half-Life: Opposing Force.




Это потенциально было его полноценное возвращение после 1999 года.




#### Ключевой персонаж { #_28 }




**Father Grigori.**




В версии Arkane он:
\- экспериментирует с headcrabs;
\- пытается создать средство, защищающее от заражения;
\- использует результаты исследований на себе;
\- постепенно начинает мутировать.




Сам сюжет должен был показать, как человек из Half-Life 2 приходит к своему странному состоянию и что происходит с ним дальше.




### Системные инструменты { #_29 }




#### Magnet Gun { #magnet-gun }




Наследие эксперимента Junction Point: физическое управление металлическими объектами.




#### Nail Gun { #nail-gun }




Особенно важная идея:
\- оружие стреляет гвоздями;
\- гвозди проводят электричество;
\- ими можно строить электрические цепи;
\- одна система работает как weapon, puzzle tool и инфраструктурный инструмент.




Это очень зрелая Arkane-логика:




> один инструмент должен иметь несколько универсальных функций.




#### Другие прототипы { #_30 }




Фигурировали:
\- air/leaf-blower-like tool;
\- chainsaw;
\- физические ловушки и другие interaction tools.




### Насколько далеко дошёл проект { #_31 }




Это был не маленький paper pitch.




По поздним воспоминаниям Колантонио:
\- существовал полный playable path от начала до конца;
\- несколько участков были близки к polished/cinematic качеству;
\- большая часть остального — alpha;
\- потребовалось бы ещё примерно 6–12 месяцев разработки.




### Viktor Antonov { #viktor-antonov }




Ravenholm — один из важнейших невидимых проектов истории Arkane именно из-за работы с **Viktor Antonov**, визуальным архитектором Half-Life 2 / City 17.




Колантонио позднее описывал Ravenholm как:




> **школу для Arkane.**




Антонов помогал команде мыслить не «красивым уровнем», а:
\- архитектурной логикой;
\- production art;
\- культурой места;
\- связью art direction и gameplay;
\- историей пространства.




Это напрямую подготовило студию к Dishonored.




### Почему отменили { #_32 }




Разные участники в разные годы упоминали:
\- усталость Half-Life от zombies/headcrabs;
\- ограничения timeline относительно Episode Two/Three;
\- экономику;
\- стоимость внешней эпизодической разработки.




Поздняя позиция Колантонио наиболее прозаична:




> Valve поняла, что экономика episodic-модели не сходится достаточно хорошо; Arkane требовала ещё значительное время, и бизнес-кейс перестал работать.




### Наследие { #_33 }




Ravenholm не вышла, но дала Arkane:
\- глубокий опыт Source/Valve production;
\- Viktor Antonov;
\- понимание системного инструмента, который одновременно является оружием и частью мира;
\- ещё один опыт отмены почти готовой большой игры.

## 7\. The Crossing { #7-the-crossing }




### Период { #_34 }




Примерно 2006–2009.




### Статус { #_35 }




Собственная IP Arkane; публично показана; серьёзно профинансирована самой студией; заморожена и фактически отменена.




### Значение { #_36 }




Первый большой проект, где Arkane пыталась придумать **не просто игру, а новую форму взаимодействия single-player и multiplayer**.




### Crossplayer { #crossplayer }




Основная идея:
\- сюжетный игрок проходит first-person campaign;
\- часть противников в ключевых зонах может контролироваться живыми игроками;
\- multiplayer-участник не обязательно воспринимается как отдельный «invader»;
\- он органично занимает роль персонажа мира.




В идеале campaign-player мог не знать:




> перед ним AI или живой человек.




### Два типа игроков { #_37 }




Упрощённо:
\- **story players** — более сильные персонажи, проходящие кампанию;
\- **skirmish players** — сетевые игроки, занимающие роли более обычных противников/участников конфликта.




Для multiplayer-человека сюжетный герой мог становиться специальной целью внутри привычного сетевого матча.




Это и было настоящим смыслом названия **The Crossing**: пересечение разных режимов/ролей внутри одной игры.




### Главная дизайнерская проблема { #_38 }




Свободный immersive sim любит:
\- паузы;
\- медленное исследование;
\- чтение;
\- долгий выбор маршрута.




Multiplayer любит:
\- постоянное действие;
\- предсказуемый темп;
\- быстрое появление противников/целей.




Если story-player десять минут читает документы, живые противники не могут десять минут сидеть и ждать.




Поэтому структура начала делиться на:
\- narrative/traversal sections;
\- multiplayer hotspots, где происходят встречи.




То есть сама multiplayer-механика начинала ограничивать свободу single-player — фундаментальный конфликт проекта.




### Мир: два Парижа { #_39 }




The Crossing была первой большой попыткой Arkane после Dark Messiah создать очень сильную собственную визуальную идентичность.




#### Париж №1 { #no1 }




Близкий к современному миру:
\- политический/социальный распад;
\- вооружённые группы;
\- современная урбанистика;
\- узнаваемая городская реальность.




#### Париж №2 { #no2 }




Альтернативная история:
\- в XIV веке тамплиеров не уничтожили;
\- они захватили/сохранили власть;
\- их цивилизация развивается дальше столетиями;
\- современность получается готической, рыцарско-технологической и совершенно иной.




Миры начинают пересекаться из-за экспериментов/портальной технологии.




### Viktor Antonov + Sébastien Mitton { #viktor-antonov-sebastien-mitton }




The Crossing — первый большой оригинальный мир, где Arkane серьёзно применяет совместную художественную школу Mitton + Antonov.




Здесь уже появляется метод, который позже станет центральным в Dishonored:




> знакомая европейская архитектура + история, пошедшая по другой ветке + альтернативная технология.




### Геймплейная смесь { #_40 }




Проект хотел объединить:
\- firearms;
\- first-person melee;
\- mobility tools;
\- systemic environment;
\- сетевых людей как часть encounter design.




То есть это логическое продолжение Dark Messiah и Ravenholm.




### Насколько далеко дошёл проект { #_41 }




Это не был pitch на десять страниц:
\- был рабочий vertical slice;
\- проект показывали журналистам и издателям;
\- люди реально играли друг против друга;
\- Arkane потратила примерно **около €1 млн собственных средств**.




Для независимой Arkane это был огромный риск.




### Почему проект не получил нормального издателя { #_42 }




Проблемы:




#### 1\. Непонятный продукт { #1_1 }




Издатель задавал базовый вопрос:




> это single-player или multiplayer?




В 2007 году рынок ещё не имел привычного языка вроде:
\- invasion;
\- asynchronous multiplayer;
\- shared-world systemic campaign.




#### 2\. Технический риск { #2_1 }




Нужно было решить:
\- matchmaking;
\- разрыв соединения;
\- skill mismatch;
\- живых игроков, которые знают карту лучше campaign-player;
\- timing story-player vs multiplayer users.




Arkane даже привлекала **Max Hoberman**, одного из ключевых людей multiplayer Halo 2, чтобы укрепить сетевую сторону pitch.




#### 3\. Платформы { #3 }




PC + Xbox 360 были реальны. PS3 добавляла дорогой технический риск, но крупные издатели хотели широкий рынок.




#### 4\. Стоимость { #4 }




Полная реализация оценивалась примерно в $15–20 млн — огромная сумма для независимой Arkane того периода.




#### 5\. Издатели хотели изменить сам проект { #5 }




Кто-то хотел:
\- убрать multiplayer;
\- убрать single-player;
\- сделать более обычный shooter;
\- радикально сменить сеттинг.




Один потенциальный партнёр почти дошёл до сделки, но:
\- бюджет уменьшался;
\- требований становилось больше;
\- риск переезжал на Arkane.




Колантонио решил, что контракт станет **setup for failure**, и отказался.




### Почему проект в итоге заморозили { #_43 }




EA предложила Arkane более безопасный контракт:
\- финансирование;
\- Spielberg;
\- Doug Church;
\- крупный first-person проект LMNO.




После риска The Crossing это выглядело разумнее.




Arkane переключила ресурсы на LMNO.




В 2009 году The Crossing публично объявили «on hold». Больше она не вернулась.




### Что перешло дальше { #_44 }




#### Визуально { #_45 }




The Crossing → Dishonored:
\- альтернативная европейская история;
\- сильная архитектурная идентичность;
\- школа Antonov/Mitton.




#### Системно { #_46 }




Crossplayer → позднее Deathloop:
\- живой человек внутри твоей одиночной fiction;
\- multiplayer не отдельным меню, а частью мира.




В Deathloop Arkane наконец решит scope-проблему:




> вместо целой команды живых противников — **одна Julianna**.

## 8\. LMNO — Spielberg / EA / Doug Church { #8-lmno-spielberg-ea-doug-church }




### Период { #_47 }




Основная версия с участием Arkane: примерно 2007–2008. Остаточная разработка внутри EA тянулась дольше; официальная отмена была подтверждена позже.




### Статус Arkane { #arkane_2 }




Arkane — не единственный и не главный разработчик всей LMNO. Основной проект шёл внутри EA Los Angeles / EA Blueprint. Arkane подключили как сильную внешнюю first-person команду, особенно по melee/level design/vertical slice.




### Ключевые люди { #_48 }




- Steven Spielberg — исходная концепция/история;

- Doug Church — один из главных игровых руководителей;

- Neil Young — внутренний покровитель проекта в EA;

- Arkane — внешний разработчик значимого vertical slice;

- Sébastien Mitton и другие сотрудники Arkane — визуальная/level/design работа.





### Исходная задача { #_49 }




Не сделать «Spielberg shooter», а ответить на вопрос:




> **может ли игра заставить игрока эмоционально привязаться к AI-партнёру через сами игровые системы?**




Центральный NPC — инопланетная девушка **Eve**.




Главный человеческий герой в поздних материалах — **Lincoln**.




### Сюжетная основа { #_50 }




- Eve удерживают в секретном исследовательском комплексе;

- Lincoln помогает ей сбежать;

- начинается road movie через США;

- государственные силы преследуют героев;

- игрок вместе с Eve проезжает мотели, кафе, заправки, маленькие города.





Тональность очень Spielberg:
\- E.T.;
\- Close Encounters;
\- road movie;
\- человеческая близость важнее «спасти галактику».




### Eve как игровая система { #eve }




Eve должна была:
\- наблюдать за человеческими предметами;
\- пробовать их использовать;
\- ошибаться;
\- реагировать на поведение игрока;
\- развивать отношения с Lincoln;
\- открывать/усиливать возможности в зависимости от сформировавшейся связи.




Идея:




> **отношения \= gameplay/progression**, а не отдельная полоска Like +5.




Характерный пример из сохранившихся материалов: Eve в кафе пробует майонез, не понимая человеческой еды, и реагирует на него как на странный объект.




Это мелочь, но она показывает центр дизайна:




> NPC должен казаться существом, изучающим мир, а не скриптовым companion.




### Movement / parkour { #movement-parkour }




LMNO проектировалась от первого лица с:
\- бегом;
\- прыжками;
\- climbing;
\- wall-running;
\- более физичной навигацией.




Eve должна была двигаться ещё необычнее и сверхчеловечески.




Параллельно внутри EA развивалась Mirror’s Edge, что создавало естественное сравнение технологий/parkour-направления, хотя нельзя сводить отмену LMNO к существованию Mirror’s Edge.




### No guns { #no-guns }




Spielberg не хотел превращать проект в обычный shooter.




Поэтому ключевым направлением стал **first-person melee**, более похожий на Jason Bourne:
\- захваты;
\- быстрые удары;
\- использование окружения;
\- обезвреживание вместо мясного FPS.




Именно здесь опыт Dark Messiah делает Arkane идеальным подрядчиком.




### Vertical slice Arkane { #vertical-slice-arkane }




Arkane делала заметный кусок вокруг американского **truck stop / roadside diner**.




Команда:
\- ездила по США;
\- фотографировала реальные места;
\- собирала field references;
\- строила пространство и взаимодействия.




Mitton позднее считал LMNO важной школой именно в методе полевых визуальных исследований. Этот подход потом станет нормой Arkane:




> понять реальное место → собрать реальные материалы → стилизовать, а не выдумывать визуальный шум из головы.




### Проблемы production { #production }




LMNO слишком долго находилась в research/prototyping:
\- как сделать Eve убедительной;
\- как связать relationship и gameplay;
\- как сделать parkour;
\- как сделать melee;
\- какой длины должна быть игра;
\- насколько она должна быть replayable.




Один из вариантов — короткая 2–3-часовая кампания с сильной вариативностью и повторными прохождениями.




Для AAA EA конца 2000-х это было очень трудно продавать:
\- цена полной игры;
\- короткое прохождение;
\- эпоха страха used-game resale;
\- нет очевидного multiplayer retention.




### Почему проект умер { #_51 }




Ключевые факторы:
\- проект долго не переходил из экспериментов в уверенный mass production;
\- внутренний покровитель Neil Young покинул EA;
\- финансовый кризис 2008;
\- EA начала сокращать и закрывать рискованные проекты;
\- основной состав LMNO расформировали;
\- участие Arkane прекратилось;
\- остаточная версия внутри EA постепенно превращалась в более обычный cinematic action-проект и тоже умерла.




### Почему отмена особенно ударила Arkane { #arkane_3 }




The Crossing была рискованной собственной инициативой.




LMNO, наоборот, была попыткой выбрать **безопасный большой контракт**:
\- EA;
\- Spielberg;
\- Doug Church;
\- оплачиваемая работа.




Когда умерла даже она, Arkane получила очень неприятный урок:




> даже большой издатель и большая лицензия не дают независимой студии стабильности.




После этого компания буквально распалась на work-for-hire группы.




### Что осталось в Arkane DNA { #arkane-dna }




- интерес к поведению NPC как к системе;

- first-person melee;

- real-world field reference;

- production discipline;

- ещё один опыт, где одна амбициозная идея не может быть доведена без чёткого scope.

## 9\. Период выживания 2008–2010 { #9-20082010 }




После LMNO Arkane временно перестаёт выглядеть как единая авторская студия.




Людей раскидывают по контрактам:
\- Call of Duty;
\- BioShock 2;
\- Boom Blox;
\- Ubisoft consulting;
\- небольшие неизвестные проекты;
\- KarmaStar;
\- другие work-for-hire задачи.




Harvey Smith в поздней ретроспективе вспоминал момент, когда Arkane одновременно имела примерно **девять проектов**, а финансовый runway мог составлять около четырёх месяцев.




Главный вывод:




> стратегия «много маленьких контрактов \= безопасность» помогает платить зарплаты, но уничтожает общий фокус и не создаёт будущее самой Arkane.




### 9.1 Call of Duty: World at War — 2008 { #91-call-of-duty-world-at-war-2008 }




Важно:




> Arkane не была основным разработчиком World at War.




Основная игра — Treyarch.




Certain Affinity помогала с multiplayer.




Часть людей Arkane работала через эту связку над multiplayer/level задачами.




Для истории Arkane важен не масштаб вклада, а контраст:
\- студия системных first-person RPG;
\- после нескольких отмен;
\- отдаёт специалистов в оплачиваемый production Call of Duty.




Это нормальная коммерческая работа, но не авторский проект Arkane.




### 9.2 KarmaStar — 2009 { #92-karmastar-2009 }




Маленькая стратегия/карточная игра для iPhone.




#### Harvey Smith { #harvey-smith }




После Deus Ex / Invisible War / BlackSite работает над микропроектом, прототипировавшимся буквально карточками и кубиками.




Суть:
\- человеческая жизнь как восемь ходов;
\- несколько характеристик/ценностей;
\- компактные решения;
\- маленькая команда.




Для Харви это было творческим восстановлением после тяжёлого AAA:




> снова можно видеть механику целиком и быстро понимать, работает ли решение.




Для Arkane это одновременно:
\- side project;
\- способ занять часть людей;
\- симптом периода, когда студия берёт любую оплачиваемую работу.




### 9.3 Ubisoft RPG consulting { #93-ubisoft-rpg-consulting }




Колантонио и Harvey консультировали Ubisoft по RPG/design.




Конкретный проект в нашем обсуждении надёжно не идентифицирован, поэтому в базе не приписываем ему название.




Значение:




> два человека школы Deus Ex/Arx объясняют другому издателю, как делать RPG, вместо того чтобы вести собственную.




### 9.4 Boom Blox { #94-boom-blox }




Поздние воспоминания Harvey подтверждают работу Arkane на EA/Boom Blox в этот период.




Детальный scope вклада в обсуждении не зафиксирован, поэтому не выдумываем конкретные levels/features.




Значение — снова симптом work-for-hire режима.




### 9.5 Неизвестный zombie shooter { #95-zombie-shooter }




Harvey упоминал небольшую группу сотрудников, отданных на внешний zombie-shooter project.




Название надёжно не установлено.




Сохраняем как факт существования внешнего контракта, но без домыслов.




---




## 10\. BioShock 2 — 2009–2010: work-for-hire, который действительно подходит Arkane { #10-bioshock-2-20092010-work-for-hire-arkane }




### Роль { #_52 }




Не основной разработчик. Основная студия — 2K Marin, с несколькими крупными партнёрами.




Arkane получает значимый блок:
\- level architecture;
\- level design;
\- art;
\- animation;
\- часть production для кампании.




Это уже не «пара людей в аренду», а отдельный Arkane-под внутри большого AAA.




### Почему работа важна { #_53 }




BioShock родственен школе Arkane:
\- System Shock;
\- first-person;
\- powers;
\- environmental storytelling;
\- системные encounter;
\- плотные interior spaces.




То есть Arkane наконец платят за то, **в чём она реально сильна**.




### Производственная школа { #_54 }




Arkane должна работать не в собственном мире, а внутри уже существующего Rapture:
\- соблюдать art bible;
\- понимать чужую systemic grammar;
\- строить уровень так, чтобы он выглядел частью BioShock, а не Arkane fan mod.




Полезный урок:




> авторская идентичность — не только «придумать своё», но и уметь понять внутреннюю логику чужого мира.




### Косвенное наследие { #_55 }




Технические приёмы с несколькими состояниями пространства/визуальными переключениями в BioShock 2 позднее всплывают как часть общего опыта, родственного тому, что Arkane значительно мощнее реализует в Dishonored 2: A Crack in the Slab.




Не утверждаем прямую «копию», но фиксируем технологическую школу.




### Что BioShock 2 дала бизнесу Arkane { #bioshock-2-arkane }




- крупный выпущенный AAA-credit;

- подтверждение компетенции в first-person level design;

- работа после серии отменённых проектов;

- более убедительное портфолио перед Bethesda/ZeniMax.





---




## 11\. Почему независимость перестала казаться свободой { #11 }




К 2009–2010 Колантонио приходит к парадоксальному выводу:




> формально independent studio может быть **сильнее зависима**, потому что каждый следующий проект зависит от внешнего издателя.




Независимая Arkane постоянно должна:
\- искать следующий контракт;
\- доказывать право существовать;
\- переключать людей между чужими production;
\- принимать отмену как финансовую угрозу всей компании.




Колантонио не создавал Arkane из романтики владения бизнесом. Он создал её, потому что иначе не мог делать игры типа Ultima Underworld.




Если крупная компания даст:
\- деньги;
\- стабильность;
\- право делать Arkane-игры,




то сама корпоративная независимость ему не особенно нужна.




На этом фоне предложение ZeniMax выглядит не «продажей принципов», а потенциальным способом **наконец получить больше творческой свободы через финансовую зависимость от одного владельца, а не десяти клиентов**.

## 12\. Bethesda, Thief 4 и Blade Runner — преддверие Dishonored { #12-bethesda-thief-4-blade-runner-dishonored }




Перед тем как окончательно прийти к собственной IP, Arkane обсуждала с Bethesda несколько мечтательных вариантов.




### 12.1 Thief 4 pitch { #121-thief-4-pitch }




Для Колантонио это почти идеальный проект:
\- основал Arkane из любви к Looking Glass;
\- Arx выросла из Ultima Underworld;
\- Arkane уже работала с Randy Smith, Harvey Smith, Antonov;
\- теперь можно официально продолжить Thief.




Существовал реальный pitch, включая visual/video материалы.




Это не просто «хотели бы когда-нибудь сделать Thief».




### 12.2 Blade Runner pitch { #122-blade-runner-pitch }




Параллельный вариант, особенно близкий Harvey Smith.




Arkane экспериментировала:
\- с first-person физикой репликанта;
\- с анимацией;
\- с тем, как отличать нечеловеческое тело не цифрой +Strength, а действиями и поведением;
\- с системными идеями вокруг мира Blade Runner.




Harvey гораздо сильнее тяготел к Blade Runner, Raph — к Thief.




### 12.3 Оба варианта не становятся реальными играми { #123 }




Лицензионные/коммерческие конструкции не закрываются.




Самое важное — Bethesda не уходит.




Она фактически говорит:




> нам нужна не только лицензия. Нам нужна **игра Arkane**.




Работа над Thief-like first-person systemic проектом остаётся фундаментом.




Параллельно/следом переосмысливается ранняя концепция supernatural ninja/revenge game.




Из этого начинает собираться собственная IP.




### 12.4 Покупка ZeniMax — 12 августа 2010 { #124-zenimax-12-2010 }




ZeniMax покупает Arkane Studios целиком:
\- Lyon;
\- Austin.




К моменту покупки Arkane уже работает над неназванным проектом Bethesda — будущим Dishonored.




Ключевое изменение:




> Arkane больше не надо каждые несколько месяцев делить команду между контрактами.

## 13\. Harvey Smith — путь до Arkane и почему он важен для студии { #13-harvey-smith-arkane }




Этот раздел не заменяет историю Arkane, а фиксирует только ту карьерную линию Harvey, которая объясняет, **что именно он принёс в Dishonored**.




### Super Wing Commander — 1994 { #super-wing-commander-1994 }




Роль: QA в Origin.




Harvey ещё не автор дизайна, но попадает внутрь компании, где:
\- интерактивное кино;
\- нелинейные кампании;
\- Warren Spector и Origin-school.




### System Shock — 1994 { #system-shock-1994 }




Роль: lead tester.




Ключевая точка всей карьеры:
\- Doug Church;
\- Warren Spector;
\- Looking Glass;
\- пространство как реальное место;
\- systemic design;
\- environmental storytelling.




Сам Harvey позже считал этот опыт своим дизайнерским bootcamp.




### Ultima VIII: Pagan — CD re-release { #ultima-viii-pagan-cd-re-release }




Роль: production/QA/design-adjacent работа.




Урок:




> упрощение/экшенизация сложной RPG может потерять часть её идентичности.




Впоследствии особенно иронично рифмуется с Invisible War.




### BioForge — 1995 { #bioforge-1995 }




Не считаем ключевой авторской игрой Harvey. Он не был одним из главных дизайнеров; важнее как соседний эксперимент Origin.




### CyberMage: Darklight Awakening — 1995 { #cybermage-darklight-awakening-1995 }




Harvey уже Associate Producer + немного design/dialogue.




Работает рядом с Warren Spector и David W. Bradley.




Ранний гибрид:
\- FPS;
\- RPG;
\- способности;
\- сюжет;
\- транспорт.




Для Harvey это переход от QA к настоящему production/design.




### Technosaur — \~1995–1996, отменён { #technosaur-19951996 }




Первая собственная крупная игра Harvey.




RTS:
\- погода;
\- распространяющийся огонь;
\- environment simulation;
\- кибернетические велоцирапторы.




Здесь уже виден будущий Harvey:




> универсальные системы лучше сотни специальных скриптов.




Проект закрывают на фоне финансовой/организационной перестройки Origin/EA.




### FireTeam — 1998 { #fireteam-1998 }




Harvey — Lead Designer.




Командный multiplayer:
\- классы;
\- objectives;
\- встроенный voice chat;
\- lobby/community;
\- рейтинги/кланы.




Очень современная конструкция для 1998 года, но рынок/аудитория слишком малы.




Во время работы Warren Spector зовёт Harvey в Ion Storm Austin.




### Deus Ex — 2000 { #deus-ex-2000 }




Harvey — Lead Designer.




Главный вклад в нашей истории:
\- problem, not puzzle;
\- multiple paths;
\- systemic consistency;
\- less is more;
\- дисциплина сокращения гигантского design scope;
\- навыки/аугментации/level-design grammar.




Warren Spector приносит огромную авторскую концепцию, Harvey помогает превратить её в работающую игру.




### Deus Ex: The Conspiracy — 2002 { #deus-ex-the-conspiracy-2002 }




PS2-адаптация.




Урок:




> сложную PC immersive sim можно перенести на консоль, если адаптировать интерфейс/техническую структуру, а не уничтожать ядро.




Карты режут дополнительными загрузками, но структура Deus Ex сохраняется лучше, чем в Invisible War.




### Deus Ex: Invisible War — 2003 { #deus-ex-invisible-war-2003 }




Harvey — Project Director.




Ключевой болезненный урок:
\- общий с Thief технологический фундамент;
\- тяжёлая динамическая технология;
\- Xbox 64 MB;
\- маленькие карты;
\- conscious streamlining;
\- skills убраны;
\- universal ammo (идея Harvey);
\- меньше пространства для планирования.




Поздняя ретроспектива Harvey/Ricardo:




> shared tech, плохо подходившая Deus Ex, была одной из больших ошибок.




Invisible War важна для будущего Arkane именно как **набор анти-уроков**:
\- не жертвовать пространством ради renderer;
\- не считать всю «сложность» мусором;
\- упрощение должно увеличивать решения, а не уменьшать их.




### Thief: Deadly Shadows — 2004 { #thief-deadly-shadows-2004 }




Не игра Harvey как руководителя.




Главные люди: Randy Smith / Jordan Thomas.




Harvey помогает ближе к финалу, в частности с locomotion first-/third-person.




Урок:




> технология, плохая для больших пространств Deus Ex, лучше подходит Thief, потому что свет/тень/компактные помещения — сердце Thief.




### Area 51 — 2005 { #area-51-2005 }




Harvey приходит в Midway уже ближе к окончанию проекта.




Не считаем Area 51 «его игрой»:
\- Studio Creative Director;
\- additional design/writing.




Это нормальный линейный коммерческий FPS, сильно отличающийся от immersive sim.




### Criminal / Career Criminal — отменён { #criminal-career-criminal }




Один из самых интересных потерянных проектов.




Концепция:




> **Heat + open-world immersive sim.**




Идеи:
\- профессиональные ограбления;
\- предварительная разведка;
\- команда;
\- распределение ролей;
\- intimidation вместо обязательного убийства;
\- поведение заложников;
\- полиция как последствие ошибок;
\- побег после heist.




Harvey пришёл в Midway во многом из-за интереса к этому направлению, но затем его перебросили спасать другой проблемный FPS-проект.




### BlackSite: Area 51 — 2007 { #blacksite-area-51-2007 }




Harvey получает тяжёлый production, который сам не выбирал как игру мечты.




После релиза публично критикует состояние разработки и ранний выпуск.




Midway и Harvey расстаются.




Главный личный урок:




> он больше не хочет выпускать игру, если считает её неготовой.




### Приход в Arkane — 2008 { #arkane-2008 }




Colantonio и Smith знают друг друга много лет и имеют общую интеллектуальную родословную:
\- Ultima Underworld;
\- System Shock;
\- Looking Glass;
\- Deus Ex.




Harvey приходит в Arkane после тяжёлого Midway-периода с огромным набором:
\- systemic design;
\- stealth;
\- level design;
\- production trauma;
\- понимание цены неправильной технологии;
\- желание снова делать глубокие first-person игры.




Именно встреча:




> **Arx/Dark Messiah (Raph)** \+ **System Shock/Deus Ex/Thief (Harvey)**




станет фундаментом Dishonored.

## 14\. Dishonored — происхождение и разработка { #14-dishonored }




### Период { #_56 }




Примерно 2009–2012.




### Офисы { #_57 }




Lyon + Austin как единая Arkane.




### Ключевые люди { #_58 }




- Raphaël Colantonio — co-creative director;

- Harvey Smith — co-creative director;

- Sébastien Mitton — Art Director;

- Viktor Antonov — Visual Design Director / world conception;

- Christophe Carrier и другие lead designers;

- Austin Grossman, Terri Brosius и другие writers;

- команда Lyon + Austin.





### Технология { #_59 }




**Unreal Engine 3** \+ собственные Arkane systems/tools.




### 14.1 До Dishonored: Thief 4, Blade Runner и ninja-концепт { #141-dishonored-thief-4-blade-runner-ninja- }




Ранняя история проекта грязная и складывается из нескольких слоёв:




1. Arkane обсуждает с Bethesda полноценный **Thief 4** pitch.

2. Параллельно Harvey ведёт pitch по **Blade Runner**.

3. Обе лицензионные версии не становятся production.

4. Сохраняется first-person systemic foundation, особенно Thief-подобная логика пространства.

5. Параллельно/следом существует ранний Bethesda-концепт supernatural ninja revenge game.

6. Arkane заменяет феодальную Японию на более близкий ей европейский материал.

7. Игра постепенно превращается в самостоятельную IP.





Свежие воспоминания разработчиков уточняют старую simplified legend «Japan → London → Dunwall»: между этими точками реально существовали Thief 4 и Blade Runner pitches.




### 14.2 London 1666 { #142-london-1666 }




Первая сильная авторская версия:
\- Лондон;
\- 1666 год;
\- Великая чума;
\- Великий пожар;
\- убийца;
\- политический кризис;
\- мрачный город.




Но геймдизайн начинает требовать технологий:
\- Walls of Light;
\- Tallboys;
\- прожекторы;
\- сложные механические системы.




Художественная команда всё сильнее уходит в более поздний XIX век.




В какой-то момент исторический Лондон уже не выдерживает накопившихся отклонений.




Так возникает **Dunwall** и собственная Empire of the Isles.




### 14.3 Player fantasy сначала, мир потом { #143-player-fantasy }




После ошибки Dark Messiah Arkane старается раньше понять:




> что игрок должен делать каждую минуту?




Главная формула:
**supernatural assassin.**




Отсюда уже строятся:
\- уровни;
\- архитектура;
\- powers;
\- AI;
\- verticality.




Это важный производственный рост Arkane:




> core verbs определяются раньше, чем весь мир окончательно заморожен.




### 14.4 Co-direction Raph + Harvey { #144-co-direction-raph-harvey }




Оба привыкли быть финальным творческим руководителем.




Для Dishonored они становятся равноправными co-creative directors.




Упрощённая разница подходов:
\- Raph — simulation, физические interaction, неожиданные системные комбинации;
\- Harvey — stealth, level-design discipline, narrative reactivity, multiple solutions.




Dishonored становится точкой встречи их биографий.




### 14.5 Viktor Antonov + Sébastien Mitton { #145-viktor-antonov-sebastien-mitton }




Именно здесь опыт Ravenholm/The Crossing окупается полностью.




#### Antonov { #antonov }




Большая концепция:
\- архитектура;
\- промышленность;
\- технологическая история;
\- силуэт города;
\- социальная структура пространства.




#### Mitton { #mitton }




Production-art:
\- персонажи;
\- материалы;
\- читаемость;
\- стилизация;
\- приведение большого visual bible в реальную игру.




### 14.6 Whale oil: worldbuilding через причинность { #146-whale-oil-worldbuilding }




Нужен источник энергии.




Arkane выбирает **китовый жир**.




Из одного решения логически следуют:
\- китобойный флот;
\- переработка;
\- рабочие;
\- порты;
\- экономика;
\- fuel tanks;
\- military tech;
\- социальный класс;
\- индустриальные районы.




Whale-oil tank одновременно:
\- lore object;
\- gameplay resource;
\- explosive;
\- power source;
\- security-system component.




Это один из чистейших примеров Arkane:




> **один объект должен работать и на fiction, и на системную игру.**




### 14.7 Визуальная читаемость выше технологического шума { #147 }




В 2012 индустрия одержима высокочастотными текстурами и детализацией.




Arkane сознательно стилизует:
\- крупные формы;
\- живописные поверхности;
\- читаемые силуэты;
\- преувеличенные лица/руки/тела.




Принцип:




> игрок должен мгновенно видеть окно, трубу, дверь, карниз, врага и маршрут.




Визуальная стилизация — не просто арт, а часть level design.




### 14.8 Stealth: не копия Thief { #148-stealth-thief }




Thief сильно опирается на тьму как числовую механику.




Dishonored больше использует:
\- line of sight;
\- view cones;
\- расстояние;
\- периферию;
\- архитектуру;
\- вертикальность.




Ключевой сдвиг:




> **Thief прячется в темноте; Dishonored прячется в архитектуре.**




### 14.9 Blink { #149-blink }




Blink становится центральной механикой не сразу.




Ранние варианты movement были менее чистыми.




Плейтесты показали:
\- люди часто играли почти как в обычный FPS;
\- многие не использовали powers.




Решение:




> дать базовый Blink всем и сделать его фундаментальной частью movement grammar.




Отсюда дизайнеры могут гарантированно строить:
\- крыши;
\- фонари;
\- трубы;
\- окна;
\- балконы;
\- вертикальные shortcuts.




Минимальная mana regeneration специально поддерживает частое использование Blink.




Урок по сравнению с Invisible War:




> хорошее упрощение не уменьшает decisions — оно **чаще приводит игрока к интересным decisions**.




### 14.10 Powers как verbs { #1410-powers-verbs }




- Blink — изменить позицию игрока;

- Possession — изменить, кем является игрок;

- Bend Time — изменить правила времени;

- Windblast — изменить положение объектов/людей;

- Devouring Swarm — создать самостоятельных существ;

- Dark Vision — изменить доступную информацию.





Это не просто «spells с damage values».




Именно поэтому системы комбинируются без сотен специальных scripted combos.




### 14.11 Весёлые exploits { #1411-exploits }




Arkane сознательно различает:
\- баг, ломающий progression;
\- неожиданный interaction, логично вытекающий из систем.




Второй тип часто оставляют.




Философия:




> если игрок сделал что-то неожиданное, логичное и весёлое — не спешить чинить только потому, что дизайнер это не планировал.




### 14.12 Mini-open worlds { #1412-mini-open-worlds }




Dishonored не open world.




Структура:
\- последовательность hand-crafted missions;
\- каждая миссия — большой автономный район;
\- внутри района множество путей.




Это компромисс между:
\- Arx — одним большим связанным миром;
\- линейным action;
\- слишком маленькими пространствами Invisible War.




### 14.13 Hound Pits Pub { #1413-hound-pits-pub }




Hub между миссиями:
\- передышка;
\- персонажи;
\- реакция на предыдущие действия;
\- ощущение дома;
\- контраст с грязным Dunwall.




Hub помогает кампании ощущаться единым путешествием, а не меню миссий.




### 14.14 Нелетальные устранения { #1414 }




Изначально targets надо было именно assassinate.




Но система позволяла проходить рядовых врагов:
\- мимо;
\- choke;
\- sleep dart.




Возникла логическая проблема:




> почему pacifist-прохождение внезапно обязано убивать главную цель?




Arkane добавляет для каждой target нелетальный вариант.




Важно:




> non-lethal ≠ moral good.




Некоторые наказания хуже быстрой смерти:
\- Heretic’s Brand;
\- Pendleton brothers отправляют в рабство;
\- Lady Boyle — похищение одержимым поклонником.




### 14.15 Chaos { #1415-chaos }




Arkane избегает шкалы Good/Evil.




Chaos — реакция мира на уровень насилия:
\- больше трупов;
\- больше крыс;
\- больше Weepers;
\- более тяжёлое состояние города;
\- изменения диалогов/Emily/финала.




Но система создаёт противоречие:
\- игра даёт очень весёлые lethal tools;
\- игрок начинает воспринимать Low Chaos как «правильный» стиль;
\- часть дорогой боевой системы психологически оказывается запрещённой.




Это станет одной из вещей, которые Arkane попытается исправить в Dishonored 2 и радикально отбросит в Deathloop.




### 14.16 Corvo — молчаливый { #1416-corvo }




Причина:




> voiced protagonist может сказать фразу, противоречащую стилю конкретного игрока.




Поэтому Corvo остаётся blank-slate avatar.




Цена:
\- сильное projection;
\- слабее character arc;
\- эмоциональная дистанция.




Daud DLC потом покажут преимущества voiced protagonist.




### 14.17 Outsider { #1417-outsider }




Удобная fiction-фигура для supernatural powers.




Также тематически почти отражает самого дизайнера:




> даёт человеку силы и наблюдает, что он с ними сделает.




В первой игре Outsider намеренно остаётся загадкой.




### 14.18 Unreal Engine 3 и собственные системы { #1418-unreal-engine-3 }




Arkane выбирает зрелый middleware вместо технологической гонки.




Пишет поверх UE3:
\- stealth/AI;
\- audio propagation;
\- dialog/story tools;
\- gameplay systems;
\- **Soiree** — систему, позволяющую NPC плавно переключаться между scripted сценами и systemic AI.




Это важный анти-Invisible-War урок:




> renderer не должен быть главной инновацией игры; инженерное время важнее вложить в взаимодействие систем.




### 14.19 Релиз — октябрь 2012 { #1419-2012 }




Dishonored:
\- получает высокие оценки;
\- продаётся выше ожиданий Bethesda;
\- быстро воспринимается как новая франшиза;
\- получает BAFTA Best Game.




Историческое значение для Arkane:




> впервые большая оригинальная игра студии одновременно **вышла, была высоко оценена и коммерчески сработала**.




После Arx, Dark Messiah и серии отмен это главный перелом.

## 17\. Dishonored 2 { #17-dishonored-2 }




### Период { #_69 }




2013–2016.




### Офис { #_70 }




Arkane Lyon.




### Ключевые люди { #_71 }




- Harvey Smith — Creative Director;

- Sébastien Mitton — Art Director;

- Dinga Bakaba — Lead Designer;

- Christophe Carrier;

- Dana Nightingale и другие level designers.





### Технология { #_72 }




**Void Engine**, глубоко переделанный id Tech 5.




### 17.1 Задача сиквела { #171 }




Первая игра уже определила:
\- мир;
\- язык;
\- powers;
\- stealth/combat philosophy.




Поэтому Dishonored 2 может заниматься:




> не изобретением формы, а **углублением**.




Цели:
\- улучшить sword combat;
\- дать больше non-lethal combat;
\- улучшить stealth feedback;
\- сделать Chaos тоньше;
\- показать другой регион мира;
\- сделать миссии ещё более концептуально смелыми.




### 17.2 Emily как playable protagonist { #172-emily-playable-protagonist }




Через 15 лет девочка из первой игры становится императрицей.




Идея сильна потому, что игрок:
\- знает её ребёнком;
\- видел, как действия Corvo формировали её мировоззрение;
\- теперь играет за результат этих событий.




Позже добавляют и Corvo.




Игрок выбирает одного героя на всю кампанию.




### 17.3 Два powerset { #173-powerset }




Emily — не skin Corvo.




#### Emily { #emily }




- Far Reach;

- Domino;

- Mesmerize;

- Doppelganger;

- Shadow Walk.





#### Corvo { #corvo }




- развивает знакомые Dishonored powers.





Главная цель:




> выбор героя должен менять, **как игрок читает пространство**, а не только голос и анимацию.




### 17.4 Far Reach vs Blink { #174-far-reach-vs-blink }




Blink — мгновенное перемещение.




Far Reach:
\- физически тянет Emily;
\- имеет инерцию;
\- может подтягивать объекты/людей;
\- позволяет использовать momentum.




Даже «аналогичная» mobility power создаёт другой способ движения.




### 17.5 Domino { #175-domino }




Одна из чистейших Arkane-механик:




> связать состояния нескольких NPC.




Это не AoE spell, а новое системное правило:
\- усыпил одного — заснули связанные;
\- убил одного — умерли связанные;
\- другие systems могут воздействовать на связь.




### 17.6 No Powers { #176-no-powers }




Можно отказаться от Mark Outsider.




Это заставляет level design быть честным:
\- каждый ключевой маршрут должен иметь физическую логику;
\- powers расширяют пространство решений, но не являются обязательным ключом.




### 17.7 Voiced Corvo / Emily { #177-voiced-corvo-emily }




Опыт Daud DLC показывает плюсы voiced protagonist.




Corvo получает голос **Stephen Russell**, Garrett из классических Thief.




Философский сдвиг:




> Arkane выбирает более определённых персонажей вместо почти полного player projection.




### 17.8 Karnaca { #178-karnaca }




Mitton не хочет ещё четыре года делать холодный Dunwall.




Новый город:
\- Serkonos;
\- солнце;
\- море;
\- южная архитектура;
\- испано-итало-средиземноморские мотивы;
\- яркие интерьеры;
\- совсем другая социальная/географическая логика.




Задача:




> за секунду понятно, что это Dishonored, но это не Dunwall.




### 17.9 Worldbuilding → gameplay { #179-worldbuilding-gameplay }




#### Плоские крыши { #_73 }




В южной культуре крыши используются людьми → roof route больше не гарантированно безопасен.




#### Bloodflies { #bloodflies }




Экология трупов и заразы вместо повторения крыс.




#### Dust District { #dust-district }




Геология серебряных шахт → пыль → архитектура/windbreakers → gameplay routes → dust storms, меняющие visibility/stealth.




Классическая Arkane-причинность:




> геология → экономика → архитектура → механика.




### 17.10 Каждая миссия как отдельный тезис { #1710 }




Lyon максимально использует mission-based structure:
\- можно создать уникальную систему для одного уровня;
\- не надо сохранять её для всей игры.




Именно здесь Lyon формируется как студия **великих отдельных уровней**.




### 17.11 Clockwork Mansion { #1711-clockwork-mansion }




Kirin Jindosh живёт в доме, который реально перестраивается.




Механика:
\- стены двигаются;
\- комнаты меняют конфигурацию;
\- backstage spaces существуют за декорациями;
\- игрок может буквально залезть внутрь механизма.




Особенно Arkane:




> вместо того чтобы уважать «сцену трансформации», игрок может обходить её из технических кишок дома.




#### Production { #production_1 }




Уровень потребовал:
\- специальных moving-geometry tools;
\- сложной AI/navigation работы;
\- обработки объектов/трупов/мин во время трансформации;
\- технологий, которые потом пригодились другим картам.




#### Clockwork Soldiers { #clockwork-soldiers }




Роботы меняют знакомую grammar combat:
\- нельзя choke;
\- видят в разные стороны;
\- отрубленная голова не убивает, а делает робота слепым;
\- слепой робот может атаковать всё по звуку, включая союзников.




Уничтожение части врага создаёт **новое состояние**, а не просто HP reduction.




### 17.12 A Crack in the Slab { #1712-a-crack-in-the-slab }




Два состояния одного особняка:
\- настоящее;
\- прошлое.




Timepiece:
\- показывает другую временную линию;
\- позволяет мгновенно переключаться;
\- перемещение между эпохами становится traversal/puzzle/stealth tool.




Действия в прошлом меняют настоящее.




Если спасти Stilton от травмирующего ритуала:
\- меняется судьба персонажа;
\- состояние дома;
\- часть окружения/мира.




Это дорогой контент, который часть игроков вообще не увидит.




Именно за такую расточительность hand-crafted possibility-space Dishonored 2 становится культовой.




#### Powers отключены { #powers }




Arkane временно забирает обычный powerset, чтобы игрок действительно освоил новую механику времени и снова начал читать архитектуру ногами.




### 17.13 Dust District / Jindosh Lock { #1713-dust-district-jindosh-lock }




Фракционный конфликт:
\- Howlers;
\- Overseers.




Можно:
\- помочь одной стороне;
\- другой;
\- нейтрализовать обоих лидеров;
\- вообще не играть в эту ветку.




Если самостоятельно решить Jindosh Lock:




> можно пропустить значительную часть дорогого faction-content.




Игра уважает решение игрока даже когда это означает:




> он не увидит то, на что мы потратили бюджет.




### 17.14 Chaos 2.0 { #1714-chaos-20 }




Arkane сохраняет реактивность мира, но расширяет:
\- non-lethal combat;
\- drop knockout;
\- parry → choke;
\- stun options;
\- более тонкий вес отдельных NPC.




Low Chaos больше не обязан означать:




> только choke сзади всю игру.




### 17.15 Void Engine { #1715-void-engine }




Lyon берёт id Tech 5 и настолько сильно его модифицирует, что получается собственный **Void Engine**.




Плюсы:
\- технология под Dishonored;
\- большая визуальная/системная амбиция.




Минусы:
\- огромный production risk;
\- первые годы инструменты/движок нестабильны;
\- контент приходится переделывать;
\- PC launch страдает.




### 17.16 Релиз — ноябрь 2016 { #1716-2016 }




Как дизайн/level design:




> одна из вершин Arkane.




Как PC-релиз:
\- stuttering;
\- performance issues;
\- проблемы с scaling/settings;
\- технические патчи после запуска.




Коммерчески:
\- старт не показывает огромный рост относительно первой игры;
\- полные официальные lifetime sales не раскрыты;
\- поздние бывшие разработчики говорили, что игра не достигла внутренних ожиданий Bethesda;
\- утверждение «стоило дороже Skyrim» существует как позднее свидетельство бывшего сотрудника, а не опубликованный бюджет, поэтому в базе держим его как **reported claim**, а не бесспорный факт.




### Итог { #_74 }




Dishonored 2 — пик Lyon-формулы:
\- компактность;
\- очень высокая плотность решений;
\- уникальные mission gimmicks;
\- systems + authored spaces;
\- минимальный filler.




Но экономически это дорогая модель:




> можно потратить огромные ресурсы на целый механический дом или две временные версии особняка, которые игрок увидит один раз и частично.




Эта проблема позже станет важна для Deathloop, где повторное освоение одних и тех же районов станет частью самой структуры.

## 18\. Dishonored: Death of the Outsider — 2017 { #18-dishonored-death-of-the-outsider-2017 }




### Офис { #_75 }




Arkane Lyon.




### Формат { #_76 }




Standalone expansion / самостоятельная компактная игра на фундаменте Dishonored 2.




### Ключевые люди { #_77 }




- Dinga Bakaba и новое Lyon leadership;

- Harvey Smith уже постепенно возвращается к Austin;

- Sébastien Mitton и команда Lyon.





### Исходная идея { #_78 }




Не делать Dishonored 3 сразу после огромной Dishonored 2.




Вместо этого:
\- использовать уже созданный Void Engine;
\- сделать компактный финал большой сюжетной эпохи;
\- закрыть линии Daud / Billie / Outsider;
\- экспериментировать с системами без стоимости ещё одной огромной кампании.




### Главная героиня { #_79 }




**Billie Lurk**.




Её линия:
\- lieutenant Daud в DLC;
\- Meagan Foster в Dishonored 2;
\- теперь полноценный protagonist.




Это хороший пример того, как Arkane превращает DLC-персонажа в центральную фигуру серии.




### Daud { #daud }




Дауд снова появляется как ключевой человек, но центр действия передан Billie.




### Центральная задача { #_80 }




Буквально:




> **убить Outsider.**




То есть после нескольких игр, где Outsider является наблюдателем и источником сил, сюжет наконец направляет игрока прямо в Void и ставит вопрос о существовании самой supernatural-системы мира.




### Системные изменения { #_81 }




Arkane позволяет себе чуть сильнее отойти от привычного Dishonored:
\- другая система powers;
\- нет классической Mark-конструкции;
\- mana регенерирует свободнее;
\- меньше моральной бухгалтерии Chaos;
\- Billie ощущается иначе, чем Corvo/Emily.




Это логично:




> профессиональная убийца, идущая убивать бога, не должна постоянно жить под тем же моральным UI, что Corvo в первой части.




### The Bank Job { #the-bank-job }




Одна из самых сильных миссий:
\- банк;
\- security systems;
\- разные входы;
\- крыша;
\- подземные маршруты;
\- вентиляция;
\- возможность манипулировать инфраструктурой здания.




Это Arkane в чистом виде:




> одно здание как системная задача.




### Значение { #_82 }




Death of the Outsider:
\- закрывает большую арку первой эпохи Dishonored;
\- даёт Lyon компактный production после очень дорогой D2;
\- передаёт лидерство следующему поколению;
\- позволяет студии психологически завершить восьмилетнюю жизнь внутри Dishonored.




После неё Lyon сознательно хочет **другую игру**, а не Dishonored 3.

## 19\. Prey — 2017 { #19-prey-2017 }




### Период { #_83 }




Примерно 2013–2017.




### Офис { #_84 }




Arkane Austin.




### Ключевые люди { #_85 }




- Raphaël Colantonio — Creative Director;

- Ricardo Bare — Lead Designer;

- Susan Kath — Lead Producer;

- Austin team.





### Технология { #_86 }




**CryEngine.**




### 19.1 Почему Austin выбирает другой путь { #191-austin }




После Dishonored Austin не хочет делать вторую Dishonored.




Колантонио возвращается к первоначальной мечте Arkane:
\- Arx Fatalis;
\- Ultima Underworld;
\- System Shock.




Логика:




> Dishonored стала нашим Thief-наследником; теперь хотим сделать свою System Shock-игру.




### 19.2 Структура рождается раньше названия и сюжета { #192 }




Проект изначально не был reboot Prey.




Раннее рабочее название/направление связано с **Project Danielle**, отсылкой к SHODAN.




Главный structural pitch:




> взять Arx — один связанный мир — и сделать вместо подземелья космическую станцию.




Так появляется фундамент **Talos I**.




### 19.3 CryEngine как risk management { #193-cryengine-risk-management }




Lyon одновременно строит Void Engine для Dishonored 2.




Austin сознательно не хочет одновременно рисковать:
\- новой IP;
\- новой структурой;
\- новым огромным движком.




Поэтому берёт более готовый CryEngine.




Принцип:




> игра выбирает технологию под свои нужды; не унифицировать движок только потому, что две команды принадлежат одной компании.




Это организационно противоположно ошибке Ion Storm с общим tech для Invisible War / Thief.




### 19.4 Talos I — станция как реальное место { #194-talos-i }




Arkane сначала долго строит:
\- alternate history;
\- назначение станции;
\- логические отделы;
\- архитектурные слои;
\- бытовую инфраструктуру.




Станция должна отвечать на вопросы:
\- где люди живут;
\- где едят;
\- откуда воздух;
\- откуда энергия;
\- как доставляют грузы;
\- куда идут отходы;
\- где maintenance;
\- как физически связаны разные decks.




Характерный пример:




> отходы перерабатываются через систему, включающую угрей, которых затем могут возвращать в пищевую цепочку.




Даже гротескная деталь подчёркивает подход:




> station ecology должна быть понятна дизайнеру, даже если игрок увидит только часть логики.




### 19.5 Neo-Deco { #195-neo-deco }




Talos I строилась/перестраивалась десятилетиями.




Поэтому визуально есть слои:
\- старые советско-американские технологические секции;
\- индустриальные пространства;
\- поздняя роскошная TranStar-архитектура;
\- Art Deco / Neo-Deco.




Это не generic white sci-fi corridor.




Архитектура рассказывает:
\- историю станции;
\- корпоративную иерархию;
\- возраст помещений.




### 19.6 Физическая связность { #196 }




Ключ:




> станция реально является одним объектом.




Игрок:
\- возвращается в старые зоны;
\- открывает shortcuts;
\- понимает связи;
\- выходит наружу в zero-G/космос;
\- физически видит разные части станции снаружи.




Это прямой наследник Arx.




### 19.7 Mimic { #197-mimic }




Изначально идея была ближе к маленькому stealth/scout enemy.




Вопрос:




> как он прячется?




Ответ:




> **становится предметом.**




Это меняет всю игру.




Теперь обычный environmental prop:
\- кружка;
\- степлер;
\- стул;
\- коробка




становится потенциальным врагом.




Mimic заставляет игрока **смотреть на окружение**, а не просто идти по waypoint.




### 19.8 Mimic Matter { #198-mimic-matter }




Классическая Arkane-эволюция:




> если враг делает интересную системную вещь, можно ли дать её игроку?




Игрок превращается в маленький предмет и:
\- пролезает через отверстия;
\- обходит закрытые двери;
\- использует геометрию иначе.




Не «unlock door level 2», а:




> изменить физические свойства самого player object.




### 19.9 GLOO Cannon { #199-gloo-cannon }




Один из лучших примеров Arkane tool design.




Функции:
\- остановить Typhon;
\- перекрыть hazard;
\- закрыть утечку;
\- создать платформу;
\- построить импровизированную лестницу;
\- изменить traversal.




Одна «пушка» меняет:
\- combat;
\- puzzle;
\- exploration;
\- level geometry.




Прямая линия:
Dark Messiah environment tool → Ravenholm Nail Gun → Dishonored verbs → GLOO.




### 19.10 Recycler Charge { #1910-recycler-charge }




Не обычная grenade.




Она:
\- перерабатывает физические объекты в materials;
\- может уничтожить врагов;
\- может убрать тяжёлое препятствие, если у героя нет нужного Strength/Leverage.




Пример systemic solution:




> нет способности поднять шкаф — не обязательно прокачивать её; можно изменить сам объект.




### 19.11 Neuromods { #1911-neuromods }




Progression встроена в fiction:
\- реальная TranStar technology;
\- способности приобретаются через физический процесс;
\- human и Typhon abilities.




Чем больше Typhon-способностей использует Morgan, тем иначе некоторые системы мира воспринимают его/её — например turrets.




Build меняет не только числа, но и **отношение среды к персонажу**.




### 19.12 No Needles { #1912-no-needles }




Игру можно пройти вообще без Neuromods.




Это вынуждает level design оставаться проходимым:
\- abilities открывают возможности;
\- но не являются единственными ключами.




Прямая рифма с Dishonored 2 No Powers.




### 19.13 Вступление { #1913 }




Morgan просыпается в квартире, едет на работу, проходит тесты.




Потом выясняется:
\- квартира — декорация;
\- окно — экран;
\- «город» — постановка;
\- герой всё время внутри лабораторного комплекса.




Тематическая формула Prey задаётся очень рано:




> **не доверяй пространству.**




Mimic добавляет:




> не доверяй предметам.




Сюжет с памятью Morgan:




> не доверяй даже собственной прошлой личности.




Геймплей и тема работают вместе.




### 19.14 Morgan Yu { #1914-morgan-yu }




Можно выбрать мужскую/женскую версию.




Главная narrative-конструкция:
\- Neuromod-experiments постоянно сбрасывали память;
\- разные прошлые версии Morgan оставили противоречивые инструкции;
\- игрок сам решает, кем является текущий Morgan.




Это удобнейшая immersive-sim fiction:




> нет жёсткого «канонический Morgan так бы не сделал», потому что текущая личность реально формируется заново.




### 19.15 Narrative через место { #1915-narrative }




Сценарий и level design развиваются вместе.




Сайд-истории часто начинаются не с quest giver:
\- найден труп;
\- письмо;
\- workstation;
\- имя человека;
\- след;
\- физическая цепочка событий.




Знание станции становится отдельной формой progression.




### 19.16 «Баги», которые оставляют { #1916 }




Arkane снова применяет правило:
\- если неожиданное interaction логично вытекает из систем;
\- не ломает progression;
\- создаёт интересную историю,




то не обязательно его запрещать.




Prey — одна из самых чистых реализаций mature Arkane philosophy.




### 19.17 Название Prey { #1917-prey }




Игра не проектировалась как продолжение Prey 2006 / отменённой Prey 2.




Bethesda имела IP и навязала название уже существующему проекту.




Публично в 2017 Colantonio дипломатично принимал решение.




После ухода говорил жёстче:
\- не хотел названия;
\- команда не хотела;
\- считал это маркетинговой ошибкой;
\- приходилось изображать поддержку решения.




Позднее бывший маркетинговый руководитель Bethesda Pete Hines тоже говорил, что был против названия.




Почему название мешало:
\- фанаты старой Prey ждали другое;
\- люди, которым старая Prey не нравилась, могли проигнорировать;
\- аудитория immersive sim не сразу понимала, что перед ней System Shock-like Arkane game.




### 19.18 Релиз — май 2017 { #1918-2017 }




Критика в целом хорошая, но более смешанная, чем поздняя культовая репутация.




Коммерческий старт:
\- не катастрофа;
\- но не массовый breakout hit.




Важно:




> Prey со временем стала восприниматься значительно сильнее, чем в launch window.




### 19.19 Уход Raphaël Colantonio { #1919-raphael-colantonio }




Через несколько недель после релиза основатель Arkane объявляет об уходе.




Официально:
\- семья;
\- усталость;
\- желание переосмыслить жизнь.




Позже добавляет:
\- гигантский AAA production перестал приносить прежнюю радость;
\- слишком много энергии уходит на продукт/масштаб вместо чистого дизайна;
\- Bethesda/ZeniMax сильнее интересовалась live-service-направлением;
\- история с названием Prey тоже символизировала потерю части контроля.




Исторически:




> Prey — последняя большая Arkane-игра с основателем студии внутри.




### Итог { #_87 }




Prey — вероятно, самая «рафаэлевская» поздняя игра Arkane:
\- Arx structure;
\- System Shock fantasy;
\- системность;
\- физическое пространство;
\- инструменты с несколькими функциями;
\- знание мира как progression.

## 20\. Prey: Mooncrash — 2018 { #20-prey-mooncrash-2018 }




### Офис { #_88 }




Arkane Austin после ухода Colantonio.




### Ключевые люди { #_89 }




- Ricardo Bare — creative/design leadership;

- Susan Kath — production leadership;

- Richard Wilson и команда;

- Harvey Smith как studio leadership в Austin.





### Исходный вопрос { #_90 }




Prey даёт игроку огромное количество систем, но конкретный человек часто:
\- находит любимую пушку;
\- любимые три способности;
\- любимый способ вскрывать двери;
\- всю игру повторяет одну и ту же стратегию.




Mooncrash хочет:




> **насильно заставить игрока использовать больше systemic possibility space.**




### 20.1 Roguelite поверх immersive sim { #201-roguelite-immersive-sim }




Команда вдохновляется:
\- Spelunky;
\- Rogue Legacy;
\- Risk of Rain;
\- другими roguelites.




Но не хочет выбрасывать hand-crafted level design.




Решение:




> геометрия остаётся сделанной вручную; процедурно меняется **состояние пространства**.




### 20.2 Pytheas Moonbase { #202-pytheas-moonbase }




Новая лунная база TranStar.




Не procedural corridors.




Игрок постепенно реально учит:
\- Labs;
\- Moonworks;
\- Crew areas;
\- exterior;
\- routes.




Но каждый reset меняет:
\- врагов;
\- loot;
\- hazards;
\- сломанные/работающие системы;
\- доступность некоторых exit/paths.




### 20.3 Fiction: simulation { #203-fiction-simulation }




Главный внешний герой Peter работает на KASMA и исследует симуляцию последних событий Pytheas.




Это естественно объясняет:
\- reset;
\- вариативность;
\- несовпадающие reconstruction;
\- повторные попытки.




### 20.4 Пять персонажей { #204 }




Вместо универсального Morgan:
\- Engineer;
\- Security;
\- science/Typhon;
\- stealth/hacking;
\- другие специализированные роли.




Каждый имеет ограниченный набор skills.




Теперь одна дверь означает разную задачу в зависимости от того, **кто именно сейчас жив**.




### 20.5 Одна simulation на нескольких героев { #205-simulation }




Главная гениальная механика:




Персонаж №1:
\- чинит;
\- убивает;
\- открывает;
\- забирает loot;
\- оставляет предметы.




Персонаж №2 приходит в **тот же изменённый мир**.




То есть один run — подготовка следующего.




Игрок планирует:




> кем идти первым не потому, что он сильнее, а потому, что он создаёт лучший state для остальных.




### 20.6 Цель: вывести всех пятерых { #206 }




Большой системный экзамен:
\- каждый способ эвакуации обычно ограничен;
\- надо распределить exit paths;
\- некоторые требуют действий разных специалистов.




Это превращает Mooncrash почти в tactical immersive sim:




> ты управляешь не одним build, а последовательностью build-ов.




### 20.7 Corruption Meter { #207-corruption-meter }




В отличие от медленного Prey:




> время давит.




Чем дольше run:
\- сильнее враги;
\- выше опасность.




Это спорно внутри самой Arkane, потому что противоречит традиционному:




> исследуй медленно.




Но именно давление заставляет принимать неидеальные решения и не вычищать каждый шкаф.




Delay\_Loop.Time позволяет покупать себе время ресурсом.




### 20.8 Почему это важно { #208 }




Mooncrash решает важный парадокс immersive sim:




> много решений обычно превращаются в одно любимое решение опытного игрока.




Roguelite-состояние заставляет:
\- импровизировать;
\- менять build;
\- работать с другим loot;
\- использовать другой маршрут.




### 20.9 Влияние на будущую Arkane { #209-arkane }




Нельзя сводить Deathloop к «Mooncrash 2», но дизайнерское родство очевидно:




Mooncrash:
\- повторное пространство;
\- знание;
\- изменяющееся состояние;
\- планирование последовательности;
\- идеальный финальный run.




Deathloop:
\- повторные районы;
\- знание как permanent progression;
\- времена суток;
\- планирование идеального дня.

## 21\. Typhon Hunter и TranStar VR — 2018 { #21-typhon-hunter-transtar-vr-2018 }




### Typhon Hunter { #typhon-hunter }




Асимметричный multiplayer:
\- Morgan Yu;
\- до пяти Mimic-игроков;
\- Mimics превращаются в props;
\- смертельные прятки/Prop Hunt.




Исторически важно как ещё один эксперимент Arkane:




> живой игрок занимает роль существа fiction, а не абстрактного красного солдата.




Рифмуется с The Crossing и поздней Julianna в Deathloop.




Как самостоятельный продукт режим не получил сильной долгосрочной репутации.




### TranStar VR { #transtar-vr }




Небольшие VR escape-room сценарии на Talos I до событий Prey.




Значение:
\- эксперимент Austin с VR;
\- использование знакомых пространств как физического puzzle environment.

## 22\. Значение Prey-эпохи для Austin { #22-prey-austin }




Выпущенные форматы:
\- Prey — классический immersive sim;
\- Mooncrash — roguelite immersive sim;
\- Typhon Hunter — asymmetric multiplayer;
\- TranStar VR — VR escape room.




То есть после одной большой игры Austin экспериментирует сразу в нескольких направлениях.




Главный исторический вывод:




> после ухода Colantonio команда всё ещё полностью способна на оригинальный systemic design.




Поэтому Redfall нельзя объяснить простой формулой:




> «Raph ушёл — студия сразу разучилась делать игры».




Mooncrash является прямым опровержением.

## 23\. Wolfenstein: Youngblood — 2019 { #23-wolfenstein-youngblood-2019 }




### Офисы / студии { #_91 }




Arkane Lyon + MachineGames.




### Почему проект важен для Arkane { #arkane_4 }




Это не просто support-credit.




Lyon получает реальный опыт:
\- co-op;
\- более открытых районов;
\- repeatable mission structure;
\- сетевой синхронизации;
\- level design для двух человеческих игроков.




Именно этот опыт потом становится одним из мостов к Deathloop.




### 23.1 Почему MachineGames зовёт Arkane { #231-machinegames-arkane }




Wolfenstein до этого в основном:
\- линейный;
\- режиссированный;
\- одиночный.




Youngblood должна:
\- работать в co-op;
\- позволять двум игрокам расходиться;
\- иметь более открытые районы;
\- поддерживать возвращение в знакомые зоны.




Это ровно область, где Arkane сильнее:
\- verticality;
\- alternate routes;
\- systemic spaces.




Особенно заметно участие Lyon в уличных районах Парижа.




### 23.2 Париж { #232 }




Исторически красиво:
\- The Crossing — альтернативный Париж Arkane, отменён;
\- через \~12 лет Lyon всё-таки делает альтернативный Париж в Wolfenstein.




Теперь:
\- 1980;
\- нацистская оккупация;
\- более открытая городская структура.




### 23.3 Co-op как новая производственная школа { #233-co-op }




Два игрока означают:
\- они могут быть в разных частях карты;
\- spawn system должна учитывать обоих;
\- checkpoint/gating должны быть безопасными;
\- encounter нельзя проектировать только вокруг одной камеры/позиции;
\- пространство должно быть шире и многомаршрутнее.




Это не вопрос «добавить Player 2».




Меняется архитектура уровня.




### 23.4 Что получилось хуже { #234 }




Youngblood одновременно добавляет:
\- уровни персонажей;
\- enemy levels;
\- health bars;
\- weapon upgrades;
\- loot/economy;
\- currencies;
\- repeatable activities.




Эти systems часто конфликтуют с классическим Wolfenstein:




> оружие перестаёт быть чисто физически мощным и начинает работать через числовую progression.




Враги становятся bullet sponges, выбор оружия местами сводится к matching armor type.




Это важный анти-урок:




> большое пространство и RPG-progression сами по себе не создают Arkane-depth.




### 23.5 Service-ish zeitgeist { #235-service-ish-zeitgeist }




Youngblood не полноценная live-service игра, но хорошо отражает конец 2010-х:
\- co-op retention;
\- повторяемые миссии;
\- currencies;
\- progression;
\- длительный engagement.




В том же корпоративном климате ZeniMax позже будет развиваться Redfall.




Не прямая причинность, но важный фон.




### 23.6 Buddy Pass { #236-buddy-pass }




Хорошее решение:
\- один владелец Deluxe Edition может пригласить друга без полной покупки игры;
\- снижает барьер для co-op.

## 24\. Wolfenstein: Cyberpilot — 2019 { #24-wolfenstein-cyberpilot-2019 }




### Офисы { #_92 }




Arkane Lyon + MachineGames; Lyon особенно значима в производстве.




### Ключевой человек { #_93 }




**Dinga Bakaba — Game Director.**




Это важная ступень его карьеры:
\- Dunwall City Trials — producer;
\- Dishonored 2 — lead designer;
\- Death of the Outsider — leadership;

\- затем Deathloop.




### Формат { #_94 }




VR-only standalone side story.




### Идея { #_95 }




Не переносить обычный Wolfenstein movement в VR буквально.




Игрок — hacker/pilot French Resistance и захватывает нацистские машины:
\- Panzerhund;
\- Zitadelle;
\- drone.




VR fantasy строится вокруг:




> быть внутри машины, а не пытаться повторить 60-fps акробатический Wolfenstein в шлеме.




### Значение { #_96 }




Как игра Cyberpilot небольшая и не стала важным хитом.




Для истории Lyon:
\- VR production;
\- spatial UI;
\- телесное присутствие;
\- ещё один самостоятельный проект Dinga;
\- тренировочная ступень перед Deathloop.

## 25\. Deathloop — 2021 { #25-deathloop-2021 }




### Офис { #_97 }




Arkane Lyon.




### Ключевые люди { #_98 }




- Dinga Bakaba — Game Director / Creative Director;

- Sébastien Mitton — Creative / Art Director;

- Dana Nightingale, Christophe Carrier и команда Lyon.





### Историческая роль { #_99 }




Первая большая оригинальная IP Lyon после Dishonored, уже без:
\- Raphaël Colantonio;
\- Harvey Smith как непосредственного директора проекта.




Deathloop доказывает, что Lyon имеет собственное новое leadership.




### 25.1 Исходная задача { #251 }




После примерно восьми лет Dishonored команда хочет:
\- более сфокусированный high concept;
\- меньше гигантского world bible;
\- одно место;
\- одну аномалию;
\- сильную пару персонажей.




Ранние референсы:
\- John Carpenter;
\- The Thing;
\- Escape from New York;
\- The Running Man.




### 25.2 Blackreef { #252-blackreef }




Изолированный остров:
\- старая военная/исследовательская инфраструктура;
\- Cold War architecture;
\- поверх неё яркая культура AEON / вечной вечеринки;
\- 60s/70s-inspired retro-future.




Визуальная формула:




> холодный бетон военной базы + психоделическая поп-культура.




### 25.3 Временная петля без real-time таймера { #253-real-time }




Arkane понимает:




> настоящий тикающий таймер убьёт медленное исследование.




Поэтому день делится на дискретные периоды:
\- утро;
\- полдень;
\- послеобеденное время;
\- вечер.




Время продвигается, когда игрок сам покидает район.




Это почти turn-based structure поверх immersive FPS.




### 25.4 Четыре района × четыре состояния { #254 }




Основные районы:
\- Updaam;
\- The Complex;
\- Fristad Rock;
\- Karl’s Bay.




Одна карта в разное время суток меняется:
\- NPC;
\- открытые здания;
\- события;
\- Visionaries;
\- routes;
\- последствия ранних действий.




Дешёвая идея «всего четыре уровня» превращается в дорогую:




> каждый уровень должен оставаться интересным в нескольких состояниях.




### 25.5 Knowledge as progression { #255-knowledge-as-progression }




Самый настоящий permanent upgrade — информация:
\- код;
\- расписание;
\- shortcut;
\- причина события;
\- место цели.




Colt может потерять день, но игрок уже знает больше.




Позднее Residuum позволяет также сохранять любимое gear между loops.




### 25.6 Попытка уйти от F5/F9-перфекционизма { #256-f5f9- }




Классический immersive sim легко превращается:
\- quicksave;
\- эксперимент;
\- ошибка;
\- quickload;
\- идеальный ghost run.




Deathloop:
\- нет ручного сохранения внутри района;
\- Reprise даёт несколько жизней;
\- смерть не является моральной катастрофой;
\- reset встроен в fiction.




Цель:




> заставить игрока импровизировать, а не бояться «испортить» прохождение.




### 25.7 Нет Chaos { #257-chaos }




После Dishonored Arkane понимает, что интерфейс и финал фактически учили:




> stealth/low-chaos \= правильная игра.




Deathloop снимает моральное давление.




Eternalists всё равно проснутся снова.




Поэтому игра намного смелее говорит:




> используйте оружие, kicks, Slabs, хаос.




Это самая «не стесняющаяся быть шутером» крупная игра Lyon.




### 25.8 Powers { #258-powers }




Часть deliberately familiar:
\- Shift \~ Blink;
\- Nexus \~ Domino;
\- Aether \~ invisibility;
\- Karnesis \~ телекинетический контроль;
\- Havoc \~ боевой усилитель.




Arkane сознательно не пытается изобрести всё одновременно.




После The Crossing lesson:




> если loop structure и multiplayer новые, mobility/powers могут опираться на уже понятную дизайнерскую школу.




### 25.9 Возвращение ноги { #259 }




Поначалу был Dishonored-like parry.




PvP latency делает parry нечестным/неприятным.




Защитная система упрощается, а затем появляется решение:




> меньше defense, больше offensive displacement.




Возвращается **kick**, системный наследник Dark Messiah.




Через 15 лет студия снова официально делает пинок важным глаголом.




### 25.10 Murder puzzle { #2510-murder-puzzle }




Чтобы разорвать loop:
\- надо убить восемь Visionaries за один день.




Но цели:
\- находятся в разных районах;
\- появляются в разное время;
\- их расписание можно изменить.




Игрок не просто выбирает способ убийства:




> он меняет день так, чтобы нужные люди оказались в совместимых местах.




### Ограничение свободы { #_100 }




Глобально существует в основном одна правильная конфигурация Golden Loop.




То есть ощущение:




> «я сам сконструирую любой идеальный день»




на практике ближе к:




> «я постепенно реконструирую решение большой authored puzzle».




Это одна из главных границ Deathloop как immersive sim.




### 25.11 Julianna — реализованная мечта The Crossing { #2511-julianna-the-crossing }




The Crossing:
\- множество живых игроков внутри кампании;
\- огромный scope;
\- не вышло.




Deathloop:
\- один живой invader;
\- один понятный fictional character;
\- single-player остаётся главным.




Julianna:
\- может быть AI или человеком;
\- органична сюжету;
\- Eternalists считают её союзником;
\- может использовать карту, traps, alerts, Masquerade.




Colt имеет преимущество:
\- Reprise;
\- несколько жизней;
\- multiplayer можно выключить.




Arkane наконец находит scope, в котором идея seamless multiplayer inside fiction работает.




### 25.12 Youngblood как production-школа { #2512-youngblood-production- }




До Deathloop Lyon уже выпустила co-op game.




Поэтому у команды есть реальный опыт:
\- сетевого first-person;
\- двух людей на системной карте;
\- spawn/AI/network constraints.




Youngblood не породила Deathloop, но сделала технический/дизайнерский переход менее безумным.




### 25.13 Корпоративная ирония { #2513 }




Deathloop получает договор временной консольной эксклюзивности PS5.




Потом Microsoft покупает ZeniMax.




В результате:




> Arkane становится Xbox studio, но её новая игра год не может выйти на Xbox.




Контракт Sony сохраняется.




### 25.14 COVID и переносы { #2514-covid }




Проект:
\- изначально задумывался более компактным;
\- разросся;
\- пережил пандемию;
\- переносы;
\- смену корпоративного владельца.




Релиз: сентябрь 2021.




### 25.15 Приём { #2515 }




Критика очень сильная, множество GOTY/высоких оценок.




Игроки реагируют холоднее:
\- AI проще, чем ждут фанаты Prey/Dishonored;
\- четыре района повторяются;
\- systemic depth воспринимается как более лёгкая;
\- Golden Loop менее свободен, чем кажется.




Deathloop становится:
\- одной из самых доступных Arkane;
\- для части старых фанатов — одной из самых упрощённых.




### 25.16 Та же вселенная, что Dishonored { #2516-dishonored }




Позже Arkane официально подтверждает:




> Deathloop существует в мире Dishonored, далеко после Death of the Outsider.




Это не просто easter egg.




Линия Lyon:
Dishonored → Dishonored 2 → Death of the Outsider → большой временной разрыв → Deathloop.




### 25.17 Dinga становится лицом Lyon { #2517-dinga-lyon }




После Deathloop Dinga окончательно становится Studio Director / главным творческим лидером Lyon.




Линия:
\- producer;
\- lead designer;
\- director;
\- studio director.




Это важнейшее доказательство институциональной зрелости Arkane:




> студия переживает основателей и первых директоров.

## 26\. Redfall — 2023 { #26-redfall-2023 }




### Период { #_101 }




Примерно 2018–2023.




### Офис { #_102 }




Arkane Austin.




### Ключевые люди { #_103 }




- Harvey Smith — Studio Director;

- Ricardo Bare — Creative Director;

- Austin team;

- Roundhouse Studios и большой внешний support;

- ограниченная помощь Lyon.





### Исторический контекст { #_104 }




После Prey:
\- игра уважаема, но не массовый blockbuster;
\- Raph уходит;
\- ZeniMax сильнее интересуется долгосрочными/service-like продуктами.




При этом внутри Austin реально есть собственный интерес:
\- Harvey/Ricardo любят Diablo/Borderlands/co-op;
\- возникает вопрос: можно ли сделать **Arkane game, но с друзьями?**




То есть Redfall нельзя честно описать только как насильственный приказ сверху.




Правильнее:




> реальный творческий интерес к co-op совпал с корпоративным запросом на более массовую/долгоиграющую игру.




### 26.1 Исходный pitch { #261-pitch }




Не Left 4 Dead.




Ближе:




> open-world Arkane + co-op + vampires.




Сеттинг:
\- небольшой город в Massachusetts;
\- дома;
\- церкви;
\- магазины;
\- паром;
\- туристические зоны;
\- everyday Americana;
\- вампиры и культисты.




Потенциально это могло быть:




> «Prey в маленьком американском городе».




### 26.2 Главная производственная ошибка: две неизвестности сразу { #262 }




Harvey сам позднее формулировал риск:




> возможно, надо было выбрать либо open world, либо co-op.




Но Redfall берёт сразу:
\- open world;
\- four-player co-op;
\- hero builds;
\- loot;
\- narrative campaign;
\- repeatable activities;
\- service roots.




Для студии, традиционно сильной в плотных single-player пространствах, это гигантский скачок.




### 26.3 Плотность { #263 }




Классическая Arkane:




> зачем существует этот метр пространства?




Open world неизбежно добавляет:
\- дороги;
\- пустые промежутки;
\- traversal between points.




Сделать весь остров с плотностью Talos I практически невозможно по бюджету.




В Redfall периодически встречаются хорошие Arkane-дома/маленькие истории, но между ними появляется большое количество разреженного пространства.




Это одна из фундаментальных причин, почему игра ощущается не как «большой Prey», а как более пустая структура.




### 26.4 Loot против Arkane tool philosophy { #264-loot-arkane-tool-philosophy }




Prey reward:




> GLOO Cannon \= новый способ взаимодействия.




Redfall reward:




> часто новый экземпляр оружия с большей цифрой/редкостью.




Это не плохая система сама по себе, но она принадлежит другой дизайнерской школе.




Проблема:
\- недостаточно глубокая для идеального looter;
\- слишком числовая для традиционной Arkane.




Получается конфликт идентичностей.




### 26.5 Неясность направления { #265 }




По послерелизным расследованиям сотрудники не всегда понимали главный центр продукта:
\- Far Cry-like?
\- Borderlands-like?
\- multiplayer Arkane?
\- service?
\- single-player Arkane, который можно пройти вместе?




Если после нескольких презентаций аудитории приходится постоянно объяснять, **чем игра не является**, это симптом слабой продуктовой идентичности.




### 26.6 Исход ветеранов { #266 }




По поздним расследованиям к релизу около **70% людей, работавших над Prey**, уже не были в Austin.




Это не значит «70% всей студии уволились одновременно», но показывает очень глубокую смену состава.




Причина найма тоже очевидна:
\- человек идёт в Arkane из-за Prey;
\- получает open-world co-op loot/service-ish проект;
\- интерес может не совпасть.




Изменение команды усиливает production risk.




### 26.7 Ранние live-service элементы { #267-live-service }




Проект начинался в корпоративном климате, где ZeniMax интересовалась long-tail monetization.




Ранние версии предполагали больше service/microtransaction элементов.




К релизу магазин/микротранзакции убрали.




Но structural DNA:
\- герои;
\- loot;
\- repeatable world;
\- co-op;
\- post-launch heroes




уже остаётся.




### 26.8 Герои { #268 }




Layla, Jacob, Remi, Devinder.




Здесь всё ещё видна старая Arkane:
\- разные способности;
\- mobility tools;
\- отвлечение;
\- teleporter;
\- разные ways of approach.




Сами hero kits не являются главной проблемой Redfall.




Проблема в том, что окружающий systemic world не даёт им той плотности interactions, как Prey/Dishonored.




### 26.9 Co-op progression { #269-co-op-progression }




Сюжетный прогресс сохраняется только у host.




Гость сохраняет:
\- XP;
\- gear;
\- character progression,




но не campaign completion.




Логика:




> избежать разрушения нелинейной narrative sequence.




Минус:




> центральный co-op режим создаёт трение для группы друзей.




Ещё один пример конфликта narrative Arkane и persistent co-op.




### 26.10 Microsoft покупает ZeniMax { #2610-microsoft-zenimax }




Сделка объявлена 2020, закрыта 2021.




Некоторые сотрудники Austin, по поздним источникам, надеялись:
\- на reboot проекта;
\- возврат к single-player;
\- либо даже cancellation.




Microsoft сохраняет большую автономию Bethesda и почти не вмешивается в творческий курс.




Крупное видимое изменение:
\- PS5-версия прекращается;
\- focus Xbox/PC.




Phil Spencer после релиза признает:




> Xbox могла раньше и глубже работать со студией после приобретения.




Урок:




> **невмешательство — тоже управленческое решение.**




### 26.11 Перенос { #2611 }




Summer 2022 → первая половина 2023.




Значит Redfall уже получила заметное дополнительное время.




Важно:




> проблема была не только в polish. Structural design за дополнительные несколько месяцев не превращается автоматически в Prey.




### 26.12 Красные флаги до релиза { #2612 }




На Xbox launch:
\- только 30 fps;
\- 60 fps promised later.




Для big first-party co-op shooter это плохой сигнал.




Также:
\- single-player требует online;
\- нельзя нормально поставить одиночную игру на паузу.




Очень символично:




> production architecture multiplayer/service начинает диктовать поведение solo-mode.




### 26.13 Релиз — 2 мая 2023 { #2613-2-2023 }




Критический провал:
\- Metacritic около середины 50-х;
\- огромный разрыв с историческими оценками Arkane.




Проблемы:
\- AI;
\- баги;
\- crashes;
\- performance;
\- пустые части мира;
\- повторяемые активности;
\- слабая loot-структура;
\- недостаточно глубокий stealth;
\- отсутствие pause;
\- presentation.




Это уже не спор старых фанатов — игра объективно выходит недоделанной.




### 26.14 Но технические баги не являются единственной проблемой { #2614 }




Даже идеальный patch не меняет:
\- open-world density;
\- конфликт loot и systemic tools;
\- компромиссы solo/co-op;
\- service-shaped architecture;
\- общую неопределённость идентичности.




Phil Spencer после релиза правильно отмечал:




> delay сам по себе не решает creative execution.




### 26.15 Почему Redfall особенно больно видеть { #2615-redfall }




В отдельных зданиях периодически снова появляется Arkane:
\- маленькая история;
\- несколько входов;
\- environment storytelling;
\- нормальная verticality.




И поэтому видно:




> внутри Redfall реально существует призрак более плотной игры, которую Austin могла бы сделать.




Но он растворён в open-world масштабе.




### 26.16 Пострелизные исправления { #2616 }




Arkane продолжает работать примерно год.




Добавляют/улучшают:
\- AI;
\- encounter frequency;
\- performance;
\- 60 fps mode;
\- stealth takedowns;
\- controller settings;
\- другие QoL.




В 2024 Update 4:
\- offline mode;
\- настоящий single-player pause;
\- Community Standing;
\- Elder Nests;
\- новые encounters;
\- Story Mode;
\- другие улучшения.




Последний патч специально делает игру более автономной, чтобы она не умерла вместе с онлайн-серверами.




### 26.17 Hero Pass { #2617-hero-pass }




Дорогие издания обещали двух будущих playable heroes.




На момент закрытия studio production ещё не был полностью заброшен.




После закрытия:
\- heroes отменяются;
\- покупателям предлагают компенсационную программу.




### 26.18 Закрытие Austin — 7 мая 2024 { #2618-austin-7-2024 }




Microsoft закрывает **Arkane Austin**.




Не всю Arkane.




Важно:
\- исходная Lyon продолжает существовать;
\- Austin существовала с 2006 по 2024.




Harvey позднее говорил, что команда уже работала над неанонсированной следующей штукой и закрытие стало шоком.




Colantonio резко критиковал решение:




> команды такого типа нельзя просто восстановить наймом новых людей; ценность была в конкретной сложившейся группе.




### 26.19 Ответственность { #2619 }




Нельзя сводить Redfall к:




> «злые корпораты заставили гениев».




Harvey Smith и Ricardo Bare реально руководили проектом.




Они:
\- хотели co-op experiment;
\- согласились на open world;
\- принимали дизайн-решения.




Но контекст важен:
\- service push;
\- scope;
\- staff attrition;
\- смена владельца;
\- пандемия;
\- нехватка ясности;
\- большой внешний production.




Redfall — одновременно:
\- управленческая;
\- дизайнерская;
\- организационная;
\- корпоративная неудача.




### 26.20 Redfall как анти-Prey { #2620-redfall-prey }




**Prey**
\- маленькая площадь, огромная плотность;
\- reward \= новый способ взаимодействия;
\- single-player dictates architecture;
\- каждая комната может быть задачей.




**Redfall**
\- большая площадь, меньше плотности;
\- reward часто \= число/редкость;
\- мир обслуживает solo + co-op;
\- между задачами много traversal space.




Именно поэтому игры одной студии ощущаются почти противоположностями.

## 27\. Marvel’s Blade — текущая глава Lyon { #27-marvels-blade-lyon }




### Статус на 2026-09-13 { #2026-09-13 }




**В разработке у Arkane Lyon.**




Официальный сайт Arkane в сентябре 2026 по-прежнему называет Marvel’s Blade:
\- mature;
\- single-player;
\- third-person;
\- Paris;
\- collaboration with Marvel Games.




На официальной странице Arkane сейчас указана Lyon как действующая площадка.




Важно: в этой базе фиксируем **официально подтверждённый текущий статус** и не выдаём неподтверждённые слухи о внутренней дате релиза за факт.




### Ключевые люди { #_105 }




- Dinga Bakaba — Game Director / studio leadership;

- Sébastien Mitton — Co-Creative / Art Director;

- Arkane Lyon.





### 27.1 Почему проект исторически странный { #271 }




Arkane десятилетиями строила идентичность вокруг first-person:
\- Arx;
\- Dark Messiah;
\- Dishonored;
\- Prey;
\- Deathloop;
\- Redfall.




Blade:




> **third-person.**




Это не косметическая смена камеры.




Меняется:
\- animation;
\- body readability;
\- locomotion;
\- melee silhouette;
\- camera design;
\- level visibility;
\- взаимодействие с углами/пространством.




Blade проверяет:




> Arkane DNA — это first-person камера или способ проектировать системные задачи?




### 27.2 Single-player immersive gameplay { #272-single-player-immersive-gameplay }




Официально Marvel/Bethesda подчёркивают:
\- оригинальная история;
\- signature immersive gameplay Arkane;
\- mature single-player third-person.




То есть задача не выглядит как:




> сделать обычный Marvel action с логотипом Arkane.




Студия явно хочет перенести свой метод дизайна в третье лицо.




### 27.3 Париж { #273 }




Для Dinga проект личный:
\- Париж — его родной город;
\- Blade — персонаж двойного происхождения;
\- он публично говорил о личной связи с героем.




Историческая рифма:
\- The Crossing — большой альтернативный Париж, не вышел;
\- Youngblood — Arkane всё-таки проектирует альтернативный Париж;
\- Blade — наконец собственная большая Arkane Lyon-игра про Париж.




### 27.4 Сеттинг { #274 }




Официальная завязка:
\- quarantined section of Paris;
\- supernatural emergency;
\- vampires вышли наружу;
\- жители прячутся ночью.




Очень аркейновская формула:




> конкретный город + системный кризис.




Dunwall — plague.
Karnaca — bloodflies/dust/political coup.
Blackreef — timeloop.
Blade Paris — vampire emergency.




### 27.5 Third-person challenge { #275-third-person-challenge }




Blade физически важен как персонаж:
\- меч;
\- тело;
\- стойка;
\- плащ;
\- movement;
\- combat silhouette.




В third-person игрок должен видеть самого героя.




Для Arkane это означает рост компетенций в:
\- character animation;
\- rigging;
\- locomotion;
\- third-person combat;
\- camera.




### 27.6 Почему Blade важнее лицензии { #276-blade }




Если проект получится, он докажет:




> Arkane не равна «first-person immersive sim».




Arkane \= метод:
\- системные инструменты;
\- пространство;
\- взаимодействующие правила;
\- несколько решений;
\- сильная identity;
\- игрок создаёт собственную историю действиями.




Blade — проверка переносимости этого метода в другую камеру и жанровую форму.

## 28\. Arkane DNA — эволюция принципов { #28-arkane-dna }




### 28.1 Мир как место, а не список уровней { #281 }




**Arx Fatalis → Prey**




Игрок должен понимать:
\- где находится;
\- что сверху/снизу;
\- как зоны связаны;
\- зачем пространство существует.




### 28.2 Environment as weapon/tool { #282-environment-as-weapontool }




**Dark Messiah → Ravenholm → Dishonored → Prey → Deathloop**




Комната — не фон.




Объекты:
\- толкаются;
\- горят;
\- проводят электричество;
\- питают системы;
\- становятся платформой;
\- меняют AI-state.




### 28.3 Universal verbs лучше специальных scripted solutions { #283-universal-verbs-scripted-solutions }




**Technosaur / Deus Ex через Harvey → Dishonored → Prey**




Хорошая способность:
\- не открывает один special door;
\- меняет правило мира.




Примеры:
\- Blink;
\- Possession;
\- Domino;
\- Mimic Matter;
\- GLOO;
\- Recycler;
\- Timepiece.




### 28.4 Problem, not puzzle { #284-problem-not-puzzle }




Наследие Deus Ex/Harvey.




Дизайнер ставит проблему:




> попасть внутрь, убрать цель, отключить систему.




Не диктует:




> найди синий ключ и положи на синий алтарь.




### 28.5 Игрок должен чувствовать, что решение придумал он { #285 }




Arkane часто заранее создаёт opportunities, но старается не выглядеть как:




> нажми дизайнерскую кнопку.




Шипы Dark Messiah поставлены специально — но пинок должен ощущаться твоей идеей.




### 28.6 Сильная authored architecture вместо generic open world { #286-authored-architecture-generic-open-world }




Пик:
\- Dishonored;
\- Dishonored 2.




Проблема Redfall показывает цену отхода от плотности.




### 28.7 Структура должна соответствовать игре { #287 }




Урок Invisible War:




> неправильная технология/размер карты может убить саму дизайнерскую фантазию.




Урок Prey vs Dishonored 2:




> две студии одной компании не обязаны использовать один движок.




### 28.8 Простота хороша, если увеличивает возможность действия { #288 }




Хорошее упрощение:
\- Blink бесплатно/доступно → игрок чаще использует verticality.




Плохое упрощение:
\- universal ammo → меньше запасных решений.




### 28.9 Fiction и gameplay должны объяснять друг друга { #289-fiction-gameplay }




Примеры:
\- whale oil;
\- Neuromods;
\- simulation в Mooncrash;
\- loop в Deathloop;
\- Daud Favors;
\- Bloodflies;
\- TranStar station infrastructure.




### 28.10 Не бояться дорогого контента, который игрок может пропустить { #2810 }




Это почти манифест Arkane:
\- альтернативные маршруты;
\- комнаты;
\- entire faction branch;
\- состояние прошлого/настоящего;
\- non-lethal chains.




С точки зрения Excel расточительно.
С точки зрения player agency — фундамент жанра.




### 28.11 Не каждый неожиданный interaction — баг { #2811-interaction }




Если system composition:
\- логична;
\- интересна;
\- не ломает progression,




Arkane часто предпочитает оставить.




### 28.12 Знание как progression { #2812-progression }




Особенно:
\- Deus Ex;
\- Prey;
\- Mooncrash;
\- Deathloop.




Игрок становится сильнее не только из-за цифр, а потому что:




> понимает место.




### 28.13 Игровая идентичность важнее «больше контента» { #2813 }




Лучшие Arkane:
\- имеют одну очень чёткую идею;
\- компактнее многих open-world AAA;
\- каждое пространство поддерживает эту идею.




Redfall показывает, что большой scope без той же плотности разрушает идентичность.




### 28.14 Multiplayer работает у Arkane, когда он подчинён systemic fiction { #2814-multiplayer-arkane-systemic-fiction }




Плохой/сложный ранний пример:
\- The Crossing — слишком огромный scope.




Удачный ограниченный:
\- Julianna в Deathloop.




Урок:




> не строить single-player вокруг нужд multiplayer; встроить multiplayer в уже работающую single-player fantasy.

Dishonored:

Deathloop:

\- Dishonored берёт зрелый UE3;
\- Prey сознательно берёт CryEngine;
\- студии не унифицируют technology ради корпоративной красоты.




### 29.7 Mooncrash → Deathloop { #297-mooncrash-deathloop }




Не прямое «копирование», но общая дизайнерская линия:

\- знания;

\- игрок учится владеть картой.




### 29.8 Youngblood → Deathloop production competence { #298-youngblood-deathloop-production-competence }

\- two-player first-person spaces;
\- более открытые районы.




Deathloop использует сетевого человека уже как противника/нарративного персонажа.




### 29.9 Dishonored 2 → Deathloop economic/design question { #299-dishonored-2-deathloop-economicdesign-question }




Dishonored 2:
\- невероятно дорогие hand-crafted levels;
\- игрок видит их один раз и может пропустить половину.




Deathloop:
\- меньше районов;
\- повторное посещение встроено в core loop;
\- игрок учится использовать дорогой level design много раз.

## 36\. Последний вывод { #36 }




История Arkane — это не история «студии immersive sim».




Точнее:




> immersive sim — следствие более глубокого принципа.




Arkane снова и снова пытается создать **пространство, которое не просто содержит контент, а отвечает на действия игрока через универсальные правила**.




Поэтому лучшие игры Arkane обычно имеют:
\- высокую плотность решений;
\- минимум filler;
\- сильную идентичность;
\- компактные пространства;
\- инструменты, которые меняют мир, а не только damage numbers;
\- возможность решить задачу неожиданным, но логичным способом.




А худшие моменты появляются, когда production уводит студию от этого:
\- слишком большая площадь;
\- слишком много корпоративных pillars;
\- технология начинает диктовать дизайн;
\- gameplay reward заменяется числовой progression;
\- проект пытается быть слишком многими играми одновременно.




Главная цепочка всей истории:




> **Ultima Underworld → Arx Fatalis → Dark Messiah → Dishonored / Prey → Deathloop → Blade.**




Между ними лежит кладбище отменённых проектов, и почти каждый труп всё равно оставил в следующей игре какую-нибудь механику, человека, production-метод или идею.




И именно поэтому история Arkane настолько связная:  

**они двадцать пять лет не делают одну и ту же игру — они двадцать пять лет пытаются решить одну и ту же задачу разными способами.**
