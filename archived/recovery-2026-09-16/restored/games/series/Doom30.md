#### 1\. Что произошло с DOOM после DOOM 64 и почему серия исчезла на несколько лет { #1-doom-doom-64 }




После DOOM II id очень быстро перестала воспринимать Doom как собственное будущее. Для нас сейчас линия выглядит почти непрерывно:




DOOM → DOOM II → DOOM 64 → DOOM 3.




Для id середины 1990-х она выглядела иначе:




DOOM → DOOM II → Quake → Quake II → Quake III.




Carmack уже считал Doom Engine решённой задачей. Студия всегда жила следующим техническим скачком: Keen дал scrolling, Wolfenstein — быстрый raycasting, Doom — сложное sector-based пространство, Quake должен был дать настоящий polygonal 3D. Поэтому идея сделать «DOOM III на чуть улучшенном старом движке» вообще противоречила культуре id.




Quake постепенно забрала почти все функции Doom: стала технологической витриной, главным брендом, основой engine licensing, моддинга, сетевой игры и будущего eSports. А сама Doom продолжила жить отдельно через Ultimate Doom, Master Levels, Final Doom, консольные версии и Doom 64. Особенно показательно, что Doom 64 — полноценная новая игра серии — создавалась в основном Midway, пока сама id уже жила Quake.




Публикация исходников Doom Engine в 1997-м символически окончательно разделила две линии:




id Software → Quake II → Quake III → новая технология.




DOOM community → Boom → ZDoom → PrBoom → бесконечные WAD.




Doom не умерла. Просто её развитие на годы ушло из основной команды id.




К 1999–2000 годам ситуация снова стала интересной. Quake III довела multiplayer-направление id почти до логического предела, Carmack строил очередной renderer, а сама студия уже сильно изменилась: Romero, Hall, Petersen, McGee давно ушли; остались Carmack, Adrian Carmack, Kevin Cloud и новое поколение разработчиков.




И тут рядом лежал бренд, к которому id по-настоящему не возвращалась почти десятилетие. Причём новая технология позволяла сделать то, что в 1993-м существовало только в воображении: настоящую марсианскую базу, физичных демонов, динамический свет, тени и убедительный horror.




Поэтому между DOOM II и DOOM 3 серия не столько «пропала», сколько разделилась:




DOOM как флагман id → исчезла.




DOOM как игровая система → продолжила бешено жить через community.




А вернувшись, id решила продолжать не эволюцию WAD-геймплея, а заново материализовать исходный миф: один Marine, база на Марсе и Hell за стеной.

#### 2\. Почему id вообще решила делать DOOM 3 { #2-id-doom-3 }




DOOM 3 не была автоматическим следующим проектом после Quake III. За неё внутри id реально пришлось бороться.




У Graeme Devine существовал проект Quest — fantasy online/RPG, вдохновлённый тем, насколько команда подсела на EverQuest. Уже шёл pre-production, Adrian Carmack рисовал art, и часть студии хотела наконец перестать снова делать «ещё один FPS с монстрами».




Другая часть команды, наоборот, очень хотела Doom. John Carmack позже публично описал конфликт: предложение несколько раз отклоняли, Adrian Carmack был против, а сторонники Doom в итоге фактически поставили владельцам ультиматум — либо следующим проектом становится Doom, либо увольняйте нас. Для маленькой id потеря Carmack и значительной части команды могла развалить студию, поэтому решение продавили.




Дополнительным аргументом оказался Return to Castle Wolfenstein: реакция на возвращение старого IP показала, что аудитория всё ещё хочет классические бренды id.




Но главный аргумент — новый renderer Carmack. Doom идеально подходила технологии динамического освещения:




тёмная база
\+
локальные источники света
\+
движущиеся тени
\+
демоны
\+
неизвестность за углом.




Это уже не «Doom, но больше полигонов». Можно было впервые сделать саму фантазию оригинальной игры физически убедительной.




При этом проект сразу задумывался как single-player, почти как реакция на Quake III. После чистого competitive multiplayer id снова хотела мир, атмосферу, scripting и кампанию.




Внутренний конфликт был настолько жёстким, что сразу после решения уволили Paul Steed, одного из сторонников Doom. Carmack считал это ответной мерой за его участие в бунте; Kevin Cloud и Adrian Carmack это отрицали и говорили, что причины были другими. Сам факт конфликта бесспорен, мотивация увольнения — уже спорная история.




Почему в итоге Doom победила? Всё сошлось одновременно:




Quake III завершила одну эпоху id;




Quest не объединяла команду;




старые IP снова были востребованы;




новый renderer идеально подходил horror;




а premise оригинальной Doom почти ничего не ограничивал.




Mars → UAC → teleportation → Hell → один Marine.




Не нужно продолжать сложный canon. Можно просто спросить:




> а что если бы первую Doom впервые делали в 2000-х?




Именно поэтому DOOM 3 изначально не пыталась сделать «современную Doom II». Она хотела реализовать фантазию 1993 года технологиями нового поколения. Отсюда потом естественно вырастут Mars City, NPC, PDA, тьма, маленькие encounters и horror pacing.

#### 3\. Кто делал DOOM 3: новая id Software { #3-doom-3-id-software }




К DOOM 3 это уже далеко не та маленькая группа, что делала игру 1993 года. Из старого ядра внутри остаются John Carmack, Adrian Carmack и Kevin Cloud; Romero, Hall, Petersen, McGee давно ушли.




Новая творческая ось выглядит примерно так:




John Carmack → technology.




Robert Duffy → lead programming.




Tim Willits → game / level design.




Kenneth Scott → visual direction.




Adrian Carmack + Kevin Cloud → art и связь со старой id.




Todd Hollenshead → CEO / business.




Graeme Devine → ранний project management и design.




Marty Stratton → пока business development, задолго до своей будущей роли в современной Doom.




Carmack остаётся техническим центром, но DOOM 3 уже невозможно описывать как «движок одного человека». Renderer и архитектура его, однако рядом есть полноценная programming team под Robert Duffy. Сам движок стал слишком большим для старой модели id.




Tim Willits фактически определяет, какой игрой станет эта технология. Он отвечает за pacing, level design, single-player structure и реализацию horror-концепции. Kenneth Scott — Lead Artist — формирует внешний вид мира и существ. Это важная смена поколений: Adrian Carmack всё ещё делает art, но уже не единолично задаёт визуальный язык Doom.




Производство тоже другое. В 1993-м mapper мог почти сам сделать игровое пространство. Теперь уровень — это связка:




level design + environment art + models + materials + lighting + scripting + sound + animation + cinematics.




То же самое с монстром: concept → high-poly → low-poly → normal maps → materials → rig → animation → effects → AI.




Graeme Devine особенно интересен как переходная фигура. Он продвигал Quest, затем всё равно работал project manager/designer на DOOM 3, но ушёл в 2003-м, примерно за год до релиза. Поэтому в истории финальной игры его видно гораздо меньше, чем Carmack, Willits и Scott.




И при всём этом основная id всё ещё удивительно маленькая — десятки людей, а не современная AAA-фабрика на тысячу сотрудников. Вокруг неё уже есть Activision, QA, локализация, внешнее аудио и voice acting, но центральная команда остаётся компактной.




DOOM 3 поэтому и ощущается странной переходной игрой. Гаражная id уже закончилась. Современная огромная id ещё не появилась. Старое ядро, Quake-поколение и новая AAA-структура впервые вместе пытаются решить, чем должна быть Doom XXI века.

#### 4\. Первоначальная концепция DOOM 3: не продолжение, а новая версия первой DOOM { #4-doom-3-doom }




Ключевая фраза Tim Willits времён разработки:




> It's like the original never happened.




DOOM 3 не строилась как продолжение Doom II или Doom 64. Никто не собирался отвечать на вопрос, что произошло с Doomguy после финала Doom 64. Это новый Marine и новое первое вторжение Hell.




Но retelling здесь не означает remake. id не собиралась делать E1M1, E1M2 и E1M3 в полигонах. Сохранялся не layout, а миф:




UAC
\+
Mars
\+
опасный эксперимент
\+
портал
\+
Hell
\+
демоны
\+
одинокий Marine.




И вот здесь появляется главный конфликт всей DOOM 3. Оригинальную Doom можно определить двумя способами.




Через механику:




скорость + толпы + projectile dodging + weapon rhythm + контроль пространства.




Через fantasy:




один Marine + мёртвая база + UAC + тьма + демоны + Hell.




DOOM 3 почти сознательно выбирает второе.




Поэтому id заранее говорила про fear, а не fast action. Большие толпы уступают место маленьким, близким encounters. Monster должен быть не «шахматной фигурой», а существом, с которым неприятно находиться в одной комнате.




Отсюда же идея показать Mars City ДО вторжения. Игрок сначала видит рабочих, охрану, учёных, терминалы и нормальную инфраструктуру. Потом то же пространство заражает Hell. Это почти возвращение к части идей Tom Hall: база наконец ощущается местом, а не абстрактной картой.




Появляются NPC, диалоги, scripted sequences и cinematics, но Marine остаётся немым. Мир становится намного более прописанным, а protagonist всё ещё должен оставаться в первую очередь аватаром игрока.




DOOM 3 впитывает язык FPS после Half-Life: работающий объект до катастрофы, живые NPC, событие прямо перед игроком, narrative внутри first-person пространства. Но накладывает на это собственную задачу — horror через свет, тени и физическое присутствие монстров.




Уровень тоже меняет природу. Classic Doom часто строит систему и даёт игроку самому создать последовательность событий. DOOM 3 гораздо чаще режиссирует время:




здесь услышишь звук → здесь погаснет свет → здесь появится demon → здесь откроется дверь.




Это даст великолепные сцены и одновременно породит проблему предсказуемых triggers.




Поэтому DOOM 3 с самого начала была задумана именно такой. Horror — не случайный побочный эффект движка и не поздняя ошибка production. Это сознательная попытка сделать реальным тот кошмар, который оригинальная Doom только подразумевала.

#### 5\. Macworld Tokyo 2001: первое публичное появление новой DOOM { #5-macworld-tokyo-2001-doom }




Первый публичный показ будущей DOOM 3 состоялся в довольно сюрреалистичной комбинации:




Steve Jobs + Apple + NVIDIA + John Carmack + новая Doom.




На Macworld Tokyo 2001 главной звездой вообще была GeForce3. Apple и NVIDIA показывали новое поколение GPU, а Carmack вышел продемонстрировать реальный game code, который это железо способен тянуть.




Почему на Mac? Потому что Carmack строил renderer вокруг OpenGL, и технология была гораздо менее привязана к Windows/Direct3D, чем многие современные движки. Демо реально работало под Mac OS X.




GeForce3 важна здесь как символ перехода к programmable graphics. Carmack хотел уже не просто «наклеить texture на polygon», а рассчитывать взаимодействие:




surface + material + light + normal + view direction + shadow.




Именно это публика впервые увидела. Персонажи входили в свет, поверхности реагировали на него, тени двигались вместе с объектами, мелкие детали выглядели объёмными.




Но это ещё не была DOOM 3 как полноценная игра. Не показывали нормальную миссию, combat loop, HUD и campaign structure. По сути это был первый публичный visual target и демонстрация Doom 3 technology.




Главная идея, которую Carmack продавал со сцены: свет становится полноценным объектом мира. Не заранее запечённой картинкой, а системой, которая сейчас взаимодействует с поверхностями и объектами.




И это идеально ложилось на Doom:




тёмный corridor
\+
одна лампа
\+
монстр ещё не виден
\+
его огромная тень уже движется по стене.




Технология уже сама подталкивала игру к horror.




Для Apple это был шанс показать Mac как платформу для cutting-edge realtime graphics. Для NVIDIA — killer demo GeForce3. Для id — первое заявление: новая Doom снова собирается быть технологической витриной поколения.




Причём до релиза оставалось ещё больше трёх лет. На Macworld показывали не готовый продукт, а направление исследования. Но практически вся будущая эстетика уже читалась:




high-detail models + per-pixel surface detail + dynamic lights + real-time shadows + тёмные interiors.




Публике сначала продали свет и поверхности новой Doom. Как в неё будут играть, объяснят уже позже.

#### 6\. E3 2002 и leaked alpha: момент, когда DOOM 3 стала настоящей игрой { #6-e3-2002-leaked-alpha-doom-3 }




Macworld показывал renderer. E3 2002 впервые показала саму игру.




Activision построила маленький закрытый театр, куда запускали небольшими группами. Демонстрация была полностью режиссированной: id контролировала темп, свет, камеру, звук, появление монстров и даже смерть Marine.




Начиналось всё показательно — не с BFG, а с людей на работающем объекте UAC. Публике демонстрировали лица, броню, материалы и свет. Затем эксперимент выходит из-под контроля, Hell буквально заражает комплекс, люди превращаются в zombies, и только после этого появляется Marine.




Уже здесь становится ясно, что ритм будет совсем не Doom II:




тёмный corridor → аварийный light → звук → shadow → несколько близких enemies.




Один monster должен быть сценой.




Особенно запоминался Pinky: огромная мясная кибернетическая тварь вместо старой розовой «собаки». Imp тоже стал физичным, агрессивным, прыгающим существом, хотя fireball сохранился. Одна из лучших сцен вообще строилась на тени огромного демона до появления самого демона. Вот ради этого и существовал весь renderer.




Финал демо специально заканчивался поражением Marine. Большой demon убивал героя практически перед камерой. Сообщение было предельно ясным: теперь этих монстров надо не только расстреливать — их надо бояться.




Огромную роль играл звук Trent Reznor. id даже возила специальный Dolby Digital theatre, потому что spatial audio была половиной horror-эффекта.




Показ работал на тогдашнем high-end железе ATI, позже связываемом с Radeon 9700. И даже в 640×480 выглядел как невозможное будущее. DOOM 3 снова стала той самой игрой, ради которой обсуждают новый компьютер.




А осенью 2002-го произошла знаменитая утечка E3 Alpha. В сеть попала сборка 0.02 примерно с тремя сегментами демонстрационного контента. Она не была готовой игрой — это snapshot ветки, созданной для контролируемого showpiece. Но интернету было похуй.




Люди начали запускать карты через console, копаться в cvars, renderer, editor и скрытых assets. Производительность была чудовищной, что только усилило миф «для Doom 3 понадобится новый компьютер».




Источник утечки публично окончательно не установлен. Главным подозреваемым долго была ATI, потому что hardware vendors получали ранние builds, но доказанного факта «ATI слила Doom 3» нет. Carmack отдельно заявил, что утечка точно не была намеренным маркетингом.




Сегодня alpha важна как археология. В ней сохранились ранние модели, звук Reznor, другое lighting и специально построенные showcase-сцены. Но сравнивать её с финальной игрой в духе «alpha была графически лучше» некорректно: несколько минут демонстрации могут позволить себе то, что двадцатичасовая стабильная campaign на тысячах PC не может.




Тем не менее именно E3 2002 зафиксировала публичную ДНК DOOM 3:




Mars + UAC + horror + darkness + dynamic shadows + few enemies + close encounters + scripted scares + тяжёлый sound design.

#### 7\. id Tech 4: почему технология DOOM 3 была поколенческим скачком { #7-id-tech-4-doom-3 }




Сразу поправка: название id Tech 4 закрепилось позже. Во время разработки это обычно называли Doom 3 engine / Doom 3 technology.




И революция была не в том, что id первой придумала normal mapping, dynamic shadows или per-pixel lighting по отдельности. Всё это уже существовало. Скачок в другом: Carmack построил весь renderer вокруг единой модели взаимодействия света, поверхности и объекта и реально сделал на ней большую игру.




До этого уровень часто освещался заранее:




geometry + baked lightmap → готовое освещение.




DOOM 3 хочет:




light + surface + material + object → результат считается сейчас.




Отсюда unified lighting. Один и тот же источник света влияет на стену, стол, Marine и Imp, а объекты могут реально перекрывать его и создавать тени.




Per-pixel lighting переносит расчёт с грубых vertex values на пиксели. А normal map позволяет простой геометрии выглядеть намного сложнее: поверхность остаётся почти плоской, но хранит направления microscopic normals, и свет реагирует на них так, будто там есть болты, складки, мышцы и вмятины.




Отсюда новый production pipeline:




high-poly model → bake → normal map → low-poly runtime model.




Геометрия хранит силуэт и крупные формы. Мелкий рельеф переезжает в texture data.




Material тоже перестаёт быть одной картинкой. Условно:




diffuse → цвет;




normal/bump → форма мелких деталей;




specular → насколько поверхность бликует.




Именно поэтому DOOM 3 так любит металл, пластик и влажную плоть: новый renderer буквально хочет показать движущийся specular highlight.




Вторая знаменитая часть — stencil shadow volumes. Из силуэта объекта относительно источника света строится геометрический shadow volume, а stencil buffer определяет, какие pixels находятся в тени. Поэтому тени получаются очень резкими и чистыми. Carmack популяризировал z-fail / «Carmack's Reverse» для устойчивой работы таких volumes.




Цена огромная: shadowing съедает чудовищный rendering budget, особенно если в сцене много lights и объектов. Это напрямую повлияет на level design.




Ещё одна крутая штука — in-world GUI. Монитор на стене является настоящим интерактивным интерфейсом. Подходишь, crosshair превращается в cursor, нажимаешь кнопку прямо на экране, дверь рядом открывается. Для UAC как «реального места» это чрезвычайно важно.




Именно здесь Doom 3, Half-Life 2 и Far Cry показывают три разных варианта next-gen 2004 года:




DOOM 3 → light, materials, shadows.




Half-Life 2 → physics, characters, simulation.




Far Cry → outdoor scale, vegetation, дальность.




DOOM 3 радикальнее остальных поставила почти всю игру на одну rendering philosophy. И поэтому технология будет не просто украшать игру — она начнёт диктовать жанр, размеры комнат, количество enemies, темноту и сам ритм.

#### 8\. Цена технологии DOOM 3: почему игра стала тесной, тёмной и тяжёлой { #8-doom-3 }




У id Tech 4 была очень конкретная цена. Каждый dynamic light реально стоил вычислений: surfaces, normal/specular maps, animated objects и shadow volumes нужно обрабатывать в runtime. Несколько lights в одной комнате — уже не просто «чуть красивее», а заметно больше работы.




Отсюда главный визуальный язык:




почти чёрное помещение
\+
одна белая лампа
\+
красный emergency light
\+
несколько monitors.




Художественно это horror. Технически — управляемый budget.




Тесные corridors и комнаты тоже удобны. Двери и стены легко делят мир на маленькие visible areas, ограничивая geometry, lights, monsters и shadows. Движок не запрещал большие пространства, но closed interiors идеально совпали и с rendering constraints, и с клаустрофобной концепцией.




То же самое с количеством enemies. Classic Doom может дешёво показывать десятки sprites. DOOM 3 demon — skeletal model + materials + normal maps + dynamic lighting + shadow + particles + sound + AI. Поэтому бюджет переносится от количества к качеству отдельного существа:




не двадцать Imps, а один Hell Knight, который реально занимает комнату.




Даже исчезающие трупы demons удобно работают сразу художественно и технически: они «возвращаются в Hell», а сцена не захламляется persistent geometry и shadows.




Отдельная история — абсолютная чернота. DOOM 3 великолепно считает direct light, но не имеет современного real-time global illumination. Нет прямого света — участок легко проваливается почти в black. В другой игре это недостаток. Здесь id говорит: отлично, сделаем из этого horror.




Так появляется flashlight loop. Фонарик — настоящий dynamic light, который оживляет normal maps и materials. И знаменитое «flashlight или gun» тоже частично выросло из бюджета: ещё один постоянно активный dynamic light вместе с оружием был дорогим, поэтому ограничение превратили в механику.




Hardware-требования тоже были частью мифа. Carmack предпочитал снижать resolution, но сохранять основную lighting model. Поэтому 640×480 с полноценными shadows считалось нормальным компромиссом.




Low / Medium / High / Ultra в основном управляли качеством и compression material maps. Ultra фактически смотрела в будущее и хотела около 512 MB VRAM — почти экзотику для 2004 года. Обычной системе уже было желательно около гигабайта RAM.




Но самая важная цена была не FPS, а дизайн:




маленькие spaces;




мало enemies;




локальные lights;




много darkness;




дорогие assets;




повторяемые industrial modules;




flashlight management.




Именно поэтому DOOM 3 настолько цельная и одновременно настолько спорная. Технология идеально помогла сделать страшную Doom, но естественным образом мешала сделать Doom с масштабом и readability классики.

#### 9\. Модели, normal maps и новый production pipeline { #9-normal-maps-production-pipeline }




DOOM 3 изменила не только картинку, но и саму профессию художника.




В classic Doom художник фактически создавал уже готовое изображение: sprite содержал и форму, и нарисованное освещение. В DOOM 3 объект должен правильно реагировать на любой dynamic light, поэтому информацию приходится разделять.




Diffuse отвечает за цвет.




Normal/bump — за microscopic форму.




Specular — за блик и ощущение материала.




Главная производственная схема:




concept → high-poly model → low-poly model → UV → bake normals → diffuse/specular → material → rig → animation → export.




High-poly может содержать огромное количество реальной анатомии: мышцы, морщины, швы, кости. В игру идёт значительно более дешёвый mesh, а информация о мелком рельефе запекается в normal map. Для этого id встроила в toolchain собственный RenderBump.




Normal map по сути хранит ту форму, которую выкинули из runtime geometry. Но она не меняет silhouette, поэтому художник должен понимать, что оставить polygons, а что можно запечь. Рога, пальцы и крупные выступы требуют geometry; мышцы, складки и болты отлично живут в normals.




Из-за tangent-space normal mapping внезапно становятся критичными UV seams, vertex normals, tangents и topology. Ошибка в развёртке превращается в lighting artifact. Художнику теперь мало «красиво моделировать» — нужно понимать весь technical pipeline.




Персонажи дополнительно требуют skeleton, skin weights и animation. DOOM 3 использует MD5Mesh / MD5Anim. Monster 2004 года — это уже совершенно другой производственный объект по сравнению со sprite 1993-го.




Та же философия переносится на environment. Огромная технологическая panel может геометрически оставаться почти плоской, а болты, канавки, швы и мелкие детали жить в normal map. Отсюда характерная визуальная плотность Mars Base.




И отсюда же знаменитый недостаток эпохи: все очень хотят показать новую технологию. Стены, кожа и металл становятся чрезмерно рельефными и блестящими. Возникает тот самый DOOM 3 wet/plastic look.




Но для monsters это работает великолепно. Hell Knight перестаёт быть просто картинкой-функцией и становится массой из мышц, кожи, бликов и тени, которая реально стоит перед игроком.




Поэтому normal mapping здесь важна не как отдельный «эффект». Она перестроила всю цепочку производства и приблизила игры к современной AAA-модели:




HIGH-POLY SOURCE ART → GAME-READY LOW POLY → BAKED SURFACE DATA → MULTIPLE MATERIAL MAPS → REAL-TIME SHADING.




DOOM 3 не изобрела этот процесс, но стала одним из самых громких ранних примеров того, как он выглядит в большой коммерческой игре.

#### 10\. DOOM 3 и война видеокарт: Radeon 9700, GeForce FX и GeForce 6800 { #10-doom-3-radeon-9700-geforce-fx-geforce-6800 }




За время разработки DOOM 3 успело смениться несколько поколений GPU, и игра буквально прошла через раннюю shader revolution.




2001 → GeForce3 показывает идею нового renderer.




2002 → Radeon 9700 Pro становится showcase-картой E3/QuakeCon.




2003 → GeForce FX показывает хаос переходного programmable-GPU мира.




2004 → GeForce 6800 оказывается почти идеальной картой для финальной DOOM 3.




Radeon 9700 была очень сильной архитектурой для нового универсального ARB2 path. Carmack открыто её хвалил: ATI могла хорошо исполнять современный shader path без огромного количества специальных костылей.




С GeForce FX получилось сложнее. Generic ARB2 на NV30 работал плохо, и Carmack пришлось делать отдельный NV30 path, учитывающий особенности precision и архитектуры. При правильной оптимизации карта могла быть быстрой, но сам факт прекрасно показывает эпоху: одна и та же lighting equation реально имела несколько vendor-specific реализаций.




И да, знаменитая GeForce FX 5800 Ultra была настолько шумной, что даже Carmack отдельно жаловался на её вентилятор. Тот самый Dustbuster.




К релизу ситуация опять поменялась. NVIDIA выпустила NV40 / GeForce 6800. Её сильный Z/stencil throughput великолепно совпал с workload DOOM 3:




много depth
\+
много stencil shadow volumes
\+
много lighting passes.




В финальных benchmarks 6800 Ultra стала одной из самых быстрых карт для игры, а 6800 GT особенно хорошо выглядела по цене/производительности. ATI быстро отыгрывала часть разрыва Catalyst-драйверами, но культурный narrative уже закрепился:




DOOM 3 → NVIDIA.




А через несколько месяцев Half-Life 2 часто показывала противоположную картину в пользу ATI. Это великолепный урок shader-era: «быстрее вообще» становится всё менее осмысленным. Разные engines нагружают разные части GPU.




Radeon 9700 при этом красиво пережила весь цикл: в 2002-м на ней показывали будущую Doom, а в 2004-м двухлетняя карта всё ещё нормально запускала финальный продукт.




Главное же — DOOM 3 снова превратила видеокарту в часть разговора об игре. В 1993-м спрашивали: «потянет ли мой PC Doom?» В 2004-м история повторилась почти буквально.

#### 11\. Почему DOOM 3 стала benchmark-игрой 2004 года { #11-doom-3-benchmark-2004 }




DOOM 3 очень быстро превратилась из просто тяжёлой игры в почти единицу измерения игрового PC.




Вопрос был не «какой у тебя компьютер?», а:




> сколько FPS в `timedemo demo1`?




Причина проста: id уже десятилетиями делала игры, которые удобно benchmark'ить, а DOOM 3 получила встроенный воспроизводимый timedemo. Вместо FRAPS и попытки дважды пройти один и тот же кусок можно было запустить одну и ту же записанную последовательность и получить конкретное число FPS.




Hardware press это мгновенно подхватила. Тот же demo1 использовали для GPU, CPU, RAM, drivers и overclocking. Первый прогон часто выбрасывали из-за caching, последующие уже давали хорошо повторяемый результат.




DOOM 3 была для этого почти идеальна:




очень тяжёлый cutting-edge renderer;




широкий диапазон hardware;




resolution и quality presets сильно меняют нагрузку;




результат понятен обычному человеку;




а сама игра всем интересна.




Можно было делать 640×480 для CPU scaling, 1024×768 High как нормальный игровой тест или 1600×1200 с AA как torture test. Один executable фактически превращался в маленькую лабораторию.




Особенно важна была возможность повторить журнальный тест дома. Читаешь обзор, видишь результат Radeon 9800 Pro, запускаешь `timedemo demo1` у себя и сразу начинаешь выяснять, почему у тебя на восемь FPS меньше: driver, RAM, AGP, CPU, overclock, настройки.




Отсюда огромная tuning culture вокруг Doom 3. Новые Catalyst и ForceWare измерялись буквально цифрами. Производители понимали, что победа в этом benchmark влияет на продажи, поэтому id даже старалась не давать demo sequence заранее, чтобы усложнить специфические driver optimizations.




И здесь Doom снова повторила собственную историю:




1993 → игра + технологическая витрина + причина апгрейдить PC.




2004 → то же самое, только уже с формализованным benchmark.




Crysis позже получит более знаменитый мем «but can it run Crysis?», но DOOM 3 за несколько лет до неё выполняла почти ту же культурную функцию.

#### 12\. Главная перемена: почему DOOM 3 превратилась в sci-fi horror { #12-doom-3-sci-fi-horror }




Главное решение DOOM 3 можно сформулировать очень просто:




страх важнее скорости.




id говорила об этом ещё задолго до релиза. Не толпы и twitch action, а маленькие близкие encounters, где сам отдельный demon должен быть неприятным существом.




При этом horror не взялся из воздуха. Оригинальная Doom уже имела тёмные комнаты, демоническую imagery, трупы, тревожные треки, traps и чувство изоляции. Doom 64 вообще ушла в мрачную сторону ещё дальше. DOOM 3 просто гипертрофирует именно этот слой.




Если буквально представить premise первой Doom — один человек на мёртвой марсианской базе, вокруг zombies и демоны из Hell, — это вообще-то ужастик. В 1993-м центральным удовольствием стала скорость и combat. В 2004-м id спросила: а что если заставить игрока реально почувствовать эту ситуацию?




Меняется сама единица дизайна.




Classic Doom:




encounter \= система enemies + geometry.




DOOM 3:




encounter \= событие.




Слышишь что-то → гаснет light → видишь silhouette → Imp прыгает почти в лицо.




Enemy count уменьшается, дистанция сокращается. Вместо «как мне управлять этой группой угроз?» чаще возникает «как быстро разобраться с тем, что сейчас вылезло из темноты?»




Но DOOM 3 всё-таки не survival horror. Marine носит весь арсенал, ammo хватает, inventory-management почти нет, enemies предполагается убивать. Это horror FPS: exploration медленный, combat короткий и резкий.




Базовый rhythm:




тишина → ожидание → вспышка action → снова тишина.




Проблема в том, что scare можно выучить. Первые часы:




взял armor → открылась стена → БЛЯТЬ.




Позже:




взял armor → ну да, сейчас откроется стена.




Classic Doom после mastery часто становится интереснее, потому что комбинации enemies и geometry продолжают давать новые ситуации. DOOM 3 сильнее зависит от first-time uncertainty, поэтому сама постепенно обучает игрока не бояться.




Зато atmosphere живёт дольше jumpscare'ов. Sound, lighting, industrial environment и ощущение реального места продолжают работать даже тогда, когда ты уже понял все tricks.




Поэтому DOOM 3 — странный hybrid. Снаружи современный cinematic horror. Внутри удивительно простой old-school shooter: никакого cover, classes, stealth и сложной AI simulation. Главный глагол всё ещё:




увидел demon → достал gun → убил demon.




Самая точная формула для меня:




DOOM 3 не модернизировала gameplay классической Doom. Она материализовала её кошмар.

#### 13\. Mars City как настоящее место { #13-mars-city }




Classic Doom проектирует пространство прежде всего как game space. E1M1 великолепна, но вопрос «что это за реальное здание и зачем здесь эта комната?» игре вообще не нужен.




DOOM 3 впервые требует другого:




Mars Base должна выглядеть так, будто люди реально здесь работали до появления игрока.




Отсюда reception, administration, Marine Command, infirmary, laboratories, communications, maintenance, recycling, power systems, storage, elevators, monorail.




И особенно важно, что базу показывают ДО катастрофы. В оригинале ты приходишь уже после того, как все умерли. Здесь сначала видишь рабочих, охрану, scientists, monitors и обычную корпоративную жизнь. Потом возвращаешься в те же помещения — и там кровь, zombies и сломанный light.




Чтобы потеря работала, сначала нужно показать нормальность.




Mars City пытается существовать как единый комплекс. Progression через Alpha Labs, EnPro, Communications, Recycling, Monorail и Delta Labs ощущается не просто последовательностью maps, а маршрутом вглубь объекта UAC.




Конечно, это всё ещё videogame architecture. Реальный инженер быстро бы сошёл с ума от этих corridors, machinery и опасных технических зон. Но нужна не абсолютная реалистичность, а functional plausibility: игрок должен примерно понимать, зачем эта часть базы существует.




Очень помогают signage и world-space interfaces. Вместо условной синей двери есть SECURITY, COMMUNICATIONS или ACCESS CONTROL. Экран на стене не просто texture: подходишь, crosshair превращается в cursor, жмёшь конкретную кнопку, дверь открывается.




UAC благодаря этому впервые становится не строкой из manual, а организацией с management, security, logistics, PR, research divisions и обычной бюрократией.




И здесь DOOM 3 явно живёт в мире после Half-Life. Структура «работающий facility → catastrophe → те же spaces в разрушенном состоянии» уже доказала свою силу в Black Mesa. DOOM 3 берёт этот язык, но соединяет его с Hell и lighting-horror.




Цена тоже очевидна. Чем сильнее level обязан притворяться реальным лабораторным комплексом, тем меньше свободы для абстрактной геометрии classic Doom. Mars Base убедительнее, но и однообразнее.




В первые часы coherence работает на игру.




Через десять часов очередной серо-металлический corridor уже начинает работать против неё.

#### 14\. Начало до вторжения: зачем Doom почти двадцать минут не даёт стрелять { #14-doom }




Для серии это почти кощунство: запускаешь DOOM и довольно долго вообще никого не убиваешь.




Но это не просто растянутая заставка. Игра одновременно обучает и строит emotional baseline.




Ты прилетаешь на Марс, проходишь reception, получаешь PDA, ищешь Marine Command, читаешь signage, видишь сотрудников, идёшь за sentry bot, спускаешься в Underground, получаешь pistol и armor, ищешь пропавшего scientist. И только потом начинается Hell.




Tutorial спрятан внутрь обычного рабочего дня Marine.




PDA выдаётся как корпоративный инструмент новому сотруднику.




Objective «найди Sergeant Kelly» учит навигации.




Sentry bot буквально показывает маршрут без giant quest arrow.




World-space monitors учат interaction без отдельного «PRESS E».




Оружие дают ДО первого enemy, чтобы игрок спокойно понял управление.




Но важнее четвёртая функция: игра показывает мир ДО.




До invasion:




люди + свет + охрана + работающая machinery + порядок.




После:




те же walls + corpses + zombies + darkness + demons.




Самый сильный момент — возвращение тем же маршрутом. Ты уже знаешь эту комнату и помнишь человека, который здесь стоял. Поэтому разрушение воспринимается как изменение знакомого места, а не просто horror decoration.




Игра ещё заранее подбрасывает тревогу: сотрудники жалуются, люди пропадают, слышат голоса, Delta Labs ведёт себя подозрительно. Поэтому структура не «нормально → внезапно Hell», а медленная escalation.




Всё это очень похоже на post-Half-Life grammar, но Marine в отличие от Gordon почти внешний наблюдатель. Он только приехал и знает ровно столько же, сколько игрок. Поэтому exposition новому сотруднику звучит естественно.




Почему id вообще могла позволить себе двадцать минут без action? Потому что она продавала уже не только стрельбу, но присутствие: свет, machinery, NPC, world GUIs, звук. Первая часть кампании работает почти как персональный tech demo нового engine.




На первом прохождении это сильный риск и сильный payoff.




На повторном — уже хуже. Ты всё знаешь и думаешь:




> да дайте уже пистолет.




Вот фундаментальная разница с E1M1: classic opener отлично replay'ится как game space; Mars City introduction сильно зависит от первого знакомства и атмосферы.

#### 15\. Environmental storytelling: PDA, письма, аудиологи и терминалы { #15-environmental-storytelling-pda }




DOOM 3 впервые пытается показать не просто «на базе случился ад», а как люди на ней жили за день до катастрофы.




PDA становится архивом мёртвого объекта. Находишь устройство сотрудника → получаешь его mail, audio logs, security info. Отдельно есть corporate video disks.




Идея простая и сильная: corpse перестаёт быть декорацией. У него было имя, должность, коллеги, жалобы и бытовая жизнь.




Лучшие записи вообще не про Betruger и Hell. Кто-то ругается на поставку, кто-то зовёт коллегу играть в покер, кто-то требует починить equipment. Именно эта скучная офисная хуйня лучше всего продаёт UAC как реальную корпорацию.




А затем бытовое постепенно заражается ужасом:




странные симптомы → пропавшие сотрудники → аварии → голоса → Delta Labs → паника.




Игрок собирает историю задним числом из mail + audio + bodies + environments.




Особенно хорошо работает контраст corporate PR и реальности. Video disk рассказывает, как UAC строит будущее. PDA инженера рядом фактически говорит: «эта хуйня опять сломалась, руководство игнорирует проблему».




World-space terminals ещё лучше, потому что не вырывают игрока из пространства. Экран — реальный объект, который может открыть door, запустить machinery или показать security cameras. Вот здесь environment действительно становится интерфейсом.




Но потом id связывает lore с наградой — и система начинает заёбывать.




Locked cabinet → ищи PDA → пролистай mail → найди три цифры → получи ammo.




Первые разы это прикольно: story + exploration + reward работают вместе. После двадцатого locker ты уже не думаешь, кем был этот человек. Ты сканируешь inbox на предмет PIN-кода.




Аудиологи создают отдельный UX-конфликт. Их можно слушать на ходу, но sound в DOOM 3 нужен для detection enemies. Можно стоять и слушать — тогда ломается pacing. Поэтому storytelling временами физически конфликтует с главным horror-инструментом игры.




И здесь хорошо видно различие plot и worldbuilding.




Plot DOOM 3 довольно простой.




Worldbuilding — значительно сильнее.




PDA великолепно показывает UAC как место с прошлым, но как постоянный code-delivery system превращается в bureaucracy simulator.

#### 16\. Дьявол в машине: technological horror DOOM 3 { #16-technological-horror-doom-3 }




Одна из лучших идей игры — Hell не просто приходит на базу. Он заражает технологию.




Начало Mars Base — это:




metal + glass + screens + pipes + robots + corporate signage + machinery.




Hell отвечает:




flesh + blood + bone + deformation + organic chaos.




Самые сильные места возникают там, где эти языки накладываются: обычная UAC laboratory, из стены которой уже растёт мясо.




Игра постепенно проходит стадии:




стерильная machine → заражённая machine → biomechanical nightmare → Hell.




Classic Doom уже имела flesh walls и cyberdemons, но DOOM 3 впервые делает это материальным. Normal maps, specular и dynamic lighting заставляют плоть блестеть, иметь рельеф и реально реагировать на flashlight. Тот самый чрезмерно «мокрый» shader-era look, который странно выглядит на человеке, для мяса и demon skin подходит идеально.




Creature design Kenneth Scott строится вокруг физической неправильности тела:




Imp — почти ободранная анатомия;




Pinky — мясо + cybernetics;




Revenant — skeleton + remnants of flesh + launchers;




Mancubus — огромный организм, сросшийся с machinery;




Cherub — человеческое и насекомое, собранные так, как не должны быть собраны.




Pinky вообще идеальная эмблема DOOM 3: Hell и machine буквально сшиты внутри одного существа.




Очень хорошо работает и база после смерти людей. Monitors, doors и machinery продолжают выполнять процедуры, хотя общество, для которого они существовали, уничтожено. Получается почти автоматический труп.




Dynamic lighting склеивает всё в один физический мир. Один и тот же light освещает steel, corpse, blood и demon. Fireball Imp на секунду сама становится движущимся источником света. Даже attack одновременно reveal'ит пространство и угрожает игроку.




Лучший horror DOOM 3 поэтому не просто darkness. Темноту можно сделать где угодно. Уникальнее другое:




нормальная человеческая machine постепенно становится ненормальным организмом.




DOOM 2016 и Eternal потом используют похожую смесь как «это круто, metal\!». DOOM 3 использует её иначе:




> ЭТО НЕ ДОЛЖНО БЫТЬ ВМЕСТЕ.




Именно это чувство неправильности — одна из самых сильных частей её identity.

#### 17\. Темнота как центральная механика: свет \= информация { #17 }




Про DOOM 3 легко сказать «она просто пиздец какая тёмная». Но darkness здесь не только эстетика.




Classic Doom обычно даёт много информации и требует быстро её обработать:




вижу enemies + projectiles + routes → принимаю решение.




DOOM 3 делает противоположное:




слышу threat → ещё не вижу → замечаю shadow → glowing eyes → наконец сам monster.




То есть challenge часто не «как решить ситуацию?», а «что вообще сейчас находится в комнате?»




Flashlight поэтому работает как разведка. В original game он занимает руки:




FLASHLIGHT \= information.




SHOTGUN \= firepower.




Посветил → запомнил положение enemy → достал gun → часть информации снова потерял.




Это почти маленький loop «разведка → память → атака».




Muzzle flash и fireballs тоже временно возвращают видимость. Imp projectile особенно красив: одновременно attack и движущийся источник света, на мгновение проявляющий room.




Lighting ещё и управляет взглядом. Если всё вокруг black, а одна дверь подсвечена — никакая giant objective arrow не нужна. Свет становится языком режиссуры: сюда смотри, это опасно, это важно, здесь что-то есть.




А sound превращается во второе зрение. Growl слева, teleport behind, footsteps, machinery — игрок строит spatial model ушами, потому что eyes намеренно ненадёжны. Поэтому 5.1 для DOOM 3 был не просто маркетинговым украшением.




Но здесь же фундаментальный конфликт:




horror хочет мало информации;




combat mastery хочет много информации.




Darkness создаёт uncertainty, но ухудшает target tracking, navigation и decision density. В хороший момент ты боишься входить в room. В плохой — просто не понимаешь, кто тебя сейчас ударил, и идёшь крутить gamma.




И ещё одна проблема — adaptation. Если темнота занимает редкий эпизод, она сильная. Если почти вся campaign тёмная, мозг быстро принимает это как normal.




То же самое с lights-out scare:




первый раз → БЛЯТЬ.




десятый → сейчас опять spawn.




Поэтому DOOM 3 сама постепенно учит игрока читать horror как videogame pattern.




Тем не менее убрать darkness нельзя без разрушения игры. Сделай всё ярче и дай always-on flashlight — получится удобнее, быстрее и читаемее, но пропадёт огромное количество shadow reveals, sound uncertainty и tension.




Самая точная разница:




Classic Doom → SPACE главная переменная.




DOOM 3 → VISIBILITY главная переменная.




Именно поэтому свет здесь реально является ресурсом информации.

#### 18\. Фонарик: «flashlight или оружие» { #18-flashlight }




Самая знаменитая механика DOOM 3 одновременно очень хорошая horror-идея и главный источник шуток про долбоёба, который в 2145 году не умеет примотать фонарь к shotgun.




Original DOOM 3 заставляет выбирать:




FLASHLIGHT → вижу угрозу.




WEAPON → могу её убить.




Позже Tim Willits объяснял, что корень решения был технический: ещё один постоянно активный dynamic light вместе с gun дорого обходился тогдашнему железу. Но команда не просто смирилась с ограничением — она превратила его в правило.




В результате возникает реальная информационная уязвимость:




посветил → увидел Imp → достал shotgun → свет исчез → стреляешь по памяти и brief muzzle flashes.




Концептуально очень сильная штука.




Но fiction действительно смешная. UAC умеет teleportation и BFG, а flashlight к оружию прикрутить не может. Поэтому Duct Tape Mod появился буквально через считанные дни после релиза. Он добавлял свет к части guns и мгновенно стал чрезвычайно популярным.




И мод менял не только удобство, а психологию:




Original → вижу ИЛИ стреляю.




Duct Tape → вижу И стреляю.




То есть часть tension исчезает.




Главная проблема original flashlight не в нереалистичности. Videogame условности переживут и не такое. Проблема в том, что meaningful choice быстро превращается в процедуру:




flashlight → проверил угол → shotgun → два метра → flashlight → shotgun.




Первые часы это напряжение.




Через десять часов — FONARIK MANAGEMENT.




При этом механика отлично заставляет игрока двигаться в horror-темпе. Не нужно отдельно просить «иди осторожнее»: если несёшься в darkness с gun, сам виноват.




BFG Edition спустя восемь лет официально делает почти то, что когда-то сделал Duct Tape Mod: flashlight становится armor-mounted и работает одновременно с оружием. Чтобы оставить хоть какое-то ограничение, ему дают battery.




Конфликт меняется:




Original → LIGHT vs WEAPON.




BFG → LIGHT NOW vs LIGHT LATER.




Играть удобнее. Но исходная tension model уже другая.




Поэтому вопрос «BFG исправила тупость?» зависит от цели.




Хочешь комфортный shooter — да, стало приятнее.




Хочешь понять, чем была DOOM 3 2004 года, — отдельный flashlight является частью самой идеи игры, а не мелким UI-недостатком.

#### 19\. Monster closets: когда хороший horror-приём становится мемом { #19-monster-closets-horror- }




Monster closet DOOM 3 не придумала. Classic Doom постоянно открывала walls после key, switch или trigger. Разница в функции.




В Doom II trap обычно меняет боевую систему:




новые enemies → новая геометрия боя → другой target priority → infighting → перестройка маршрута.




В DOOM 3 closet гораздо чаще работает как режиссёрский jumpscare:




тишина → pickup → КЛАЦ → стена открылась → Imp.




Engine идеально под это заточен: triggers, map scripts, hidden entities, spawn FX, lighting и sound позволяют дизайнеру очень точно решить, когда, где и на каком расстоянии появится enemy.




Когда scripting уникален, это работает охуенно. Первая встреча с Pinky запоминается, потому что monster сначала ломает дверь, создаёт ожидание, меняет маршрут и только потом врывается внутрь. Ты помнишь событие, а не trigger volume.




Но невозможно двадцать часов строить уникальную сцену для каждого Imp. Поэтому production скатывается в универсальные схемы:




взял item → enemy;




нажал switch → enemy;




убил enemy → второй behind;




прошёл trigger → teleport.




И игрок начинает видеть machinery дизайнера. Не «стена внезапно перестала быть безопасной», а «ага, `trigger_once` вызвал Imp».




Особенно вредно постоянное появление behind. Первые разы ломается чувство безопасности. Потом появляется автоматический рефлекс:




увидел monster впереди → развернулся на 180°.




То есть приём, придуманный ради непредсказуемости, сам делает игру предсказуемее.




Сам monster closet не плохой. Он отлично работает как punctuation mark: иногда нарушить cleared space, подло наказать уверенность, заставить слушать surround.




Проблема в частоте.




Один `!` сильный.




Если весь текст выглядит как `!!!!!!!!!!!!`, эффект исчезает.




К середине DOOM 3 игрок уже не боится стены. Он смотрит на неё и думает:




> ну давай, открывайся уже, я знаю, что там Imp.

#### 20\. Combat DOOM 3: что остаётся, если убрать horror { #20-combat-doom-3-horror }




Если мысленно выключить darkness, monster closets, PDA и весь audiovisual horror, внутри обнаруживается удивительно старомодный shooter.




Marine умеет примерно то же, что старый Doomguy:




move + shoot + jump + crouch + sprint + weapon switch.




Он таскает весь arsenal сразу. Нет classes, skill tree, cover, prone, stealth, recharging shields или сложных tactical systems.




Базовое правило всё ещё:




видишь demon → выбираешь gun → стреляешь, пока demon не умер.




Но classic Doom была глубокой не из-за большого toolkit героя, а из-за сложности ситуации вокруг него:




скорость + открытое пространство + projectile dodging + enemy roles + большие группы + infighting + resource economy.




DOOM 3 сохраняет простого player, но сильно упрощает боевое окружение. Большинство encounters маленькие: один Imp, два Imps, Hell Knight плюс мелочь. Поэтому вопрос чаще:




> как быстро убить ЭТО?




а не:




> в каком порядке разобрать всю систему угроз?




Отсюда гораздо ниже decision density.




Взамен enemies становятся физичнее. Imp прыгает, лезет в melee, занимает экран. Pinky реально давит массой. Hell Knight ощущается огромным существом, а не просто большим HP bar.




Movement всё ещё довольно быстрый, projectiles можно dodge'ить, circle-strafe существует, все пушки стреляют с бедра. То есть ДНК classic Doom внутри есть. Просто levels, darkness и enemy count редко позволяют ей раскрыться на полную.




Когда DOOM 3 даёт больше пространства — особенно Hell — combat сразу оживает. Это хороший индикатор: само ядро не полностью «медленное», его постоянно тормозит presentation и architecture.




И здесь главный trade-off игры становится предельно ясным:




Classic Doom → простые monsters, сложные combinations.




DOOM 3 → сложнее отдельный monster, проще combinations.




Поэтому gunplay сам по себе нормальный, местами очень приятный, но редко достигает той глубины, которую серия уже умела давать десять лет назад.

#### 21\. Movement и ощущение Marine: почему он кажется тяжелее, чем есть { #21-movement-marine }




DOOM 3 часто вспоминают как игру с медленным, тяжёлым героем почти из survival horror. Но технически Marine вовсе не черепаха. Он нормально strafes, бегает, прыгает, crouch'ится и умеет sprint.




Медленным его делает не столько максимальная скорость, сколько весь контекст вокруг.




Classic Doomguy почти не ощущается телом. Нажал направление — получил скорость. Это практически:




ВЕКТОР + SHOTGUN.




DOOM 3 хочет другого:




> я нахожусь ВНУТРИ конкретного человека.




Отсюда camera/weapon bob, stamina, breathing, damage reactions, knockback, кровь на экране и ощущение шага. После удара камера дёргается, aim нарушается, тело слегка сдвигается. Персонаж постоянно напоминает о собственной физичности.




Вторая большая разница — sprint. В classic Doom run очень быстро становится обычным состоянием. В DOOM 3 ускорение — отдельный режим со stamina. Психологически:




Classic Doom → быстро \= NORMAL.




DOOM 3 → быстро \= временно ускорился.




Но главное — level design сам учит не спешить. Corridor → door → dark room → corner → PDA → terminal → ambush. Sprint просто быстрее отправляет тебя лицом в неизвестность.




Поэтому игра технически даёт скорость, но психологически запрещает пользоваться ей постоянно.




Air control тоже слабее Quake/Doom-school ощущения. На земле герой отзывчивый, а в воздухе уже не превращается в старый id-шный снаряд, который корректирует trajectory как хочет.




И очень показательно, что multiplayer ощущается быстрее. Убираем exploration, darkness, PDA и horror pacing — остаются movement + guns + arena, и внезапно видно, что controller сам по себе вовсе не был медленным.




Итог простой:




Marine DOOM 3 тяжелее не потому, что id просто занизила speed.




Его делают тяжёлым:




stamina + body feedback + damage reactions + тесная geometry + darkness + cautious pacing.




Classic Doom старается убрать тело между игроком и управлением.




DOOM 3 специально возвращает тело обратно — потому что обычного человека в тёмной комнате пугать проще, чем абстрактный вектор скорости.

#### 22\. Shotgun DOOM 3: мощный в упор и ебанутая лотерея дальше { #22-shotgun-doom-3 }




Shotgun здесь идеально подходит самой игре:




тесные corridors + enemies в лицо + маленькая дистанция \= сильный close-range burst.




В упор он реально отличный. Zombies, Imps, Wraiths, Cherubs и часть Z-Sec можно снимать одним хорошим выстрелом.




Проблема — огромный spread. Это не ощущение игроков: в данных оружия конус реально очень широкий, а shot состоит из множества pellets. Если попали почти все — damage огромный. Если половина ушла вокруг цели — начинается:




> какого хуя он ещё жив?




То есть shotgun DOOM 3 почти melee weapon.




Очень близко → великолепно.




Средняя дистанция → уже рулетка.




Дальше → возьми Machine Gun.




И это радикально отличается от классического shotgun, который был одним из лучших оружий серии именно из-за предсказуемости и нормальной средней дистанции. Там:




навёлся → выстрелил → примерно знаешь результат.




Здесь:




навёлся → random pellet spread → возможно молодец, возможно Imp всё ещё идёт к тебе.




Отсюда ощущение, что weapon иногда «врёт»: crosshair в центре enemy, но сам cone настолько огромный, что значительная часть pellets не обязана попасть.




При этом внутри level design решение очень логичное. DOOM 3 постоянно бросает enemy в двух-трёх метрах. Monster closet открылся → Imp почти в лицо → shotgun делает БУМ → encounter закончился.




И здесь возникает забавный proto-aggression principle задолго до DOOM 2016:




хочешь использовать shotgun эффективно → иди ближе к опасной твари.




Для horror это почти обратное нормальному инстинкту.




Поэтому я бы не называл shotgun просто плохим. Он очень хорошо заточен под конкретный close-range combat DOOM 3. Но как культовый Doom-shotgun он слишком непредсказуем и слишком узок по дистанции.




Сильный инструмент для этой игры.




Слабее как универсальный weapon language серии.

#### 23\. Арсенал DOOM 3: хороший набор пушек, но роли пересекаются сильнее классики { #23-doom-3 }




По списку оружие почти идеально сохраняет Doom-iconography:




Fists, Pistol, Shotgun, Machine Gun, Chaingun, Grenades, Plasma Gun, Rocket Launcher, BFG 9000, Chainsaw, плюс Flashlight и Soul Cube.




Но структура изменилась.




Classic Doom особенно сильна тем, что gun почти всегда отвечает на конкретный вопрос:




Shotgun → экономичный точный damage.




Chaingun → hitscan control.




Rocket Launcher → splash + высокий DPS + self-risk.




Plasma → sustained damage.




BFG → особая работа с группами.




В DOOM 3 роли сильнее накладываются друг на друга. Выбор часто выглядит так:




> насколько мощную пушку мне сейчас не жалко кормить ammo?




Pistol быстро превращается в «не хочу тратить нормальные патроны».




Machine Gun — удачное новое оружие: точное, удобное на средней дистанции, нормально работает там, где shotgun уже превращается в лотерею.




Chaingun — тяжёлый DPS-tool, уже заметно мощнее и прожорливее.




Plasma Gun становится одним из самых приятных универсальных вариантов против серьёзных demons: быстро, ярко, много projectiles, хороший sustained damage.




Rocket Launcher логично работает в больших spaces, но тесная архитектура DOOM 3 постоянно делает splash опасным самому игроку.




Grenades интересны именно как попытка использовать физику и углы, но игра редко строит encounter так, чтобы они были действительно незаменимы.




Chainsaw сохраняет старый абсурдный Doom-шарм и отлично унижает слабых enemies на близкой дистанции.




BFG — уже настоящее «всё, хватит». К поздней игре она заметно меняет психологию: Hell Knight из scary encounter превращается в цель, на которую у тебя есть тяжёлая кнопка.




И это нормально: arsenal сам постепенно разрушает horror и переводит campaign в более action-heavy состояние.




Главная проблема не в качестве отдельных guns. У большинства есть характер. Проблема в encounter design: игра редко создаёт ситуации, где именно одна конкретная пушка является очевидно лучшим системным ответом.




Поэтому формула DOOM 3 чаще:




POWER vs AMMO AVAILABILITY.




У classic Doom чаще:




TOOL vs SPECIFIC COMBAT PROBLEM.




То есть арсенал хороший. Weapon system — уже менее чистая.

#### 24\. Soul Cube: первая большая combat ability Doom { #24-soul-cube-combat-ability-doom }




Soul Cube важна потому, что это уже не просто очередная gun.




Её loop другой:




убиваешь enemies → заряжаешь способность → активируешь → сильная цель умирает → здоровье возвращается тебе.




После пяти kills Cube говорит:




> Use us.




И готова к одному применению.




Главное: нет отдельного Soul Cube ammo. Боеприпас — сами смерти enemies.




Это огромный концептуальный сдвиг. Обычная Doom economy чаще говорит:




убил врага → потратил resource.




Soul Cube добавляет:




убил врага → заработал progress к следующему мощному действию.




Combat начинает кормить следующий combat.




Cube сама летит к цели, наносит чудовищный damage и возвращает health. То есть одной кнопкой решаются сразу две проблемы:




сильный enemy + низкое здоровье.




Особенно хорошо механика работает с мелочью. Пять Trites или zombies могут быть не угрозой, а буквально батарейкой:




weak enemies → charge → Soul Cube → Hell Knight.




И вот здесь впервые в основной Doom очень явно появляется идея:




ENEMY \= THREAT + RESOURCE.




Поздняя современная серия сделает это центральным законом:




DOOM 2016 → Glory Kills.




Eternal → health + ammo + armor через enemies.




Soul Cube — не прямой прототип всех этих систем, но мысль уже есть: агрессия не только расходует ресурсы, она может восстанавливать игрока.




При этом ability появляется поздно, поэтому не успевает перестроить всю игру вокруг себя. Системная глубина умеренная. Но как identity, progression и resource mechanic — одна из лучших идей DOOM 3.




Ранний Marine:




enemy → опасность.




Поздний Marine:




enemy → ещё и потенциальный health reservoir.




Это маленький, но очень важный шаг от prey mentality к будущему Doom Slayer.

#### 25\. Монстры DOOM 3: от шахматных фигур к физическим существам { #25-doom-3 }




В Doom II monster прежде всего функция:




Chaingunner → hitscan pressure.




Revenant → homing pressure.




Mancubus → area denial.




Pain Elemental → производит новые угрозы.




Arch-vile → resurrection + priority target.




DOOM 3 сознательно меняет приоритет:




DOOM II: ROLE → MONSTER.




DOOM 3: CREATURE → ROLE.




Теперь отдельный demon должен быть достаточно убедительным, чтобы один работать как encounter.




Физически это гигантский шаг. У monsters есть масса, skeleton, сложная animation, normal/specular maps, тени, звук, melee reactions. Imp прыгает и пригибается. Hell Knight реально заполняет room. Mancubus выглядит как огромная биомеханическая туша.




Но системно roster становится беднее.




Очень много creatures работают по общей схеме:




ranged attack + melee + pursuit.




Разница есть в speed, HP, projectile, размере и поведении, но чистых специализированных ролей меньше.




Imp становится универсальным monster: projectile, leap, melee, pursuit, ambush. Это нужно, потому что один Imp должен уметь поддержать сцену.




Pinky удачно сохраняет чистую classic role: melee pressure. Не дай ему подойти.




Hell Knight — главный bruiser/tank и фактически «super Imp»: много HP, projectile и страшный melee.




Arch-vile, Revenant, Mancubus и другие интереснее именно там, где сохраняют узнаваемую функцию.




И вот в этом главный trade-off всей игры:




Classic Doom → простой отдельный monster, сложная группа.




DOOM 3 → сложный отдельный monster, простая группа.




Современная Doom позже попробует соединить обе школы: физически роскошный demon + очень ясная role.




Поэтому DOOM 3 невероятно важна как переход. Она потеряла часть старой механической чистоты, но дала серии современное ощущение демона как реально присутствующего существа.

#### 26\. Imp как лицо DOOM 3 { #26-imp-doom-3 }




Если Hell Knight красуется как большой символ игры, то реальное лицо DOOM 3 — Imp. Именно его ты видишь постоянно.




Внешне от старого Imp осталось немного. Новый — почти чёрная, многоглазая, влажная, хищная тварь с нечеловеческой пластикой.




Но главное — поведение.




Classic Imp в основном:




стоит / идёт → кидает fireball → melee если подошёл.




DOOM 3 Imp умеет:




projectile + leap + melee + быстрый pursuit + ambush behavior.




Он может пригнуться, почти пойти на четвереньках, резко сократить дистанцию и оказаться перед камерой быстрее, чем ожидаешь.




При этом fireball сохранилась — и это очень правильное решение. В новом monster всё ещё мгновенно узнаётся старый gameplay verb:




вижу projectile → dodge.




А dynamic lighting делает сам fireball частью атмосферы: он на секунду освещает walls и самого демона.




Почему Imp встречается везде? Потому что он идеально подходит architecture DOOM 3:




достаточно страшный один;




достаточно слабый, чтобы использовать часто;




умеет нападать близко и издалека;




работает в monster closet, corridor, room и open space.




То есть id успешно решила задачу «сделать одного базового enemy полноценным encounter».




Но именно поэтому игра начинает им злоупотреблять. Сначала:




ОХУЕТЬ, НОВЫЙ IMP.




Потом:




ага, ещё Imp.




Позже:




ну конечно Imp за дверью.




Получается забавный парадокс: один из лучших redesign'ов в игре сам же страдает от того, насколько он удобен дизайнеру.




Механически Imp менее чистая «шахматная фигура» классики, зато гораздо лучше работает как одиночный horror-predator. Для DOOM 3 это практически идеальный базовый enemy.

#### 27\. Возвращение классических демонов: что сохранили, а что переписали { #27 }




id не использовала один рецепт «старый sprite → 3D model». Каждый monster адаптировали по-разному.




Hell Knight получает повышение статуса. Baron вообще исчезает, а Hell Knight становится главным тяжёлым humanoid demon. Механически он всё ещё довольно простой: большой HP, мощный projectile, очень опасный melee. Зато физически — один из главных wow-моментов игры. Это чистая философия DOOM 3:




не новая role, а огромная PRESENCE.




Pinky — почти полный visual redesign при отлично сохранённой функции. Кибернетическое мясное чудовище по-прежнему говорит только одно:




ОН ИДЁТ К ТЕБЕ. НЕ ДАЙ ЕМУ ДОЙТИ.




Именно поэтому Pinky механически чище многих новых creatures.




Revenant — один из самых буквальных переносов. Skeleton + launchers, homing missiles, familiar combat language. Визуально радикально современнее, но функция узнаётся сразу.




Mancubus тоже сохраняет identity: медленный тяжёлый projectile pressure. Его огромная масса и machinery великолепно подходят art direction DOOM 3. Но classic Mancubus интереснее чистотой projectile pattern и взаимодействием с большим пространством.




Cacodemon в тесной игре чувствует себя слабее. Летающий enemy особенно интересен там, где есть большая вертикальная arena, а DOOM 3 редко даёт ему такую свободу.




Arch-vile меняется сильнее. Вместо знаменитого resurrection pressure классики он становится скорее high-tier summoner / direct threat. Узнаваемость есть, но одна из лучших функций Doom II потеряна.




Lost Soul визуально тоже почти новое существо, но старая charge-role читается нормально.




И вот общий вывод:




DOOM 3 великолепно переизобрела отдельного демона.




Гораздо хуже — толпу демонов.




В отдельности roster сильный. Как комбинаторная система Doom II всё ещё заметно богаче.

#### 28\. Новые демоны: horror-roster вместо нового Doom II { #28-horror-roster-doom-ii }




Новые monsters особенно хорошо показывают, что DOOM 3 задаёт уже другой вопрос.




Doom II спрашивала:




> какой combat role нам ещё не хватает?




DOOM 3 часто спрашивает:




> какую мерзость будет неприятно увидеть в луче flashlight?




Отсюда body-horror roster.




Maggot — двухголовое неправильно собранное humanoid creature. Визуально сильный, механически проще: fast melee pressure + leap. Отличный horror monster, умеренно новый gameplay concept.




Wraith интереснее. Он teleport'ами сокращает дистанцию и нарушает обычное чтение пространства. Видишь его далеко → blink → его уже нет → следующий выход почти рядом. Эта механика реально использует central theme игры: uncertainty и darkness.




Trite возвращают количество. Маленькие spider-like enemies позволяют DOOM 3 наконец бросать в игрока swarm без огромной стоимости тяжёлых demons. Они меняют rhythm aim и делают automatic weapons полезнее.




Tick работает похоже как маленькая быстая nuisance-угроза и хорошо сочетается с resource economy Soul Cube, но системно недоразвит.




Cherub — почти pure horror design: человеческий ребёнок + insect/winged anatomy. Механически не революция, зато визуально идеально выражает идею Hell как фабрики неправильной жизни.




То есть новые monsters очень сильны как галерея nightmare-существ и намного менее сильны как расширение combat vocabulary.




Лучшие именно там, где новая форма совпадает с новой функцией:




Wraith → teleport pressure.




Trite → swarm pressure.




Слабее там, где behind body horror скрывается очередной вариант «быстро подбеги и ударь».




Художественно roster отлично сообщает: у Hell вообще нет нормальной биологии.




Механически Doom II по-прежнему задаёт больше уникальных вопросов игроку.

#### 29\. Boss design: Vagary, Guardian, Sabaoth и Cyberdemon { #29-boss-design-vagary-guardian-sabaoth-cyberdemon }




Bosses DOOM 3 великолепно работают как визуальные и сюжетные milestones. Как mastery tests — заметно слабее.




Vagary, пожалуй, самый здоровый бой. Она не отменяет обычный arsenal, но добавляет telekinesis: environment внезапно может стать weapon против игрока. Нужно следить не только за самой тварью, но и за objects, которые она швыряет. Жалко, что эта идея почти не развивается дальше основной игры.




Guardian of Hell уже чистая boss-puzzle. Самого огромного monster напрямую нормально не убиваешь: нужно разбираться с Seekers, ловить окно уязвимости и бить в правильный момент. Визуально великолепно, механически сильно отделено от обычного combat mastery.




Sabaoth интереснее всего сюжетно. Это Sergeant Kelly — человек, который долго давал тебе приказы по radio, — превращённый в огромную cybernetic демоническую машину. Хороший payoff линии персонажа и важный progression gate перед BFG.




Cyberdemon визуально идеален как финальная эскалация: всё, что было до этого, внезапно выглядит маленьким. Но механически финал спорный, потому что обычный arsenal практически теряет смысл: Cyberdemon привязан к Soul Cube mechanic.




И вот здесь особенно видно приоритет DOOM 3:




fiction + spectacle + staging &gt; чистая система.




У classic Cyberdemon вся сила в том, что он играет по обычным правилам. Это просто чудовищно сильный enemy, и ты побеждаешь теми же навыками, которые учил всю игру.




DOOM 3 в финале говорит:




> используй специальный сюжетный инструмент.




Работает как кульминация истории. Слабее как экзамен gunplay.




Зато bosses очень чисто делят campaign:




Vagary → завершение раннего большого этапа.




Guardian → Hell и получение Soul Cube.




Sabaoth → закрытие Kelly arc и путь к BFG.




Cyberdemon → финал.




Поэтому их лучше оценивать как campaign punctuation, а не как лучшие механические encounters игры.

#### 30\. Hell в DOOM 3: почти другая игра внутри игры { #30-hell-doom-3 }




Hell работает так хорошо именно потому, что игра очень долго не даёт его игроку.




После часов:




metal → pipes → labs → terminals → PDA → corridors




тебя наконец выдёргивают из человеческой логики пространства.




Здесь уже не надо объяснять, зачем архитектор построил лестницу, room или bridge. Пространство существует по правилам ада, а designer наконец получает обратно свободу:




GAME SPACE &gt; PLAUSIBLE PLACE.




И внезапно это делает DOOM 3 ближе к classic Doom.




Первый сильный ход — partial inventory reset. Ты приходишь вооружённым до зубов, а Hell заставляет быстро собирать arsenal заново. Это compressed повтор progression: оружия ты уже знаешь, поэтому теперь каждый найденный shotgun или rocket launcher ощущается как возвращение силы.




Второй — flashlight перестаёт доминировать. Hell гораздо чаще освещён fire, lava, glyphs и portals. Darkness остаётся художественной, но реже превращается в «я нихуя не вижу».




Третий — unlimited stamina. Символично: именно в нечеловеческом пространстве игра снимает одно из человеческих ограничений Marine и фактически говорит RUN.




Spaces становятся крупнее, abstract'нее и удобнее для movement. Enemy density растёт. Combat начинает дышать.




Art contrast тоже огромный. После длинной серо-металлической UAC базы:




stone + fire + blood + bone + flesh + impossible architecture




работают почти как смена игры.




Звук меняется вместе с environment: исчезает привычный machinery hum, corporate world окончательно остаётся позади.




Особенно важно, что demons наконец ощущаются дома. На Mars они вторжение в человеческий объект. Здесь Marine — чужой.




А после возвращения из Hell база уже сильнее заражена. Поэтому chapter — не экскурсия, а точка невозврата:




Mars заражается Hell → настоящий Hell → возвращение → граница миров почти разрушена.




Hell — один из лучших участков кампании именно потому, что меняет сразу слишком много привычных переменных:




architecture, stamina, arsenal, lighting, pacing и density боёв.




И заодно показывает: DOOM 3 могла быть разнообразнее. Просто большую часть этого разнообразия она слишком долго держит за серо-металлическими дверями Mars Base.

#### 31\. Delta Labs и поздняя игра: где pacing начинает проседать { #31-delta-labs-pacing }




Сначала важная поправка: Delta Labs находятся и до, и после Hell.




Поздняя цепочка примерно такая:




Monorail → Delta 1 → Delta 2A → Delta 2B → Delta 3 → Delta 4 → Hell → Delta 5 → Central Processing → Server Banks → Site 3 → Caverns → Primary Excavation → финал.




И уже по названиям видно проблему.




Delta концептуально должна быть кульминацией Mars Base: самые секретные labs, matter transfer, biological experiments, portal technology, место, где UAC реально полезла в Hell. Художественная эскалация хорошая:




SCIENCE → UNETHICAL SCIENCE → SCIENCE + HELL → PORTAL → HELL.




Но до результата игра заставляет физически пройти слишком много подразделений.




К этому моменту ты уже знаешь язык UAC наизусть:




lab corridor → office → security room → PDA → storage cabinet → terminal → Imp behind you.




Каждый конкретный segment может быть нормально сделан. Проблема cumulative. Ещё хороший получасовой кусок + ещё один + ещё один \= уже не «много качественного content», а усталость.




Особенно комично работают названия 2A и 2B. Ты дошёл до Delta Sector 2, а игра фактически говорит:




> нет, дружище, теперь 2A. Потом ещё 2B.




И believable-world logic внезапно начинает работать против videogame pacing. У крупного research complex действительно могут быть десятки секторов. Игроку совершенно не обязательно лично проходить каждый.




Classic Doom могла просто телепортировать тебя в новую идею. DOOM 3 хочет физическую continuity через lifts, corridors и departments. Это усиливает world coherence, но делает progression тяжёлым.




К Delta большинство enemies уже знакомы. Новизна ранней игры — новый monster, новый visual, новый horror trick — заметно падает. Arch-vile и серьёзные encounters помогают, но приходят поздно.




Именно поэтому Hell ощущается таким мощным: player уже отчаянно хочет другую игру хотя бы на час.




После Hell финальная часть, наоборот, снова ускоряется: Soul Cube, Sabaoth, BFG, ancient Martians, Caverns, finale. Поэтому DOOM 3 не «разваливается после Hell». Главная pacing-яма — длинный путь К Hell.




Delta Labs как worldbuilding — логично.




Как отдельные levels — в основном хорошо.




Как часть пятнадцатичасовой кампании — слишком много.

#### 32\. Почему DOOM 3 слишком длинная для собственной идеи { #32-doom-3 }




Главная проблема DOOM 3 не в darkness, shotgun или monster closets по отдельности. У каждого решения есть понятная логика.




Проблема глубже:




игра использует ограниченный набор очень сильных идей дольше, чем эти идеи способны оставаться сильными.




Первые часы великолепны именно потому, что player ещё не знает grammar.




Darkness → реально неизвестность.




Flashlight → реальный выбор information vs weapon.




Monster closet → очищенная room внезапно небезопасна.




PDA → труп получает прошлое.




Imp → новая хищная тварь.




Mars Base → каждая секция расширяет реальный объект UAC.




Renderer → почти каждую room хочется рассматривать.




Потом ты всё выучил.




Знаешь, как выглядит UAC.




Знаешь, что хороший pickup может вызвать ambush.




Знаешь, что после enemy впереди надо проверить behind.




Знаешь, что PDA часто содержит code.




Знаешь общий rhythm:




тишина → sound cue → enemy → короткий бой → снова тишина.




А campaign говорит:




> отлично, теперь ещё часов десять этого языка.




И здесь особенно видно: DOOM 3 великолепно умеет ВВОДИТЬ механику и хуже умеет её РАЗВИВАТЬ.




Flashlight почти не получает новых системных правил.




Monster closets редко начинают обманывать выученное ожидание.




PDA всё чаще превращается в routine.




Enemy roster расширяется визуально сильнее, чем комбинационно.




Mars Base долго остаётся вариациями одной industrial эстетики.




Если бы campaign была заметно компактнее, многие спорные решения работали бы лучше. Darkness не успела бы стать нормой. Closet не превратился бы в автоматический 180°. PDA не успела бы так утомить. Techbase не успела бы слиться в один длинный corridor.




Hell показывает идеальный способ решить проблему — резко поменять пространство, lighting, stamina, arsenal и rhythm. Просто игра делает такие сильные shifts слишком редко.




Поэтому вопрос не «надо ли было вырезать половину хороших комнат?». Иногда да. Плотность важнее абсолютного количества content.




DOOM 3 могла быть почти идеальным haunted-house FPS, если бы заканчивала многие свои tricks до того, как игрок начинал видеть за ними trigger volume.

#### 33\. Sound design DOOM 3: звук как второе зрение { #33-sound-design-doom-3 }




Одно из самых правильных решений игры — почти отказаться от постоянного soundtrack.




Музыка есть: знаменитая menu theme, отдельные rhythmic/ambient fragments. Но большую часть campaign эмоциональный режим создаёт сам мир:




ROOM + MACHINERY + DISTANT MONSTER + FOOTSTEPS + RADIO + SILENCE.




Mars Base постоянно гудит, шипит, щёлкает и работает. Ventilation, hydraulics, servers, doors, distant metal — всё это выполняет функцию ambient score.




Самое сильное — граница между neutral sound и threat cue постоянно размыта.




КЛАНГ за стеной.




Это machinery?




Или там кто-то есть?




Именно поэтому отсутствие музыки важно. Если сверху постоянно играет dramatic track, player перестаёт слушать мелкие spatial sounds. Здесь каждый noise потенциально значим.




Darkness уменьшает visual information, а sound часть её возвращает:




VISION ↓




AUDIO ↑




Не вижу Imp, но слышу его слева. Не вижу spawn behind, но слышу teleport cue. 5.1 поэтому реально давал gameplay advantage, а не только «киношную атмосферу».




Radio расширяет disaster за пределы видимой комнаты. Ты слышишь других Marines, panic и постепенно исчезающие voices. PDA, наоборот, возвращают голоса уже погибшим людям.




Отдельно хороши teleport FX и monster vocals: в игре с таким количеством scripted arrivals звук часто предупреждает о threat раньше eyes.




Ирония в том, что при настолько сильном общем soundscape сами guns часто звучат слабее, чем выглядят. Shotgun визуально обещает БУМ, а audio нередко делает довольно скромное «пах». Это критиковали ещё на релизе.




Но как система звук DOOM 3 отличный:




machinery → строит место;




silence → строит ожидание;




monster sound → сообщает threat;




positional audio → направление;




radio → масштаб disaster;




PDA voice → прошлое;




teleport FX → spawn information.




Главная fantasy работает именно так:




ты стоишь в темноте и пытаешься понять, ЧТО ТАМ ЗВУЧИТ.

#### 34\. Trent Reznor и ранний звук DOOM 3 { #34-trent-reznor-doom-3 }




Trent Reznor действительно работал над ранней DOOM 3. Это не фанатская легенда.




Связка выглядела естественно ещё со времён Quake: NIN уже делали музыку и часть sound design для id, а новая Doom строилась вокруг industrial horror, machinery, flesh и darkness.




Причём первоначальная идея была интереснее обычного «известный музыкант пишет OST». Reznor мог заниматься большим куском SOUND DESIGN вообще:




weapons + demons + machinery + impacts + ambient textures + industrial noise.




E3 2002 реально использовала его работу. То есть это дошло до публичной playable/rendered демонстрации, а не осталось в разговорах.




Когда E3 Alpha утекла, часть раннего sound set сохранилась внутри. Поэтому позже возникла легенда про «полный альтернативный Reznor sound design». Это уже преувеличение.




Leaked alpha \= snapshot демонстрационной ветки.




Не \= полностью законченная альтернативная audio production всей кампании.




Тем не менее разница слышна. Ранние weapon sounds многие воспринимают как более грязные, громкие и industrial. Поэтому после retail-релиза community быстро начала собирать sound packs, возвращающие alpha-assets.




Почему Reznor не остался? Полная большая collaboration в итоге не сложилась, и retail game получила другой production setup. Причины в источниках описываются менее чисто, чем сам факт ранней работы, поэтому из истории не надо делать драму уровня «id выгнала Trent и испортила звук».




Правильная формулировка проще:




Reznor реально помог сформировать ранний аудиообраз DOOM 3.




E3 Alpha сохранила часть этой версии.




Retail пошёл другим путём.




Именно поэтому ранний звук так интересен: он показывает альтернативную DOOM 3, где industrial-noise сторона могла быть ещё агрессивнее.

#### 35\. Chris Vrenna, Clint Walsh и финальный аудиоподход { #35-chris-vrenna-clint-walsh }




После ухода Reznor легко построить ложную схему:




Reznor ушёл → Vrenna заменил его как главный композитор.




На деле DOOM 3 вообще не стала традиционно scored game.




Chris Vrenna сам описывал свою работу как `musical sound design`: небольшие музыкальные textures и элементы, которые почти сливаются с environment. Позже он вместе с Clint Walsh работал и над theme.




Важно правильно разделить credits.




Основной sound design финальной игры — Ed Lima и команда.




Additional sound effects делали внешние специалисты.




Chris Vrenna — additional in-game sounds и production главной темы.




Clint Walsh — композитор знаменитой main theme.




То есть menu riff нельзя просто записать «на Vrenna» и тем более «на Reznor».




И сама структура очень умная.




MENU:




тяжёлый industrial-metal riff → «ЭТО DOOM».




GAMEPLAY:




machines + footsteps + air conditioning + distant screams → «теперь заткнись и слушай room».




Theme продаёт бренд и aggression. Campaign продаёт immersion и uncertainty.




Musical sound design позволяет иногда добавлять drone, tonal layer или pulse, не превращая space в обычную сцену с фоновой композицией.




Можно было бы хотеть чуть больше редких motifs для крупных chapters — это помогло бы разнообразию. Но постоянный metal soundtrack разрушил бы значительную часть horror grammar.




Поэтому финальная DOOM 3 делает очень точное заявление:




меню говорит «DOOM».




сама игра почти сразу выключает музыку и заставляет слушать, что находится за стеной.

#### 36\. Art direction DOOM 3: когда technology и art почти невозможно разделить { #36-art-direction-doom-3-technology-art }




DOOM 3 выглядит именно так не потому, что художники сначала придумали полностью готовый style, а Carmack потом написал renderer. И не потому, что engine случайно заставил всё блестеть.




Это взаимный процесс:




technology показывает, что выглядит охуенно → art начинает проектироваться вокруг этого → game design использует art/technology как механику.




Lead Artist — Kenneth Scott, рядом ветераны Adrian Carmack, Kevin Cloud и новая art team.




Главный скачок: demon становится МАТЕРИАЛЬНЫМ объектом.




Classic Doom работает silhouette + color + sprite animation.




DOOM 3 должна показать:




skin, muscle, bone, saliva, metal, scars, wet flesh, mechanical implants.




Normal/specular mapping идеально подходит grotesque surfaces.




Отсюда знаменитый wet/plastic look. Иногда люди, metal и walls выглядят так, будто всё покрыли лаком. Это частично limitation ранней material model: diffuse + normal + specular должны были сделать поверхность визуально «материальной» без современной PBR-системы.




Но art team ещё и сознательно выбирает материалы, которым renderer льстит:




влажная плоть, кровь, greasy metal, plastic, rubber, pipes, stone.




То есть limitation превращается в style.




Hell поэтому стареет особенно хорошо. Stone + flesh + bone + blood под жёстким dynamic light выглядят естественнее, чем человеческая кожа и «реалистичные» лица.




Mars Base тоже строится под renderer: толстые industrial doors, pipes, vents, deep panels, hard lights, darkness между локальными light volumes. Почти каждая surface хочет показать normal map или specular.




Очень важны hard shadows. DOOM 3 часто выглядит почти театрально:




одна лампа → один corpse → giant black negative space → moving silhouette.




Сегодня physically based renderer дал бы мягче и реалистичнее indirect light. DOOM 3 выглядит искусственнее, но зато чрезвычайно узнаваемо.




Именно это делает style настолько цельным:




id Tech 4 + grotesque creature art + industrial Mars + horror design буквально выросли друг из друга.

#### 37\. Полный сюжет DOOM 3: что реально произошло на Марсе { #37-doom-3 }




Если смотреть только cutscenes, сюжет кажется очень простым:




Betruger открыл Hell → всё пошло по пизде → Marine спасает Mars.




Но PDA, Site 3, tablets и линия Swann/Kelly добавляют нормальную структуру.




Задолго до UAC на Марсе существовала развитая цивилизация. Она тоже открыла путь в Hell и почти была уничтожена. Чтобы остановить invasion, множество людей жертвуют жизненной энергией и создают Soul Cube. Один древний Hero использует её против Hell.




Получается зеркало:




ANCIENT HERO + SOUL CUBE → остановил Hell.




Через тысячи лет:




MARINE + SOUL CUBE → должен повторить путь.




Выжившие ancient Martians оставляют ruins, tablets и предупреждения, а затем исчезают/покидают Mars.




Потом приходит UAC.




Археологи находят ancient sites, Soul Cube и следы teleportation technology. Корпорация одновременно получает:




1. невероятную технологию;

2. подробное предупреждение, почему её не надо использовать.





Разумеется, внимание уделяют пункту №1.




Delta Labs reverse-engineer teleportation. Проект возглавляет Malcolm Betruger. Experiments показывают, что путь связан с неизвестным измерением. Людей отправляют туда, возвращаются horror reports, accidents и psychological breakdowns. Нормальная science должна была сказать «стоп».




Betruger говорит «продолжаем».




Постепенно становится ясно, что он уже не просто самоуверенный scientist, а агент Hell. Elizabeth McNeil пытается поднять тревогу перед UAC Board. На Mars отправляют Counselor Swann и bodyguard Jack Campbell, чтобы разобраться.




И вот здесь игра специально сначала делает Swann подозрительным корпоративным чиновником, хотя на деле он один из немногих людей, которые реально пытаются остановить catastrophe.




Marine прибывает одновременно с ними. Sergeant Kelly даёт задания и кажется обычным военным командиром. После invasion его линия постепенно ломается: в итоге он оказывается превращён в Sabaoth.




Betruger использует communications и приближающийся fleet как часть плана расширить catastrophe за пределы Mars. Поэтому objective постоянно меняется: то нужно отправить сообщение, то остановить transmission, то пробиться к Delta.




В Delta игрок доходит до самого источника invasion, затем попадает в Hell и получает Soul Cube. После возвращения проходит Sabaoth, Site 3, ancient history, Caverns и Primary Excavation.




Финал возвращает Marine к древнему Hell Hole. Soul Cube уничтожает Cyberdemon и закрывает портал.




Но Betruger не получает нормальной расплаты. Последняя сцена показывает его уже связанным с Maledict — крылатой демонической формой. Крючок для Resurrection of Evil оставлен сознательно.




Сюжет хорош не сложностью, а сцепкой с route кампании. Почти каждый крупный objective объяснён fiction:




Communications → fleet.




Delta → источник disaster.




Hell → Soul Cube.




Caverns → ancient sites.




Cube → Cyberdemon.




И в основе лежит идеально Doom-овская мысль:




человечество откопало древнее предупреждение о том, как открыть Hell, и первым делом превратило его в техническую документацию.

#### 38\. Почему сюжет стал намного важнее, но всё ещё обслуживает gameplay { #38-gameplay }




В Doom 1993 story можно почти вынести за скобки. Прочитал текст → пошёл стрелять.




В DOOM 3 narrative уже определяет сам маршрут:




Mars City → invasion → Bravo → Communications → Delta → Hell → Soul Cube → Caverns → Cyberdemon.




Но id всё ещё воспринимает story не как отдельную «литературу», а как один из инструментов pacing вместе со sound, light, ammo и monsters.




Игра очевидно существует в мире после Half-Life. Не нужно говорить «id скопировала Half-Life» — прямого такого признания нет. Но grammar эпохи одна:




сначала дай игроку пожить в normal facility → потом разрушь его прямо перед глазами.




Самое важное — catastrophe происходит ПЕРЕД игроком. Ты видел живых Kelly, Swann, Campbell, scientists и workers. Потом видишь, что с этим миром сделал Hell.




Silent protagonist тоже выбран сознательно. Marine почти не говорит, потому что должен оставаться PLAYER ≈ PROTAGONIST, а не отдельным разговорчивым character.




При этом DOOM 3 менее последовательна, чем Half-Life: иногда камера выходит в third-person cinematics и буквально показывает героя со стороны.




Лучшие scripted scenes — те, где control остаётся у player. Pinky ломает дверь, Imp пробегает за glass, monster появляется в пространстве, а ты сам решаешь, куда смотреть. Это сильнее обычной cutscene именно потому, что событие случается с тобой.




Но игра любит и monster-introduction cinematics. Они обслуживают новую philosophy: demon настолько важный физический объект, что его надо отдельно «продать» игроку.




Story распределена по слоям:




обязательное → cinematics, radio, objectives;




environmental → bodies, rooms, corruption;




optional → PDA, mail, audio logs.




И иногда баланс ломается. PDA тормозит flow, Betruger говорит слишком часто, часть objectives ощущается корпоративной бюрократией.




Но сама идея правильная: Doomguy не превращают в драматического героя. Драматическим становится мир вокруг него.




Doom 1993 story объясняет, почему ты стреляешь.




DOOM 3 story объясняет, куда ты идёшь, что видишь и почему следующий fight вообще имеет значение.




А когда дверь открывается — story всё ещё умеет заткнуться:




у тебя shotgun;




там demon.

#### 39\. Финал DOOM 3 и Cyberdemon { #39-doom-3-cyberdemon }




Финал красиво возвращает игру к самому источнику catastrophe — Primary Excavation Site и ancient Hell Hole.




UAC начинала с раскопок древней цивилизации, её технологии и предупреждений. Marine заканчивает кампанию там же, закрывая последний проход в Hell.




Структура очень чистая:




DISCOVERY → EXPLOITATION → CATASTROPHE → RETURN → CLOSURE.




Cyberdemon здесь получает больше mythology, чем в classic Doom. Soul Cube заранее предупреждает о величайшем warrior Hell, против которого обычного arsenal недостаточно. То есть boss строится не просто как fan-service «смотрите, Cyberdemon», а как причина существования ancient weapon.




Визуально escalation работает отлично. После Hell Knights, Guardian и Sabaoth Cyberdemon всё равно ощущается огромнее всего.




Механически — слабее. Мы уже разобрали проблему: весь arsenal, который player собирал много часов, в финальном решении заметно теряет значение. Главная задача — переживать arena и снова заряжать Soul Cube.




Зато сюжетно Cube завершает собственную дугу. Ancient Martians создали её, чтобы остановить Hell. Ты повторяешь древний цикл, Cube уничтожает Cyberdemon и затем закрывает Hell Hole.




Marine выживает. Спасательная команда находит его. Mars disaster локально закончена.




Но главный злодей не закрыт.




Betruger всю игру разговаривал с тобой, саботировал людей и фактически организовал catastrophe. И вместо нормального «вот он, убей суку» последняя сцена показывает Maledict / Betruger и говорит:




> продолжение будет.




Поэтому финал хорошо закрывает ВОЙНУ, но не закрывает АВТОРА войны.




Story payoff сильный.




Visual payoff сильный.




Mechanical payoff средний.




Character payoff намеренно оставлен с крючком на Resurrection of Evil.

#### 40\. Что DOOM 3 действительно делает правильно { #40-doom-3 }




После всей критики легко решить, что DOOM 3 интересна только как старый technological artifact. Нет.




Её главный настоящий успех — COHERENCE.




Lighting + sound + architecture + monsters + interfaces + scripting + story говорят на одном языке:




> ты находишься в физическом месте, которое заражает Hell.




Первое: technology реально становится game design. Dynamic light рождает darkness, darkness рождает flashlight, flashlight рождает information trade-off, shadows становятся staging tool. Движок влияет на то, во что ты играешь, а не просто делает screenshots красивее.




Второе: Mars Base действительно ощущается местом. Reception, maintenance, communications, recycling, monorail, labs, server infrastructure — это не просто названия maps. У объекта есть функциональная identity.




Третье: opening отлично создаёт normality до catastrophe. Ты видел людей и нормальный свет, поэтому после invasion знакомая room с corpse работает сильнее, чем абстрактная horror-decoration.




Четвёртое: interactive world-space GUI до сих пор отличная идея. Screen выглядит как устройство и реально является устройством. Ты кликаешь конкретную кнопку внутри мира вместо выпадения в отдельный menu.




Пятое: monster physical presence. Даже когда enemy roles беднее Doom II, сам Hell Knight ощущается реальным огромным существом рядом с тобой. В 2004 это было огромным достижением, и художественно оно работает до сих пор.




Шестое: sensory design. Light и sound одновременно atmosphere и gameplay information. Fireball освещает room. Growl сообщает направление. Shadow выдаёт monster раньше модели.




Седьмое: environmental storytelling. UAC существует через terminals, mail, corporate videos, bodies и machinery, а не только exposition cutscene.




И восьмое: DOOM 3 великолепно ставит маленькие сцены. Иногда достаточно:




одна дверь + одна лампа + один sound + один Imp.




Если всё поставлено правильно, эпизод запоминается.




Главный недостаток — ровно обратная сторона этой силы. Игра отлично режиссирует одну комнату и хуже управляет пятнадцатью часами таких комнат.




Но как союз technology и художественной идеи DOOM 3, возможно, самая цельная игра серии.




У неё весь engine буквально говорит:




> НЕ СМОТРИ В ТЁМНЫЙ УГОЛ.




И ты, конечно, смотришь.

#### 41\. Что в DOOM 3 состарилось хуже всего { #41-doom-3 }




Здесь важно не списать всё на возраст. Многие вещи, которые сегодня раздражают, раздражали людей уже в 2004-м.




Я бы делил так:




было проблемой сразу → design problem;




было wow в 2004, сейчас слабее → aging;




выглядело old-school уже тогда, но работает → identity.




Repetition — точно не aging. Уже релизные reviews ругали linear levels, predictable ambushes, darkness и повторяющуюся середину. Monster closet тоже не «устарел спустя двадцать лет» — игра сама быстро учила распознавать этот script.




Сегодня это чувствуется ещё сильнее, потому что horror games получили roaming AI, dynamic threats, fake cues и более системную uncertainty. На их фоне:




trigger → panel opens → enemy spawns




слишком быстро выдаёт machinery.




Flashlight controversy тоже существовала сразу. Duct Tape Mod появился буквально через дни после релиза. Но сама abstract-механика всё ещё сильная:




хочу видеть → теряю weapon readiness.




Плохо работает скорее world logic: цивилизация с teleportation почему-то не умеет weapon light.




Weapon feel критиковали сразу. Большой arsenal, но роли часто пересекаются, sounds у части guns слабые, shotgun непредсказуем. После современных FPS — особенно после DOOM 2016/Eternal — это просто стало ещё заметнее.




AI тоже никогда не была главной силой игры. Большинство enemies действует довольно прямолинейно и предсказуемо. Сегодня особенно заметно, насколько мало systemic behavior между monsters и environment.




А вот human rendering реально состарился технологически. В 2004 лица и normal-mapped characters были чудом. Сегодня human skin, facial animation и early shader look моментально выдают эпоху.




При этом несколько вещей состарились прекрасно:




lighting composition;




monster art;




world-space GUI;




soundscape;




responsive basic controls;




общая art identity.




Поэтому фраза «DOOM 3 плохо состарилась» слишком простая.




Правильнее:




она состарилась НЕРАВНОМЕРНО.




И самое смешное — общий спор почти не изменился с 2004 года:




БЛЯТЬ, КАК ЭТО ВЫГЛЯДИТ.




+




БЛЯТЬ, ОПЯТЬ IMP ИЗ ШКАФА.




Технологический wow ушёл. Сильная художественная идентичность и старые design-проблемы остались.

#### 42\. DOOM 3 как horror отдельно от вопроса «хороший ли это Doom?» { #42-doom-3-horror-doom }




Если убрать с коробки слово DOOM, оценка игры заметно меняется.




Тогда вопрос уже не «почему Doomguy медленно ходит по тёмным corridors?», а:




> насколько хорош sci-fi horror FPS про вооружённого человека внутри огромного industrial facility, которое постепенно захватывает Hell?




И здесь DOOM 3 выглядит гораздо увереннее.




Самая точная жанровая формула:




HAUNTED-HOUSE FPS.




Это не Resident Evil. Player не беспомощный, ammo не превращено в постоянную existential economy, monster почти всегда можно убить. Уязвимость другая:




ты вооружён, но не информирован.




Страх строится не столько на psychological uncertainty, сколько на spatial uncertainty:




слышу → не вижу → свет → увидел → достал gun → снова частично потерял информацию.




System Shock 2 глубже как systemic horror: resources, builds, SHODAN, возвращающиеся threats, interconnected ship.




AvP сильнее как predator horror: Alien реально давит поведением и motion tracker превращает distance в страх.




F.E.A.R. через год покажет, что horror можно соединить с намного более сильным FPS combat, не ослабляя gunplay.




Dead Space позже лучше свяжет body horror с mechanics: monster anatomy реально определяет, как стрелять.




Но у DOOM 3 есть своя территория:




ФИЗИЧЕСКОЕ ПРИСУТСТВИЕ HORROR-ПРОСТРАНСТВА.




Одна room + один local light + один sound + один physical demon — и игра умеет сделать законченную horror-сцену.




Очень важно и то, что threat почти всегда реальна. Страшный sound часто означает не декоративную hallucination, а Hell Knight, который реально снесёт health. Horror cue и gameplay threat совпадают.




Главная проблема — слишком маленький vocabulary:




DARKNESS + NOISE + SCRIPTED ARRIVAL + MONSTER.




Игра слишком часто подтверждает paranoia. Думаешь «за pickup сейчас кто-то появится?» — да, появился. Player быстро выучивает horror.




Поэтому как великий horror вообще DOOM 3 ограничена. Но как sensory/spatial haunted-house shooter — почти уникальна.




Именно здесь особенно сильна идея:




INFORMATION \= RESOURCE.




Light даёт information.




Sound даёт information.




Shadow даёт information.




Fireball внезапно даёт information.




Flashlight улучшает information, но original version ухудшает боевую готовность.




Жаль, что игра не развивает это дальше через enemies, реагирующих на light, fake sounds, roaming threats и более systemic uncertainty.




Но если убрать Doom-logo, остаётся очень хороший sci-fi horror FPS со своей чистой identity. И, возможно, часть старой критики сразу исчезает, потому что больше не надо отвечать на вопрос «почему это не Doom II».

#### 43\. «Неправильный Doom» или полноценная альтернативная ветвь серии? { #43-doom }




Вот теперь можно закрыть главный спор.




Фраза «DOOM 3 — неправильный Doom» слишком простая.




Фраза «DOOM 3 — абсолютно нормальный Doom, фанаты просто не поняли» — тоже.




Всё зависит от того, что считать сущностью Doom.




Если Doom \= конкретная механическая формула Doom II:




speed + player initiative + large encounters + clear enemy roles + combat geometry + emergent chaos,




то DOOM 3 реально очень далеко ушла от серии.




Она потеряла:




скорость как фундамент;




массовые encounters;




combat chess;




сложную роль geometry;




высокую readability;




часть replayability через emergent combinations.




Это серьёзные потери, а не «фанаты придираются к flashlight».




Но если Doom определить шире, очень многое сохранилось.




Один Marine.




UAC.




Mars.




Hell.




Demons.




Полный arsenal без two-weapon limit.




Health/ammo как world resources.




Прямой shooter core.




И самое главное — player всё ещё решает проблему насилием.




DOOM 3 никогда не превращает героя в helpless horror protagonist. До контакта ты осторожен. После контакта:




вижу Imp → SHOTGUN.




То есть mental state меняется, но власть игрока над threat остаётся очень Doom-like.




Мне нравится рассматривать серию как две концептуальные ветки одной исходной игры:




DOOM 1993 / II




→ ACTION / SPEED → 2016 / Eternal.




→ HORROR / ATMOSPHERE → Doom 64 → DOOM 3.




Это не буквальная production genealogy, а способ понять выборы.




Doom 64 уже доказала, что серия может быть мрачнее, медленнее по настроению и сильнее опираться на ambient horror, сохраняя classic mechanics.




DOOM 3 идёт дальше: horror начинает менять САМ COMBAT.




Меньше enemies, потому что один должен быть страшным.




Меньше arenas, потому что тесная room страшнее.




Flashlight, потому что information должна иметь цену.




Более медленный progression, потому что нужен anticipation.




Вот где происходит настоящий разрыв.




При этом игра сохраняет прекрасную идиотскую смесь science fiction и Satan:




SPACE MARINE + SHOTGUN + COMPUTERS + PENTAGRAM + DEMON.




Hell не оказывается «на самом деле alien planet». Это буквально Hell.




И DOOM 3 остаётся удивительно old-school внутри: doors, access, pickups, весь arsenal, прямое уничтожение enemies.




Поэтому её парадокс в том, что одни критиковали игру за слишком сильный отход от Doom, а другие — за слишком старый shooter под новой графикой. И оба лагеря видели реальную часть картины.




Самая точная формулировка для меня:




DOOM 3 — альтернативная эволюция Doom, которая оказалась тупиковой как главная gameplay-ветка, но очень важной как художественно-технологическая ветвь.




Mainline серия позже вернёт speed, aggression и combat geometry.




Но DOOM 3 дала ей modern physical demons, UAC как реальный мир, materiality, biomechanical horror и идею Doom как не просто ruleset, а полноценного физического universe.




Classic Doom спрашивает:




> если один Marine встретит Hell, насколько быстро он сможет его уничтожать?




DOOM 3 спрашивает:




> если один Marine реально окажется ночью внутри базы, которую захватил Hell, каково ему будет открыть следующую дверь?




Оба вопроса — вполне Doom.




Просто ответы совершенно разные.
