# Quake { #quake }




### Quake: полная история франшизы, технологий и влияния (1990–2026) { #quake-19902026 }




**Дата актуальности: 14 сентября 2026 года.**




> Большая связная история Quake: не только список релизов, а попытка объяснить, почему каждая следующая стадия вообще возникла, какие проблемы решала id Software, что менялось в самой игре, как Quake влиял на железо, интернет, моддинг и соседние жанры — и почему к 2026 году под одним названием фактически существуют три разных Quake.




---




### Как читать эту историю { #_1 }




У Quake нет такой чистой линии, как у Doom. Если смотреть только на номерные части, серия кажется почти шизофренической: первая игра — готический eldritch-horror про Slipgates и Shub-Niggurath; вторая внезапно выбрасывает эту вселенную и рассказывает военную sci-fi историю про Strogg; третья почти полностью отказывается от сюжета и превращается в чистый arena FPS; четвёртая снова возвращается к Strogg; потом серия уходит в Quake Live и Champions, а в 2020-х внезапно начинает получать новые кампании для самой первой игры 1996 года.




Поэтому правильнее рассматривать Quake сразу в нескольких плоскостях:




```
Quake как игры
        │
        ├─ Ranger / eldritch Quake
        ├─ Strogg saga
        └─ Arena / competitive Quake

Quake как технология
        │
        ├─ настоящий 3D
        ├─ client/server networking
        ├─ software → hardware rendering
        ├─ QuakeC / modding
        └─ Quake engine → GoldSrc / id Tech / IW lineage

Quake как культура
        │
        ├─ QuakeWorld
        ├─ esports
        ├─ Team Fortress
        ├─ CTF / Rocket Arena / CPMA / DeFRaG
        ├─ speedrunning / machinima
        └─ QuakeCon
```




Именно в совокупности становится понятно, почему влияние Quake намного больше самой серии.

## I. 1990–1995 — Quake ещё до Quake { #i-19901995-quake-quake }




### 1990–1991 — Quake: The Fight for Justice { #19901991-quake-the-fight-for-justice }




Само слово **Quake** появляется у id Software ещё до Doom. В ранних материалах эпохи Commander Keen компания дразнит будущей игрой **Quake: The Fight for Justice**. Причём Quake тогда — не название мира и не кодовое имя инопланетной угрозы. Это имя конкретного героя из Dungeons &amp; Dragons-кампаний, в которые играли сотрудники id.




Тот Quake был сверхмощным fantasy-воином. В описаниях фигурировали Hammer of Thunderbolts, Ring of Regeneration и другие магические артефакты. Замысел был ближе к сложной action-RPG/fantasy-игре, чем к шутеру. В 1991 году id действительно начала пробовать проект, но очень быстро поняла, что тогдашнее железо и собственная технология не позволяют сделать игру такой, какой её представляли. Через несколько недель работу отложили.




Это кажется мелкой археологической деталью, но она объясняет главное противоречие будущего Quake. Когда название вернётся после Doom II, Джон Ромеро всё ещё будет мыслить Quake как необычную fantasy-игру, тогда как Джон Кармак будет прежде всего строить технологию, способную произвести следующий скачок после Doom.




### 1994–1995 — возвращение идеи { #19941995 }




После Doom II id решает, что пришло время наконец реализовать Quake. Первоначальный проект снова очень далёк от того, что выйдет летом 1996 года.




В нём планируются:




- fantasy/medieval-мир;

- огромный молот как одно из центральных оружий героя;

- melee значительно важнее, чем в Doom;

- RPG-подобное развитие;

- магические предметы;

- более сложная структура приключения;

- сильная зависимость от новых возможностей настоящего 3D.





Художественное направление тоже плавает. Команда успевает поработать с quasi-Aztec эстетикой, затем уходит в тёмное средневековье. Проблема в том, что параллельно Кармак пишет принципиально новый движок, а такой переход съедает колоссальный объём разработки.




Doom мог создавать ощущение 3D-мира с помощью 2.5D-системы: стены вертикальные, уровни не допускают настоящих комнат над комнатами, враги и предметы — спрайты. Quake должен быть другим: реальные трёхмерные координаты, полигональные враги, взгляд вверх/вниз, наклонные поверхности, сложная вертикальная геометрия.




Именно поэтому разработка превращается в конфликт между «какую игру мы хотим сделать?» и «какую игру реально можно закончить на этом революционном движке?». К концу 1995 года команда устала, дизайн всё ещё нестабилен, а технологическая часть уже существует. id принимает решение, которое фактически убивает первоначальный проект: RPG/fantasy-системы режутся, а Quake превращается в быстрый FPS по более знакомой для студии формуле.




Это решение помогает закончить игру, но раскол внутри id становится необратимым. После релиза Ромеро покинет компанию.




Так первый великий парадокс Quake возникает ещё до выхода: **одна из самых влиятельных игр в истории родилась из фактической отмены гораздо более амбициозной игры с тем же названием**.

## II. 1996 — рождение настоящего Quake { #ii-1996-quake }




### 24 февраля — QTest { #24-qtest }




За четыре месяца до полноценного релиза id выкладывает **QTest** — публичный deathmatch/technology test. В документации компания отдельно подчёркивает: это не обычная демоверсия и не alpha, предназначенная для оценки контента. Задача — испытать технологию на реальных компьютерах и сетях пользователей.




Проверяются:




- networking;

- видео;

- звук;

- производительность;

- консоль;

- multiplayer;

- совместимость с реальным железом.





С сегодняшней точки зрения это выглядит как public technical test. Для id такой подход станет традицией: затем будут Quake II Test и длинная линия Q3Test. Компания строит не только игру, но и новый engine, поэтому тысячи пользовательских конфигураций превращаются в бесплатную тестовую лабораторию.




### 22 июня — Quake { #22-quake }




Выходит **Quake**.




Самое простое описание звучит как «первый полностью трёхмерный id-шутер», но этого недостаточно. Quake одновременно перестраивает почти все технические основы FPS.




#### Настоящий трёхмерный мир { #_3 }




Doom создавал невероятно убедительную иллюзию пространства, но его мир подчинялся ограничениям 2.5D. Quake делает всё иначе.




Теперь:




```
x, y, z — реальные координаты
```




Возможны:




- комнаты над комнатами;

- мосты;

- вертикальные шахты;

- наклонные и произвольные поверхности;

- полноценный взгляд вверх и вниз;

- полигональные враги и предметы.





Это не просто «графика стала объёмнее». Меняется сам язык level design. Пространство наконец может быть действительно трёхмерным.




#### BSP, PVS и lightmaps { #bsp-pvs-lightmaps }




Полный 3D-мир значительно тяжелее рисовать. Quake использует BSP-структуру для разделения пространства и PVS — Potentially Visible Set — чтобы заранее понимать, какие области вообще могут быть видимы из текущей точки. Освещение в основном рассчитывается заранее и хранится в lightmaps.




Получается важная архитектура:




```
карта
↓
offline compile
↓
BSP + visibility + lightmaps
↓
runtime работает уже с подготовленными данными
```




Именно такой подход станет фундаментом нескольких следующих поколений движков id и множества лицензированных потомков.




#### QuakeC { #quakec }




Ещё одно решение, значение которого невозможно переоценить: игровая логика отделена от ядра движка и написана на специальном языке **QuakeC**.




Движок отвечает за:




- renderer;

- сеть;

- звук;

- filesystem;

- collision;

- базовую инфраструктуру.





QuakeC отвечает за:




- монстров;

- оружие;

- предметы;

- triggers;

- правила матча;

- поведение игровых сущностей.





Поэтому моддеру не нужно переписывать renderer, чтобы сделать новый режим или новый класс персонажа. Именно отсюда через считанные месяцы вырастут Team Fortress, Threewave CTF и десятки других экспериментов.




#### Client/server даже в single-player { #clientserver-single-player }




Quake также вводит чистую client/server-модель. Даже одиночная игра концептуально работает как сервер с одним локальным клиентом. Это архитектурно сложнее старых подходов, зато multiplayer перестаёт быть надстройкой над single-player и становится частью самого фундамента движка.




Позже QuakeWorld покажет, что первоначальная реализация была слишком оптимистична для dial-up-интернета, но сама идея окажется абсолютно правильной.

### Каким Quake оказался как игра { #quake_1 }




Технология революционная, но сама игра — очень странная смесь нескольких отменённых концепций и спринта к релизу.




Начинается всё как sci-fi:




```
секретная военная база
↓
Slipgate experiments
↓
чужое вторжение
```




Через несколько уровней Quake превращается в:




```
готические замки
руны
рыцари
огры
демоны
лавовые пещеры
древние сущности
```




Военные эксперименты со Slipgate открыли путь в иные измерения. Неизвестную силу командование условно называет **Quake**. Герой — позднее закреплённый как **Ranger** — остаётся практически единственным выжившим и проходит через четыре dimension-эпизода:




1. Dimension of the Doomed;

2. Realm of Black Magic;

3. Netherworld;

4. The Elder World.





Он собирает четыре руны и получает доступ к Shub-Niggurath.




Эстетика кажется несобранной: военные базы соседствуют со средневековыми крепостями, sci-fi technology — с магией и лавкрафтовскими именами. Но именно эта «неправильность» спустя десятилетия станет самым узнаваемым лицом Quake I. Это мир, который невозможно аккуратно классифицировать как sci-fi или fantasy.




#### Trent Reznor и звук { #trent-reznor }




Музыка Nine Inch Nails / Trent Reznor играет огромную роль в ощущении первого Quake. Это не традиционный бодрый soundtrack для shooter, а почти звуковая среда: drone, industrial noise, редкие музыкальные структуры, ощущение огромного пустого пространства.




Из-за CD Audio устройство саундтрека потом станет проблемой цифровых переизданий: без оригинального диска многие версии Quake годами запускались вообще без музыки. Только современное официальное переиздание наконец возвращает soundtrack как нормальную часть продукта.

### Shareware: Doom-модель уже в интернетную эпоху { #shareware-doom- }




Quake продолжает знаменитую shareware-модель id, но интернет играет значительно большую роль, чем в раннюю эпоху Doom.




22 июня появляется shareware-релиз: первый эпизод можно свободно скачать. Архив для 1996 года огромный — около девяти мегабайт — поэтому id делает ещё и вариант, разбитый на **семь архивов**, каждый из которых помещается на 1,44-МБ дискету.




Получается прекрасный снимок переходной эпохи:




```
FTP mirror
и одновременно
«вот тебе семь дискет, отнеси другу без интернета»
```




Но важнее сама модель жизни игры после релиза. Через интернет постоянно идут:




- патчи;

- QuakeC-код;

- Linux-бинарники;

- dedicated servers;

- карты;

- моды;

- VQuake;

- GLQuake;

- WinQuake;

- QuakeWorld.





Quake — уже не просто коробка, которую человек купил и закончил. Это **постоянно меняющийся программный продукт**, вокруг которого интернет становится основной инфраструктурой.

### Linux — через несколько недель после релиза { #linux }




Уже 5 июля появляется Linux/X11-версия Quake. Позже будут SVGAlib и OpenGL-варианты. Это начало долгой традиции id относиться к Unix/Linux серьёзнее большинства игровых компаний эпохи.




Для будущего Quake это особенно важно из-за dedicated servers. Linux станет естественной платформой для сетевой инфраструктуры Quake II, Quake III и огромного количества общественных серверов.

### Август — первый QuakeCon { #quakecon }




QuakeCon начинается не как огромная корпоративная конференция. Люди из IRC `#quake` решают встретиться, привозят свои компьютеры и CRT-мониторы в небольшой техасский отель и строят LAN.




В конце к ним приезжают сотрудники id, включая Кармака. Из маленькой фанатской встречи постепенно вырастает ежегодный институт id-культуры:




- BYOC — Bring Your Own Computer;

- огромные LAN;

- турниры;

- выступления Кармака;

- анонсы движков и игр;

- встреча моддеров, разработчиков и игроков.





QuakeCon переживёт смену поколений, покупку id компанией ZeniMax, эпоху Bethesda и к 2026 году отпразднует тридцатилетие.

## III. 1996 — Quake перестаёт принадлежать только id { #iii-1996-quake-id }




Одна из причин, почему Quake так важен, — скорость, с которой community начинает строить поверх него собственные игры. Большинство великих модов появляются не через пять лет после релиза, а буквально через месяцы.




### Team Fortress — меняем самого игрока { #team-fortress }




В августе 1996 года Robin Walker, John Cook и Ian Caughley выпускают первую публичную версию **Team Fortress**.




Главное новшество — разрушение симметрии Quake.




Обычный deathmatch предполагает:




```
Player A = Player B
различие только в skill и подобранных предметах
```




Team Fortress говорит:




```
Scout ≠ Soldier ≠ Medic ≠ Engineer ≠ Spy
```




Классы получают разные скорости, здоровье, броню, оружие, гранаты и специальные способности. Со временем формируется знаменитая девятка:




- Scout;

- Sniper;

- Soldier;

- Demoman;

- Medic;

- Heavy Weapons Guy;

- Pyro;

- Spy;

- Engineer.





Поразительно, насколько много будущего TF2 уже есть внутри Quake-мода:




- Spy маскируется и делает backstab;

- Engineer строит и улучшает sentry и dispenser;

- Heavy раскручивает тяжёлое оружие;

- Demoman ставит удалённо взрываемые pipebombs;

- Medic лечит и умеет overheal;

- Sniper заряжает более мощный выстрел ценой мобильности.





Team Fortress показывает новый принцип multiplayer FPS: **игрок может быть полезен не только потому, что лучше всех стреляет**. Появляется specialized mastery — хороший Medic, Engineer или Spy играет в другую игру, чем Sniper.




Именно отсюда идёт линия:




```
Quake Team Fortress
↓
Team Fortress Classic
↓
Team Fortress 2
↓
современный class / hero shooter
```




Авторы мода позже окажутся в Valve. Это станет типичной историей индустрии: Quake-мод работает одновременно как игра, экспериментальная лаборатория и портфолио будущего разработчика.




---




### Threewave CTF — меняем цель матча { #threewave-ctf }




Осенью 1996 David «Zoid» Kirsch выпускает **Threewave Capture the Flag**.




Team Fortress меняет способности игрока. Threewave делает другое: меняет саму структуру победы.




Было:




```
увидел противника
↓
убил
↓
+1 frag
```




Стало:




```
две базы
два флага
атака / защита / возврат / escort
```




Этого оказывается достаточно, чтобы автоматически возникли роли даже без классов:




- defense;

- offense;

- flag carrier;

- escort;

- midfield control.





Особенно важен grappling hook. Он полностью меняет геометрию карты: поверхность перестаёт быть только препятствием и становится точкой зацепа. Хорошие игроки используют hook как ускоритель, превращая CTF в высокоскоростную игру маршрутов.




Threewave популяризует ту форму CTF, которая затем станет стандартной для огромного количества FPS. Автор Zoid позже будет работать с id, а CTF станет официальной частью Quake II и Quake III.




---




### Diary of a Camper — Quake становится кинокамерой { #diary-of-a-camper-quake }




26 октября 1996 клан The Rangers выпускает короткий Quake-фильм **Diary of a Camper**. Это уже не просто demo матча, а постановочная история: игроки выступают актёрами, карта — декорацией, чат — диалогом, а demo system — системой записи.




Отсюда растёт ранняя культура **Quake Movies**, позднее получившая название machinima.




Quake неожиданно становится не только игрой и движком, но ещё и real-time инструментом для съёмки кино.




---




### Reaper Bot — Quake как кадровый лифт для Unreal { #reaper-bot-quake-unreal }




Осенью 1996 Steven Polge выпускает **Reaper Bot** — одного из первых действительно впечатляющих deathmatch-ботов Quake.




Он интересен не только умением стрелять. Reaper пытается ориентироваться в произвольной карте, искать предметы, пользоваться лифтами, дверями и телепортами, строить представление пространства.




Epic Games видит работу Polge и нанимает его заниматься AI для Unreal. Позднее его опыт станет особенно заметен в Unreal Tournament, знаменитом качественными офлайн-ботами.




Получается ещё одна типичная Quake-ветка:




```
Quake mod
↓
талантливый автор
↓
крупная студия
↓
другая великая FPS-серия
```

## IV. 1996–1997 — один Quake проживает всю революцию PC-графики { #iv-19961997-quake-pc- }




Первый Quake уникален тем, что вышел в старом мире PC-графики, а затем прямо во время своей коммерческой жизни мутировал в новую модель игрового компьютера.




### `quake.exe` — software rendering { #quakeexe-software-rendering }




Оригинальный DOS Quake — **software-rendered** игра.




Это не означает, что видеокарты нет. Она есть, но в основном показывает уже готовый framebuffer. Большую часть 3D-работы делает CPU:




```
Pentium
↓
геометрия
↓
texture mapping
↓
lighting
↓
rasterization
↓
готовые pixels
↓
видеокарта выводит изображение
```




Поэтому главным игровым компонентом считается процессор. Quake особенно хорошо работает на Pentium благодаря сильному FPU. Кармак и Майкл Абраш доводят software renderer до невероятной эффективности: BSP/PVS, span rendering, surface cache, x86 assembly, кеш-ориентированные оптимизации.




Важно понимать: аппаратное ускорение победит не потому, что software renderer плох. Он выдающийся. Просто специализированное железо внезапно начинает выполнять rasterization настолько эффективнее CPU, что огромный объём этих оптимизаций становится ненужным.




---




### VQuake — первый аппаратно ускоренный Quake { #vquake-quake }




Первым большим hardware-ответвлением становится не 3dfx, а **Rendition Vérité**.




Осенью 1996 появляется `vquake.exe` — отдельная версия Quake, заточенная под Vérité V1000. Часть работы, которую раньше делал Pentium, уходит на специализированный 3D-ускоритель.




Это даёт аппаратное filtering, mipmapping, 16-bit rendering и, главное, намного более мягкое масштабирование высокого разрешения.




В software Quake рост с 320×240 до 640×480 резко увеличивает число пикселей, которые должен обработать CPU. В VQuake rasterization становится задачей ускорителя, и bottleneck начинает смещаться с процессора на графическую плату.




Именно здесь потребитель впервые видит новый принцип:




```
раньше:
хочешь Quake быстрее → покупай более быстрый CPU

теперь:
хочешь Quake быстрее/красивее → покупай 3D accelerator
```




Но VQuake одновременно показывает проблему proprietary code paths. Если для каждого производителя требуется отдельный renderer, будущее превращается в кошмар:




```
vquake.exe
s3quake.exe
3dfxquake.exe
powervrquake.exe
...
```




Кармаку нужен стандартный API.




---




### GLQuake — перелом { #glquake }




В конце 1996 Кармак переносит Quake на OpenGL/Win32. 22 января 1997 выходит публичный **GLQuake**.




Архитектура теперь выглядит современно:




```
Quake
↓
OpenGL
↓
driver
↓
GPU
```




И главным массовым партнёром этой модели становится **3dfx Voodoo Graphics**.




#### Почему Voodoo была такой странной и такой правильной { #voodoo }




Voodoo 1 не пыталась быть нормальной Windows-видеокартой. Она фактически не заменяла основную 2D VGA. Пользователь ставил:




```
обычная 2D-карта
+
Voodoo Graphics
```




Карты соединялись passthrough-кабелем. В Windows работала 2D-плата; при запуске 3D-игры изображение перехватывала Voodoo.




С современной точки зрения это безумие. Но инженерно 3dfx сделала очень разумную вещь: не тратила ресурсы на офисный desktop и сосредоточилась на texture mapping, filtering, blending, depth и fill rate.




GLQuake становится одной из лучших демонстраций зачем вообще нужна такая плата. Покупателю можно показать одну и ту же знакомую игру:




```
вчера:
software Quake
320×240
CPU bottleneck

сегодня:
GLQuake + Voodoo
512×384 / 640×480
filtered textures
выше FPS
```




Это намного убедительнее рекламных обещаний про «миллионы треугольников».




---




### MiniGL — маленький слой, огромный эффект { #minigl }




Полный OpenGL — большой workstation API. Производителям дешёвых consumer GPU тяжело сразу написать качественный полный ICD. Но GLQuake использует лишь часть функций.




Так появляются MiniGL-драйверы: vendor реализует только subset OpenGL, нужный играм вроде Quake.




У 3dfx получается примерно:




```
GLQuake
↓
OpenGL calls
↓
3dfx MiniGL
↓
Glide
↓
Voodoo
```




Это важная смена ответственности. Вместо того чтобы game developer писал отдельный backend под каждую карту, производитель железа адаптирует своё устройство к стандартному API.




---




### Почему Кармак не стал делать отдельный GlideQuake { #glidequake }




3dfx имела собственный низкоуровневый API Glide. Кармак знал, что native Glide path может дать дополнительную производительность, но сознательно отказался поддерживать ещё один renderer.




Причина фундаментальна: каждый backend замедляет развитие всего движка. Если новую фичу надо реализовать в software, OpenGL, Vérité и Glide, шанс, что её вообще сделают, падает.




Эта инженерная идея будет определять развитие id дальше: лучше стандартизировать интерфейсы, чем поддерживать бесконечный зоопарк vendor-specific путей.




---




### WinQuake — другая революция: DOS → Windows { #winquake-dos-windows }




Важно не смешивать две линии.




VQuake/GLQuake решают вопрос:




> кто рисует 3D — CPU или GPU?




**WinQuake** решает другой:




> где работает сама игра — DOS или native Windows?




WinQuake всё ещё software-rendered. Но теперь это нормальное Win32-приложение с WinSock, DirectSound, DirectInput/DirectDraw-путями, оконным режимом и нормальной интеграцией с Windows 95/NT.




Таким образом Quake одновременно проводит PC через две независимые миграции:




```
DOS → Windows

и

CPU rasterization → hardware 3D
```




К Quake II обе идеи уже станут нормой.




---




### Quake как GPU benchmark { #quake-gpu-benchmark }




Встроенный timedemo делает Quake идеальным инструментом аппаратных обзоров.




Вместо маркетингового:




> наша карта рисует N миллионов треугольников




можно спросить:




> **сколько FPS в Quake?**




Очень быстро Quake, затем Quake II и Quake III становятся стандартными benchmarks. Культура современного обзора видеокарты — «вот реальная игра, вот разрешение, вот FPS» — формируется именно в эту эпоху.

### 3dfx Voodoo → Voodoo2: первая корона consumer 3D { #3dfx-voodoo-voodoo2-consumer-3d }




В 1997 связка GLQuake + Voodoo делает 3dfx символом игрового 3D. В 1998 выходит Voodoo2 и укрепляет лидерство.




Особенно легендарен SLI — тогда это **Scan-Line Interleave**. Две Voodoo2 могут совместно рисовать изображение, разделяя строки кадра. В одной системе иногда физически стоят три графические платы:




```
2D VGA
+
Voodoo2
+
Voodoo2
```




В Quake II такая конфигурация выглядит абсолютным high-end.




---




### NVIDIA: от RIVA до GeForce { #nvidia-riva-geforce }




NVIDIA сначала далеко не очевидный победитель. NV1 был странным и неудачным направлением. Но затем компания выстраивает очень быструю последовательность:




```
RIVA 128 — 1997
↓
RIVA TNT — 1998
↓
TNT2 — 1999
↓
GeForce 256 — 1999
↓
GeForce2 — 2000
```




Стратегия отличается от 3dfx. Вместо отдельного 3D-only ускорителя NVIDIA делает одну нормальную 2D/3D-плату и вкладывается в Direct3D/OpenGL и драйверы.




TNT ещё не «убивает» Voodoo2: в Quake II 3dfx часто быстрее. Но NVIDIA уже очень близко и технологически движется в сторону более универсальной архитектуры.




#### GeForce 256 { #geforce-256 }




Осенью 1999 NVIDIA выпускает GeForce 256 и популяризирует сам термин **GPU**. Главный новый шаг — hardware Transform &amp; Lighting: всё больше геометрического pipeline переносится с CPU на графическую карту.




Quake III оказывается идеальной витриной новой эпохи. Он уже вообще не имеет смысла без аппаратного 3D.




#### Почему 3dfx проигрывает { #3dfx }




Это не история «GeForce вышла, Voodoo умерла за ночь».




Voodoo3 в 1999 остаётся быстрой картой. Voodoo5 5500 в 2000 предлагает впечатляющий FSAA. Но стратегически 3dfx начинает отставать:




- слишком долго эксплуатирует старую архитектурную линию;

- ограничения по 32-bit/texture features начинают выглядеть хуже на фоне новых игр;

- покупка STB превращает 3dfx ещё и в производителя собственных плат и портит отношения с board partners;

- новая архитектура Rampage постоянно задерживается;

- NVIDIA штампует новые поколения с гораздо более быстрым cadence.





К GeForce2 технологическая инициатива уже у NVIDIA. В конце 2000 NVIDIA приобретает основные активы 3dfx.




Получается красивая Quake-хронология:




```
1996 — software Quake: главный компонент CPU
1996 — VQuake: первые серьёзные consumer accelerators
1997 — GLQuake + Voodoo: 3D-карта становится мечтой геймера
1998 — Quake II + Voodoo2: 3dfx на вершине
1998–99 — TNT/TNT2 догоняют
1999 — Quake III + GeForce 256: NVIDIA задаёт следующее направление
2000 — GeForce2 vs Voodoo5: NVIDIA закрепляет лидерство
```




И спустя два десятилетия цикл красиво замыкается: **Quake II RTX** снова используется NVIDIA, теперь уже чтобы объяснить потребителю, зачем ему новое поколение ray-tracing hardware.

### Вторая революция Quake: mouse-look и WASD { #quake-mouse-look-wasd }




Quake не только меняет внутренности игрового PC. Он меняет то, как человек держит руки.




Оригинальные default controls сегодня выглядят странно: стрелки могут использоваться для движения/поворота, вертикальный взгляд существует, но permanent mouse-look ещё не воспринимается как безусловная норма.




Это наследие Doom-эпохи. В Doom вертикальное наведение почти не является игровой задачей. В Quake всё иначе: враг может находиться выше или ниже, уровень реально трёхмерный, rocket jump и вертикальные бои делают клавиатурный turning неэффективным.




Competitive players быстро приходят к схеме:




```
левая рука → movement
правая рука → постоянный mouselook / aim
```




Dennis «Thresh» Fong не изобретает WASD из ничего — в community существовало множество конфигураций, включая ESDF и странные схемы на mouse buttons. Но именно лучший Quake-игрок мира делает `WASD + mouselook` знаменитым.




Его config практически уже современный:




```
W — forward
S — back
A — strafe left
D — strafe right
Space — jump
Mouse1 — fire
+mlook — постоянно
```




Игроки спрашивают, как он настроен. id даже кладёт `thresh.cfg` в Quake II. Сам Quake II ещё не делает WASD единственным default, но культурно победа уже произошла. Half-Life в 1998 помогает закрепить WASD как стандарт, а Quake III приходит в мир, где вопрос практически закрыт.




Получается вторая большая схема:




```
keyboard turning
↓
optional mouse-look
↓
competitive Quake
↓
Thresh / permanent +mlook
↓
WASD + mouse
↓
стандарт PC FPS
```




Таким образом за три года Quake помогает сформировать почти современную модель игрового ПК целиком:




```
CPU → simulation
GPU → graphics
mouse → camera / aim
WASD → movement
Internet → multiplayer
```

## V. 1996–1997 — QuakeWorld: как научить Quake жить в интернете { #v-19961997-quakeworld-quake }




Оригинальный Quake имеет хорошую client/server-архитектуру, но проектировался с чрезмерно оптимистичными ожиданиями по latency. На LAN всё отлично: клиент отправляет input, server рассчитывает движение, ответ возвращается почти мгновенно.




На dial-up всё разваливается.




При ping 300 ms проблема не только в том, что противник «лагает». **Лагает собственное управление**:




```
нажал W
↓
команда ушла на server
↓
server рассчитал движение
↓
ответ вернулся
↓
только теперь увидел движение
```




Для Quake — игры про мгновенный dodge, rocket jump и быстрый поворот — это убийственно.




Кармак публично признаёт ошибку. У него самого был отличный доступ к сети, поэтому он недооценил реальный опыт пользователей PPP-модемов.




### Client-side prediction { #client-side-prediction }




Решение QuakeWorld — одна из фундаментальных идей современного online action game.




Теперь клиент не ждёт server confirmation, чтобы показать собственное движение:




```
INPUT
├────────→ server
│
└────────→ local prediction
             ↓
       движение видно сразу
```




Server всё равно остаётся авторитетным. Когда приходит настоящее состояние, клиент сверяет его со своим прогнозом и при необходимости корректирует позицию.




Цена — физика движения теперь должна существовать и на клиенте, и на сервере и давать совместимый результат. Архитектура становится сложнее, зато управление снова ощущается мгновенным.




Кармак сознательно выбирает user experience вместо архитектурной чистоты. Это один из лучших примеров его инженерной прагматики.




### Prediction не отменяет latency { #prediction-latency }




QuakeWorld не изобретает машину времени. Противники и projectiles всё ещё существуют в server reality, поэтому игрок высокого ping учится учитывать задержку. Современная полноценная server-side lag compensation появится позже.




QuakeWorld прежде всего решает одну фундаментальную проблему: **твой собственный персонаж больше не должен ощущаться удалённо управляемой куклой**.




### Bandwidth и packet loss { #bandwidth-packet-loss }




Dial-up означает не только высокий ping, но и крошечный bandwidth и потерю пакетов. QuakeWorld активно использует delta-сжатие состояния. Если у entity изменилось только положение X, нет смысла заново пересылать model, angles и остальные поля.




Для частых объектов появляются даже game-specific форматы — например, отдельная компактная передача nails.




Система проектируется с пониманием, что packet может исчезнуть, а следующий snapshot важнее старого потерянного.




### Master servers { #master-servers }




Вторая проблема интернета 1996 года: как вообще найти сервер? QuakeWorld развивает идею master server — серверы регистрируются в центральной системе, клиент получает список доступных площадок.




Первоначально Кармак мечтал ещё шире: global accounts, статистика, рейтинги, лучший игрок мира. Реальная инфраструктура быстро упирается в масштаб — в день публичного запуска master server буквально падает под несколькими тысячами пользователей.




Но идея уже появилась. Через много лет Quake Live вернётся почти к тому же набору: accounts, matchmaking, stats, leaderboard.




### QuakeSpy → GameSpy { #quakespy-gamespy }




Параллельно сторонняя утилита QSpy/QuakeSpy помогает сканировать серверы, видеть ping, карты и игроков и быстро запускать игру. Проект позднее превращается в **GameSpy** — огромный бренд multiplayer-инфраструктуры конца 90-х и 2000-х.




Снова Quake порождает что-то значительно больше себя самого.




### Почему QuakeWorld так важен { #quakeworld }




Если Quake сделал современный 3D multiplayer FPS как объект, QuakeWorld начал учить его нормально существовать в реальном интернете.




Его наследие:




- client-side prediction;

- bandwidth-conscious protocol;

- packet-loss tolerance;

- master-server thinking;

- spectator foundation;

- отдельная международная competitive-сцена.





И многое из этого потом прямо переедет в Quake II и Quake III.

## VI. 1997 — Quake расширяется { #vi-1997-quake }




### Scourge of Armagon { #scourge-of-armagon }




Первый официальный mission pack разрабатывает Hipnotic Interactive. Он сохраняет структуру и механику Quake, но добавляет новые уровни, врагов и оружие. Это классический expansion старой школы: не отдельная игра, а новый набор задач внутри уже существующего ruleset.




Значение Armagon прежде всего в том, что он показывает жизнеспособность Quake как платформы для больших коммерческих expansion packs, пока community параллельно делает бесплатные моды.

## VIII. 1997 — Quake II: название остаётся, вселенная меняется { #viii-1997-quake-ii }




### Почему Quake II вообще не продолжает Quake { #quake-ii-quake }




Quake II выходит в декабре 1997 года и совершает вещь, которая навсегда усложнит всю идентичность серии: **он не продолжает историю первого Quake**.




Никаких Ranger, Shub-Niggurath, рун и готических измерений. Вместо этого:




```
Earth
↓
alien invasion
↓
Strogg
↓
human counterattack on Stroggos
```




Это military science fiction с кибернетическим body horror.




Причина во многом практическая: id долго не могла подобрать название для новой игры, а бренд Quake уже был очень сильным. В результате Quake становится не названием конкретной вселенной, а зонтичным именем нового поколения id-шутеров.




Именно здесь рождается будущая проблема: что вообще считать «настоящим Quake» — eldritch Q1 или Strogg-сагу Q2?




#### Почему смена мира так заметна { #_4 }




Первый Quake работает через ощущение неизвестности. Игрок почти никогда не понимает, что представляет собой очередное измерение и почему военная технология соседствует с замками и рунами. Quake II сознательно становится понятнее. Stroggos — планета противника, factories производят киборгов, Big Gun защищает мир от человеческого флота, Makron — военный лидер.




Даже level design подчиняется другой логике. Вместо отдельных сюрреалистических эпизодов появляются **units** — связанные комплексы карт с общей задачей. Игрок может пройти одну область, получить objective, вернуться назад, открыть ранее закрытый путь и только затем двигаться дальше.




Это уже не Doom-подобная цепочка уровней, а ранняя попытка создать ощущение связного пространства большой военной операции. Позднее именно эту структуру будет сложнее всего переносить на консоли с несколькими мегабайтами памяти.




---




### Strogg — совершенно другой враг { #strogg }




Strogg не демоны и не древние божества. Это экспансионистская кибернетическая цивилизация, которая перерабатывает другие виды в материал для собственных войск.




Их эстетика строится вокруг буквального смешивания:




```
плоть
+
металл
+
машинная инфраструктура
```




Человек для Strogg — не просто противник, а сырьё. Эта идея потом станет центральной для Quake 4, где игрок увидит Stroggification уже от первого лица.




#### Кампания { #_5 }




Человечество решает перейти от обороны к контрудару и атакует Stroggos. Масштабная десантная операция почти уничтожена. Один Marine продолжает миссию в одиночку, ломая инфраструктуру планеты и постепенно добираясь до Makron.




Позднее Quake III закрепит имя этого героя — **Bitterman**.




---




### Quake II как более зрелый движок { #quake-ii }




Технологически Quake II не является чистым переписыванием всего с нуля. Это следующий этап линии, которая за предыдущий год прошла через QuakeWorld, WinQuake, VQuake и GLQuake.




#### Цветные lightmaps и radiosity { #lightmaps-radiosity }




Первый Quake в основном хранит яркость света. Quake II получает RGB-lightmaps, и визуальный язык резко меняется:




```
красные аварийные коридоры
зелёные Strogg-интерьеры
синие техно-зоны
```




Offline-lighting pipeline также становится более развитым, включая radiosity-подходы.




#### QuakeC уходит, появляется native game DLL { #quakec-native-game-dll }




Вместо QuakeC gameplay компилируется в native C-модуль — например `gamex86.dll` на Windows.




Это менее романтично для случайного моддера, но удобно для профессиональной разработки и лицензирования:




```
engine
↕
стабильный game API
↕
native gameplay module
```




#### Renderer становится сменным модулем { #renderer }




Самая важная архитектурная реакция на хаос VQuake/GLQuake:




```
quake2.exe
    │
    ├─ ref_soft.dll
    └─ ref_gl.dll
```




Software и OpenGL теперь не отдельные почти независимые продукты, а два backend'а общей системы.




Quake II — это момент, когда hardware 3D перестаёт быть экспериментом вокруг игры и становится first-class конфигурацией самого движка.




#### QuakeWorld внутри Quake II { #quakeworld-quake-ii }




Сетевая часть также уже не та, что была у первого Quake в июне 1996 года. Опыт QuakeWorld — prediction, работа с Internet latency, delta-oriented updates — становится частью нового технологического фундамента.




Кармак фактически использовал 1996–97 как гигантский R&amp;D-цикл:




```
Quake
→ настоящий 3D и client/server

QuakeWorld
→ Internet networking

VQuake / GLQuake
→ hardware rendering

WinQuake
→ Win32

всё вместе
→ Quake II
```




Поэтому Quake II ощущается менее революционным одним конкретным трюком, чем первый Quake, но технологически он намного более зрелый продукт.




#### Игра становится заметно «стрелковее» { #_6 }




Q1 любит тяжёлые projectile-enemies, тесные готические пространства и необычную смесь оружия. Q2 сильнее похож на sci-fi action shooter: Machinegun, Chaingun, HyperBlaster, Railgun, BFG10K, более частая стрельба на дистанции.




Railgun особенно важен для будущего competitive Quake: мгновенный высокоточный hitscan shot с большой ценой промаха становится одним из символов всей серии. В Quake III он уже будет фундаментальным элементом Duel.




#### Почему Quake II позже воспринимается спокойнее первого { #quake-ii_1 }




У него намного яснее художественная идентичность, но именно поэтому она менее странная. Q1 сегодня невозможно спутать почти ни с чем: medieval horror, industrial machinery и eldritch dimensions существуют одновременно. Quake II легче поместить в категорию military sci-fi.




В 1997 эта ясность делала игру более современной. Через тридцать лет именно хаотичность первой части неожиданно оказывается более уникальной.

### Sonic Mayhem и новая идентичность { #sonic-mayhem }




Вместо тревожной эмбиентной музыки Trent Reznor Quake II получает агрессивный industrial-metal soundtrack Sonic Mayhem.




Это очень хорошо подчёркивает смену мира.




Quake I:




```
одиночество
чужие измерения
непонятный horror
```




Quake II:




```
ВОЙНА

```




Даже музыка показывает, насколько мало общего у двух игр кроме имени и технологического происхождения.

## IX. 1998 — Quake II становится платформой { #ix-1998-quake-ii }




### The Reckoning { #the-reckoning }




Первый большой mission pack делает Xatrix Entertainment. Он расширяет войну со Strogg новыми картами, оружием и противниками, но не пытается менять базовую идентичность Quake II.




Это дополнительная операция внутри той же войны.




### Ground Zero { #ground-zero }




Второй mission pack от Rogue Entertainment идёт ещё дальше с новыми врагами, оружием и mechanics. Позднее часть AI-идей Ground Zero Nightdive вернёт обратно в основную игру в ремастере 2023 года.

### Netpack I: Extremities — когда id официально продаёт community { #netpack-i-extremities-id-community }




В конце 1998 выходит **Quake II Netpack I: Extremities**.




Это важно не путать с mission packs. The Reckoning и Ground Zero — новые сюжетные кампании. Extremities — коммерческий сборник community-модов.




На одном официальном диске оказываются:




- Action Quake 2;

- Q2CTF;

- Rocket Arena 2;

- Jailbreak;

- Eraser Bot;

- Red Rover;

- другие multiplayer-модификации и карты.





Это великолепный снимок того, чем Quake стал всего за два года. id выпускает базовую технологию, community мутирует её в десяток разных игр, а затем сама id официально упаковывает лучшие мутации в retail-продукт.

### Action Quake 2 → Counter-Strike { #action-quake-2-counter-strike }




Самая важная вещь внутри Extremities — **Action Quake 2**.




AQ2 сознательно выбрасывает фантастику Quake II:




```
Rocket Launcher
HyperBlaster
Strogg
```




заменяются на:




```
реальное оружие
городские пространства
кинематографический action
раунды
ранения
```




Урон становится более «телесным»: попадания могут вызывать bleeding и ограничения движения, игрок должен перевязываться. Но главное — раундовая система без обычного мгновенного respawn.




Смерть теперь означает:




```
умер
↓
жди следующий раунд
```




Это резко меняет поведение людей. Информация, позиция, численное преимущество и teamwork становятся важнее бесконечного frag farming.




Minh «Gooseman» Le сначала делает Navy SEALs для Quake, затем работает над Action Quake 2, где знакомится с Jess Cliffe и впитывает именно эту модель realistic round-based multiplayer. После выхода Half-Life он использует новый GoldSrc-мир для следующего проекта — **Counter-Strike**.




Получается почти рекурсивная генеалогия:




```
Quake engine ─────────→ GoldSrc ─────────→ Half-Life
     │                                      │
     └→ Quake modding → Action Quake 2 ─────┘
                                            ↓
                                     Counter-Strike
```




Counter-Strike наследует Quake одновременно **технологически** и **через дизайнерскую/кадровую mod-сцену**.

## X. Консольные Quake I и Quake II — один бренд, совершенно разные инженерные ответы { #x-quake-i-quake-ii }




### Quake на Sega Saturn — порт, который почти пришлось написать заново { #quake-sega-saturn }




Saturn плохо подходит под Quake. Оригинальный движок рассчитывает на быстрый CPU и software rasterization настоящего polygonal мира. Saturn же имеет два SH-2, VDP1/VDP2 и очень специфическую архитектуру, где текстурированное 3D строится вокруг quads/distorted sprites.




Lobotomy Software уже имела собственный FPS-engine **SlaveDriver**, созданный для PowerSlave/Exhumed. Вместо прямого порта Quake engine студия фактически воссоздаёт Quake внутри своей технологии.




Карты приходится вручную пересобирать под внутренний editor Brew. Большие поверхности необходимо дробить на множество quads, открытые пространства особенно тяжело давят на железо.




Именно поэтому некоторые оригинальные secret levels не влезают нормально. Вместо них Lobotomy делает четыре собственные секретные карты:




- Purgatorium;

- Hell's Aerie;

- The Coliseum;

- Watery Grave.





То есть Saturn Quake одновременно хуже PC по FPS, управлению и отсутствию multiplayer — и уникален как почти отдельная техническая реконструкция игры.




Главное достижение не в том, что это «лучшая версия». Главное — **она вообще существует и удивительно похожа на Quake** на железе, которое для него почти не предназначено.

### Quake 64 — уже не инженерное чудо, а альтернативная редакция { #quake-64 }




Nintendo 64 намного естественнее работает с polygonal 3D. Midway/Raster Productions может использовать сильно модифицированную Quake-технологию, а не писать почти отдельную игру.




Но появляются другие ограничения:




- 4 MB RAM;

- картридж;

- память под textures/audio;

- необходимость оптимизировать кампанию под консоль.





В результате несколько уровней PC-версии вырезаются, структура становится более линейной, стартовый hub исчезает.




Зато Quake 64 получает:




- hardware filtering;

- цветное освещение;

- собственный soundtrack Aubrey Hodges;

- локальный deathmatch;

- отдельную атмосферу, ближе к абстрактному horror.





Поэтому сегодня Quake 64 интересен не как «бедный порт», а как официальная альтернативная редакция оригинальной игры.

### PlayStation Quake, который не вышел { #playstation-quake }




После Saturn Quake Lobotomy быстро переносит технологию на PlayStation. По воспоминаниям Ezra Dreisbach, PS1 справлялась с подобной графикой даже легче. Рабочий порт существовал, но издателя найти не удалось.




Это один из самых обидных потерянных Quake: проект умер не потому, что машина не тянула, а потому что никто не захотел довести коммерческий релиз.

### Quake II на PlayStation — собственный HammerHead engine { #quake-ii-playstation-hammerhead-engine }




Через два года PlayStation всё-таки получает Quake — но сразу вторую часть. И делает её британская HammerHead.




Вместо прямого порта Quake II engine студия создаёт собственную технологию и реконструирует игру под ограничения PS1.




PC Quake II построен вокруг связанных units с переходами между картами и backtracking. На PS1 это слишком тяжело. Кампания сокращается примерно до 20 уровней, появляются маленькие loading corridors, hub-структура сильно упрощается.




Но HammerHead добавляет и собственный официальный контент, включая новых врагов вроде Arachnid и Guardian, а также отдельные multiplayer-карты.




Порт поддерживает PlayStation Mouse и до четырёх игроков через MultiTap — довольно безумное достижение для PS1.




Поэтому PS1 Quake II — не «Quake II с худшей графикой», а техническая реконструкция оригинальной кампании на совершенно другой основе.

### Quake II 64 — Midway наконец делает собственный Quake II { #quake-ii-64-midway-quake-ii }




С N64 история ещё интереснее. Вместо попытки сжать PC-кампанию Midway/Raster делает **почти полностью новую single-player campaign**:




- 19 уровней;

- 10 deathmatch-карт;

- собственная последовательность;

- soundtrack Aubrey Hodges;

- отдельная атмосфера.





Технологически версия растёт из модифицированной N64-ветки первого Quake engine, а не является обычным портом PC Quake II.




Поэтому Quake II 64 правильнее воспринимать как **официальный side-campaign** во вселенной Strogg.




Именно поэтому Nightdive в 2023 году не просто упомянет её, а целиком включит внутрь современного Quake II Enhanced.

## XI. 1999 — Quake III Arena: id выбрасывает кампанию и оставляет только спорт { #xi-1999-quake-iii-arena-id }




После Quake и Quake II id приходит к радикальному выводу. Single-player и multiplayer требуют слишком разных дизайнерских и технологических решений.




Если хочется сделать лучший arena FPS, зачем тратить ресурсы на сюжетные уровни, monsters и scripted campaign?




Так рождается **Quake III Arena**.




Это уже не игра с multiplayer.




Это **multiplayer как сама игра**.




Одиночный режим — по сути последовательность матчей против ботов. Никакой традиционной кампании нет.




#### Базовая формула { #_7 }




```
Rocket Launcher
Railgun
Lightning Gun
armor
MegaHealth
movement
map control
```




Все игроки симметричны. Персонажи — в основном визуальная идентичность. Глубина возникает не из классов или progression, а из освоения общей системы.




Quake III становится почти лабораторно чистым arena FPS.




#### Почему это было радикальным решением { #_8 }




В 1999 крупный FPS без нормальной campaign всё ещё выглядит странно. Half-Life только что показал, насколько далеко можно увести жанр в сюжетное приключение. Unreal строит огромный sci-fi world. System Shock 2 смешивает FPS и RPG.




id идёт почти в обратную сторону:




> нам не нужна большая scripted campaign; давайте сделаем лучшие арены, лучших ботов, лучший networking и лучший combat.




Вместо сюжета игрок проходит tiers против всё более сильных ботов. Arena Eternal и Vadrigar дают минимальное оправдание происходящему: лучшие воины из разных миров бесконечно дерутся ради таинственных хозяев Arena.




#### Почему три оружия определяют характер Quake III { #quake-iii }




Quake III имеет более широкий арсенал, но competitive-ядро особенно хорошо читается через тройку:




**Rocket Launcher** — prediction, splash, area denial, вертикальный knockback, rocket jump.




**Lightning Gun** — continuous tracking на средней/ближней дистанции.




**Railgun** — редкий, мощный hitscan shot: crosshair должен быть в нужной точке в конкретный момент.




Один и тот же игрок должен уметь три совершенно разных типа aim. Поэтому weapon switching — не просто выбор «пушки с большим DPS», а постоянное решение о геометрии текущего боя.




#### Movement становится самостоятельным skill layer { #movement-skill-layer }




Strafe jumping превращает карту в систему маршрутов, доступных только человеку, который освоил физику. Новичок видит коридор. Ветеран видит линию ускорения, оптимальный угол входа и точку, где можно сохранить скорость через следующий поворот.




Это усиливает фундаментальный характер Quake: mastery не даёт +10% к характеристике персонажа — mastery буквально открывает игроку **другой способ существовать на той же карте**.




---




### id Tech 3 { #id-tech-3 }




Технологически Quake III завершает переход, начатый GLQuake.




Software renderer больше не нужен. Игра строится вокруг hardware OpenGL.




Основные идеи:




- BSP/PVS/lightmaps продолжают жить;

- shader/material scripts позволяют художникам собирать сложные multi-pass surfaces без уникального кода;

- curved patches дают более плавную архитектуру;

- server отправляет клиентам snapshots/deltas;

- gameplay, client game и UI могут исполняться через QVM bytecode;

- bots становятся first-class системой.





Quake III shader — ещё не современный programmable GPU shader. Это скорее material script для фиксированного OpenGL pipeline: texture stages, blending, animation, UV scrolling, surface deformation.




Но концептуально это важный шаг к современному material system.




---




### Quake III как GPU benchmark { #quake-iii-gpu-benchmark }




Если GLQuake помог продать первый массовый 3D accelerator, Quake III становится главным тестом уже зрелой GPU-индустрии.




Q3Test ещё до релиза используется для сравнений:




```
Voodoo3
vs
TNT2
vs
GeForce
```




А финальный Quake III годами остаётся стандартным benchmark для новых видеокарт и процессоров.




Именно здесь GeForce 256 и затем GeForce2 начинают символизировать переход лидерства от 3dfx к NVIDIA.

### Dreamcast — почти настоящий Quake III в консоли { #dreamcast-quake-iii }




Dreamcast-версия 2000 года интересна тем, что не пытается слишком сильно переделать Q3 под консоль. Sega/Raster просто даёт игроку возможность подключить **keyboard + mouse**.




Получается почти маленький PC:




```
Dreamcast
+
modem
+
keyboard
+
mouse
=
Quake III online
```




Более того, существовал cross-platform multiplayer между Dreamcast и PC — очень ранний пример проблемы, которую индустрия обсуждает до сих пор: насколько честно объединять mouse/keyboard и controller users.




На стандартном одностиковом Dreamcast pad Quake III живёт хуже. Но возможность использовать PC input делает эту версию самой «честной» консольной адаптацией эпохи.

### Quake III Revolution — PS2 делает Quake III консольной игрой { #quake-iii-revolution-ps2-quake-iii }




PlayStation 2 выбирает противоположный путь. Online-инфраструктуры на старте почти нет, поэтому Revolution выходит вообще без нормального интернетного multiplayer.




Чтобы продукт имел смысл, Bullfrog расширяет одиночную часть:




- разные персонажи получают разные базовые характеристики;

- появляется progression;

- часть Team Arena-контента приходит раньше/вместе;

- появляются новые режимы и boss-like encounters;

- прокачанного персонажа можно использовать локально.





Это очень странный официальный Quake III: почти RPG-подобная вариация аренной формулы.




Иронично, что идея «персонажи Quake имеют разные stats» появится здесь за пятнадцать лет до Quake Champions.

## XII. OSP, Rocket Arena, CPMA и DeFRaG — community снова переделывает Quake III { #xii-osp-rocket-arena-cpma-defrag-community-quake-iii }




### OSP — спорт без изменения правил { #osp }




Orange Smoothie Productions делает то, чего не хватает vanilla Q3 для серьёзных турниров:




- referee/admin tools;

- warmup;

- паузы;

- scoreboards;

- spectator systems;

- team overlays;

- demo infrastructure.





OSP старается не менять core gameplay. Это «нормальная спортивная организация» поверх Q3.




---




### Rocket Arena → Clan Arena { #rocket-arena-clan-arena }




Rocket Arena возник ещё в первом Quake как радикальное упрощение формулы:




```
всем полный arsenal
всем health/armor
нет pickups
нет item economy
сразу FIGHT
```




В Q3 эта идея достигает зрелой формы через Rocket Arena 3 и Clan Arena.




Duel проверяет combat + map economy. Clan Arena почти удаляет экономику и оставляет pure combat/team elimination.




Почему режим так живуч? Он снижает входной барьер, не снижая механический ceiling. Новичку не надо сначала учить timing MegaHealth — ему сразу дают Rocket, Rail и LG. Но чтобы быть сильным, всё равно нужны aim, movement, weapon switching и positioning.




Позднее Clan Arena станет официальным режимом Quake Live.




---




### CPMA / CPM — Quake III недостаточно сложный, исправим { #cpma-cpm-quake-iii }




Challenge ProMode Arena начинается как попытка собрать идеальную competitive-версию Quake.




Важно различать:




- **CPMA** — сам мод/competitive platform;

- **CPM** — один из gameplay rulesets внутри него.





CPM возвращает и смешивает movement-наследие предыдущих Quake:




```
QuakeWorld air control
+
Quake II double/ramp techniques
+
Quake III strafe jumping
```




Плюс более быстрое weapon switching и свои balance changes.




Результат — Quake III на ещё большей скорости и с ещё более высоким skill ceiling.




CPM никогда не становится массовой заменой VQ3 именно потому, что делает хардкорную игру ещё хардкорнее. Но среди фанатов это одна из самых чистых форм идеи «освоение механики открывает новые возможности».




---




### DeFRaG — FPS, из которого убрали противника { #defrag-fps }




DeFRaG задаёт прекрасный вопрос:




> если Quake movement настолько глубокий, нужен ли вообще enemy?




Формула:




```
START
↓
geometry
↓
FINISH
↓
time
```




И Quake превращается почти в TrackMania с Rocket Launcher.




Техники:




- circle jump;

- strafe jump;

- bunny hopping;

- air control;

- rocket jump;

- plasma climb;

- grenade/BFG jumps;

- ramp/double jumps;

- overbounces.





Игрок соревнуется не с противником, а с картой, собственной траекторией и мировым рекордом.




Появляются ghost runs, CGazHUD, огромная база custom maps и культура trickjumping-видео.




DeFRaG доказывает чрезвычайно важную вещь: **movement Quake сам по себе достаточно глубок, чтобы быть отдельной игрой**.

## XIII. Движковая генеалогия — как Quake оказался внутри Half-Life, Source и Call of Duty { #xiii-quake-half-life-source-call-of-duty }




Quake важен не только потому, что на нём выходили Quake-игры. Его technology lineage расползается по индустрии.




### Quake → GoldSrc { #quake-goldsrc }




Valve создаётся в 1996 году и лицензирует Quake engine, чтобы не тратить маленькую команду на написание собственной low-level 3D technology.




Затем движок очень глубоко переделывается. К Half-Life 1998 года это уже не «Quake с модом», а отдельная технология — GoldSrc — с новыми:




- AI;

- animation;

- scripted sequences;

- renderer extensions;

- tools;

- entity systems;

- game DLL architecture.





Но генетическая связь непрерывна.




Из GoldSrc вырастают:




- Half-Life;

- Team Fortress Classic;

- Counter-Strike;

- Day of Defeat.





---




### GoldSrc → Source { #goldsrc-source }




Внутри Valve стабильную ветку Half-Life называют `GoldSrc`, а новую экспериментальную — `Src`. Со временем `Src` превращается в Source Engine.




Source получает новый renderer, physics, animation, materials и огромное количество других систем. К Half-Life 2 это уже другая технология. Но процесс происходит постепенно — типичный корабль Тесея.




Дальше:




```
Quake
↓
GoldSrc
↓
Source
↓
Source 2
```




Так в далёкой родословной Quake оказываются Half-Life 2, Portal, Team Fortress 2, Left 4 Dead, Dota 2, Half-Life: Alyx и Counter-Strike 2.




Говорить «CS2 работает на Quake engine» бессмысленно, но говорить «Quake находится в далёкой технологической родословной Source» — абсолютно корректно.




---




### Quake III → Medal of Honor / RTCW → Call of Duty { #quake-iii-medal-of-honor-rtcw-call-of-duty }




id Tech 3 становится одной из самых лицензируемых FPS-технологий эпохи. На нём или его крупных ответвлениях выходят:




- Return to Castle Wolfenstein;

- Medal of Honor: Allied Assault;

- Jedi Outcast / Jedi Academy;

- American McGee's Alice;

- Soldier of Fortune II;

- другие проекты.





Команда Medal of Honor: Allied Assault затем образует ядро Infinity Ward.




Первый Call of Duty использует technology lineage, выросший из Quake III/RTCW-ветки, хотя Infinity Ward сразу переписывает огромные куски renderer, animation, AI и lighting.




Дальше эта линия становится IW Engine.




Получается редкая двойная наследственность:




```
id Tech 3
↓
MoHAA / RTCW tech
↓
Call of Duty

и одновременно

MoHAA developers
↓
Infinity Ward
↓
Call of Duty
```




Quake III влияет на Call of Duty и кодом, и людьми.




---




## XIV. 2000–2001 — Team Arena и зрелая Quake III-экосистема { #xiv-20002001-team-arena-quake-iii- }




### Team Arena { #team-arena }




Официальное expansion пытается придать командному Q3 больше структуры. Появляются дополнительные modes, оружие и team mechanics.




Исторически Team Arena не становится такой же центральной вещью, как сам Q3A, но часть её контента затем мигрирует в консольные версии, Quake Live и общее наследие серии.




---




## XV. 2004–2007 — id Tech 4, Quake 4 и Quake Wars { #xv-20042007-id-tech-4-quake-4-quake-wars }




### Doom 3 engine / id Tech 4 { #doom-3-engine-id-tech-4 }




После Quake III следующая технологическая революция id приходит уже с Doom 3.




Старая философия Quake/Q2/Q3:




```
много света рассчитывается offline
↓
lightmaps
```




id Tech 4 делает ставку на:




```
unified dynamic lighting
per-pixel lighting
normal maps
specular maps
stencil shadows
```




Скелетная MD5-анимация и интерактивные GUI прямо на поверхностях мира также становятся важными чертами технологии.




К четвёртой части имя Quake уже перестаёт совпадать с названием движка: Quake 4 работает на Doom 3 engine.




---




### 2005 — Quake 4: единственный прямой numbered sequel { #2005-quake-4-numbered-sequel }




Quake 4 от Raven Software — прямое продолжение Quake II.




После гибели Makron война на Stroggos не заканчивается. Новая волна людей прибывает на планету. Главный герой — Matthew Kane из Rhino Squad.




Главный сюжетный ход Quake 4 буквально реализует основную тему Strogg: Kane захватывают и начинают **Stroggification**. Его тело разбирают и кибернетически перестраивают, но процесс перепрограммирования сознания прерывается.




Получается:




```
человеческий разум
+
Strogg body
```




Это наиболее прямое продолжение мира Quake II и единственная numbered Quake, которая абсолютно однозначно продолжает сюжет предыдущей части.




#### Multiplayer { #multiplayer }




Quake 4 также пытается быть наследником Quake III в multiplayer. В нём есть быстрая arena-игра, Duel/TDM и competitive-сцена. Но он не вытесняет Q3 как вечный стандарт. Community в итоге распадается между QW, Q3/CPMA и Q4.




---




### Quake Mobile — настоящий Quake на устройстве до iPhone { #quake-mobile-quake-iphone }




В 2005 выходит официальный Quake Mobile от Bear Naked Productions/Pulse Interactive.




В отличие от Doom RPG-подхода, здесь идея радикально другая:




> не упрощать Quake под слабый телефон — дождаться мобильного железа с настоящим 3D accelerator и запустить нормальный Quake.




На мощных Windows Mobile/PDA-устройствах вроде Dell Axim игра представляет собой настоящий GLQuake-lineage продукт: полноценные карты, monsters, оружие, `.pak` и даже совместимость с single-player mods.




Главная проблема — управление. Технически Quake уже помещается в карман, эргономически mouse-look FPS на мобильном устройстве 2005 года выглядит дико.




Официальной большой J2ME/BREW-линии Quake в духе Doom RPG так и не возникает.




---




### 2007 — Enemy Territory: Quake Wars { #2007-enemy-territory-quake-wars }




Splash Damage берёт objective-based DNA Wolfenstein: Enemy Territory и переносит его в Strogg-вселенную.




Хронологически это приквел Quake II: Strogg ещё атакуют Землю, а GDF обороняется.




Формула:




```
Enemy Territory
+
Battlefield-like scale
+
Quake II/4 universe
```




Есть классы, vehicles, deployables, большие карты и асимметричные objectives.




Это Quake, где игрок уже не суперсолдат-одиночка и не гладиатор Arena Eternal, а участник большой войны.




Консольные версии PS3/Xbox 360 делают отдельные студии и адаптируют интерфейс/управление под gamepad, но исторически Quake Wars остаётся прежде всего PC-oriented objective shooter.




---




## XVI. 2007–2015 — Quake Zero превращается в Quake Live { #xvi-20072015-quake-zero-quake-live }




После Quake 4 и Quake Wars id не делает Quake 5. Вместо этого компания возвращается к Quake III и задаёт очень характерный для конца 2000-х вопрос:




> можно ли превратить старый идеально отточенный arena FPS в современный бесплатный онлайн-сервис?




### Quake Zero { #quake-zero }




На QuakeCon 2007 проект объявляют как **Quake Zero** — буквально Quake за ноль долларов.




Идея выглядит очень современно для своего времени:




```
Quake III
+
free-to-play
+
browser frontend
+
accounts / friends / stats
+
ad-supported model
```




Важно: «Quake в браузере» не означает Flash/WebGL-игру. Браузер и plugin выступают оболочкой для login, профиля, matchmaking и запуска нативного клиента. Под ним всё ещё настоящий Quake III-derived executable.




Главная инновация не rendering, а **снижение трения вокруг игры**. Вместо старой PC-процедуры:




```
купи Quake III
поставь patch
найди mod
найди server
настрой cfg
```




пользователю хотят сказать:




> открой сайт и нажми Play.




---




### 2009 — Quake Live { #2009-quake-live }




Quake Zero превращается в **Quake Live** и выходит в open beta.




Quake III к этому моменту уже почти десять лет. Любой относительно современный компьютер способен выдавать высокий FPS. Движок и карты изучены вдоль и поперёк. Поэтому id может сосредоточиться на том, чего Q3 1999 года практически не имел как сервис:




- persistent accounts;

- friends;

- achievements;

- statistics;

- ratings;

- matchmaking;

- централизованный server browser;

- автоматические обновления.





И сама игра тоже постепенно меняется. Weapon balance адаптируется под десятилетие развития aim/hardware/networking: например, Railgun становится слабее, потому что современный игрок на хорошей мыши и соединении попадает намного стабильнее, чем средний человек 1999 года.




Quake Live начинает официально впитывать то, что community десять лет делала модами:




- Duel;

- Clan Arena;

- Freeze Tag;

- Attack &amp; Defend;

- community maps;

- разные physics/ruleset experiments.





Поэтому итоговый Quake Live правильнее считать **Quake III Arena: Definitive Competitive Edition**, а не просто браузерным портом.




#### Почему именно Quake III оказался идеальным кандидатом { #quake-iii_1 }




К концу 2000-х графика Q3 уже не требует специального игрового PC. Это неожиданное преимущество: id не обязана строить новый renderer и может гарантировать огромный framerate почти на любом железе.




Поэтому модернизация происходит там, где старая PC-игра действительно устарела:




- onboarding;

- поиск матчей;

- профили;

- friends;

- статистика;

- server discovery;

- автоматические updates.





То есть Quake Live — редкий ремастер, где главная работа идёт **вокруг самой игры**, а не внутри graphics pipeline.




#### Officialization of community Quake { #officialization-of-community-quake }




За десять лет Q3-community уже определила, каким должен быть серьёзный competitive Quake: Duel, Clan Arena, Freeze Tag, популярные custom maps, tournament configs. Quake Live постепенно втягивает эти идеи внутрь официального продукта.




Это повторяющаяся схема всей истории Quake:




```
id выпускает фундамент
↓
community находит лучшие формы
↓
id/Bethesda спустя годы делает их официальными
```




CTF, Clan Arena, community maps и даже поздние official add-ons первого Quake следуют этой логике.




---




### Монетизация: сначала реклама, потом подписка { #_9 }




Первоначальная мечта — бесплатная игра, оплачиваемая рекламой на аренах.




Проблема очевидна задним числом: игрок Quake не очень внимательно рассматривает рекламный щит, пока летит через комнату, считает MegaHealth и пытается не получить Rail в голову.




Advertising model не приносит ожидаемых денег. В 2010 появляются Premium и Pro subscriptions. Дополнительные карты, режимы и возможность создавать собственные матчи начинают зависеть от платной подписки.




Это создаёт интересный конфликт с наследием старого Quake III. Q3 был почти безграничной локальной платформой для серверов и модов. Quake Live превращает часть этих возможностей в контролируемый сервис.




Именно здесь Quake впервые по-настоящему сталкивается с будущей дилеммой всей индустрии:




```
игра как программа, которой владеет пользователь
vs
игра как сервис, которым управляет оператор
```




С одной стороны, сервис позволяет нормальный matchmaking и единую population. С другой — человек, привыкший к dedicated servers, cfg и community mods, теряет часть автономии.




Любопытно, что финальная Steam-форма Quake Live в 2015 снова двинется обратно к более традиционной PC-модели.




---




### 2013 — браузерная мечта умирает { #2013 }




Chrome/Firefox постепенно отказываются от старых plugin-технологий. В результате Quake Live вынужден отказаться от самой идеи, вокруг которой первоначально строился.




Путь получается комичный:




```
2007:
«Quake, который не надо устанавливать как обычную игру»

2013:
«скачайте standalone client»
```




Одновременно прекращаются native Mac/Linux-клиенты, и standalone Quake Live становится Windows-centric.




---




### 2014 — accessibility update и война с собственной аудиторией { #2014-accessibility-update }




id сталкивается с фундаментальной проблемой arena FPS:




> новые игроки заходят и мгновенно попадают к людям, которые играют в Quake пятнадцать лет.




Ветеран:




- быстрее перемещается;

- знает item timings;

- контролирует map;

- попадает hitscan;

- понимает spawns.





Новичок видит только счёт 3:27 и не понимает, почему вообще не может начать играть.




В 2014 разработчики пробуют снизить порог входа:




- selectable starting weapons;

- упрощённый bunny hop;

- item timers;

- markers;

- глобальная ammo-модель;

- Heavy Machine Gun;

- другие accessibility changes.





Для старой community это почти святотатство: знание времени Mega/Armor и борьба за weapon control — часть самого skill Quake.




В итоге classic ruleset сохраняется, а часть спорных решений становится опциональной. Quake снова обнаруживает проблему, которая потом уничтожит попытку Champions стать массовой: **очень трудно сделать Quake доступнее, не убрав именно то, за что его любят**.




---




### 2014–2015 — Steam и возвращение к обычной игре { #20142015-steam }




Quake Live приходит в Steam сначала как F2P. В 2015 id закрывает собственную старую account/subscription инфраструктуру и окончательно переводит игру на Steamworks.




Финальная модель удивительно традиционна:




```
купил игру один раз
↓
получил всё
↓
dedicated servers
Workshop
server browser
Steam Friends
custom games
```




То есть после восьми лет экспериментов с browser/F2P/ads/subscription Quake Live практически возвращается к модели классической PC-игры — просто намного более отполированной, чем Q3 1999.




Именно эта версия становится «финальной формой» классического симметричного arena Quake.




---




## XVII. 2007 — несостоявшийся новый Quake на id Tech 5 { #xvii-2007-quake-id-tech-5 }




Параллельно Quake Zero у id существовал публичный план: после браузерного эксперимента вторая внутренняя команда должна была заняться **новым Quake на id Tech 5**.




Направление описывалось как быстрый, преимущественно duel/competitive Quake с современными stats, matchmaking, spectating и tournament infrastructure. Quake Zero должен был стать полигоном для проверки сервисных систем, которые затем перейдут в большой новый проект.




Эта игра так и не материализовалась.




К 2011 id уже прямо говорит, что внутри компании никто не делает новый Quake: одна команда занята RAGE, другая — Doom.




Нельзя честно назвать этот проект «Quake 5, отменённый на 70%». Публичных доказательств большого production-билда нет. Но это важный потерянный путь серии: **id действительно планировала ещё один чистый arena Quake на новом поколении технологии**.




Вместо него долгую жизнь получает Quake Live, а следующая полноценная новая игра появится только в 2016–2017.




---




## XVIII. 2010 — Quake Arena Arcade: поздний консольный Q3 { #xviii-2010-quake-arena-arcade-q3 }




Xbox 360 получает **Quake Arena Arcade** спустя одиннадцать лет после оригинального Quake III.




К этому моменту консольный FPS уже решил проблему twin-stick управления через Halo и Call of Duty. Поэтому задача не в том, «можно ли вообще играть шутер на геймпаде», а в том, **можно ли нормально играть именно Quake**.




Версию слегка адаптируют по темпу, добавляют Xbox Live, matchmaking, до 16 игроков, новые карты и campaign-like challenge structure.




Но время релиза работает против неё. В 2010 рядом существуют Halo: Reach, Call of Duty: Black Ops, Battlefield и уже сам Quake Live на PC. Arena Arcade остаётся любопытной консольной веткой, но не новым центром серии.




---




## XIX. 2016–2022 — Quake Champions: как модернизировать Quake и не перестать быть Quake { #xix-20162022-quake-champions-quake-quake }




После многих лет без новой номерной игры Bethesda/id наконец объявляет **Quake Champions**.




Главная дизайнерская проблема проекта звучит почти неразрешимо:




> Quake III/Live уже прекрасно работают. Что вообще добавить в новый Quake, чтобы он не был просто тем же самым с новой графикой?




Ответ:




```
Quake III gameplay foundation
+
Quake I dark/eldritch aesthetics
+
modern hero/champion layer
```




И это рождает самый спорный эксперимент серии.




#### Контекст 2016 года { #2016 }




Важно понимать, почему вообще появилась идея Champions. Рынок multiplayer за пятнадцать лет полностью изменился. Quake III создавался в эпоху server browsers, LAN и почти полного отсутствия persistent progression.




В 2016 вокруг находятся:




- CS:GO;

- League of Legends;

- Dota 2;

- Team Fortress 2;

- Rainbow Six Siege;

- только что вышедший Overwatch;

- вскоре PUBG/Fortnite.





Современная multiplayer-игра ожидает персонажей, progression, matchmaking, live updates и долгосрочную retention-модель.




Просто выпустить «Quake III с красивой графикой» кажется коммерчески недостаточно. Champions — попытка встроить Quake в этот новый язык, не уничтожив его механический фундамент.




---




### Champions — игроки больше не симметричны { #champions }




Quake III:




```
Ranger = Visor = Anarki
```




Разные модели, но одна механическая основа.




Champions:




```
Champion
├─ health
├─ armor
├─ speed
├─ hitbox
├─ movement model
├─ passive ability
└─ active ability
```




Например Ranger получает Dire Orb — бросаемый артефакт, к которому можно телепортироваться. Doom Slayer получает double jump. Slash — crouch slide. Athena — grappling hook. Anarki и Sorlag несут air-control lineage.




И вот здесь находится самая умная часть Champions: **разные персонажи фактически сохраняют разные исторические варианты Quake movement внутри одной игры**.




Это намного интереснее простого «Quake скопировал Overwatch». Champion может менять не только cooldown-ability, но и саму кинематику персонажа.




Slash через crouch slide несёт Quake 4-style движение. Anarki/Sorlag дают более сильный air control. Doom Slayer приносит double jump. Athena меняет traversal grappling hook'ом.




То есть roster одновременно становится музеем истории Quake physics.




Это очень авторская попытка решить старую проблему серии:




> QW-player хочет одно движение, Q3-player другое, Q4-player третье. Какое считать правильным?




Champions отвечает: **выбирай персонажа**.




Вместо выбора:




> какой Quake movement считать правильным?




игра отвечает:




> несколько сразу.




---




### Но цена — разрушение абсолютной симметрии { #_10 }




Классический Duel красив именно тем, что оба игрока получают одинаковые правила.




Champions добавляет matchup:




```
Nyx ≠ Sorlag
Slash ≠ Clutch
Ranger ≠ Doom Slayer
```




Теперь часть результата можно объяснять не только skill/map-state, но ещё и свойствами выбранного Champion.




Для hero shooter это естественно. Для Quake — философский конфликт.




---




### Первый Duel вообще пытался переизобрести Duel { #duel-duel }




Изначально игрок выбирает несколько Champions, которые работают почти как жизни/roster fighting game. После смерти один Champion выбывает, игрок переходит к следующему.




Идея интересная: добавить draft/counter-pick layer поверх Quake.




Но она слишком далеко отходит от чистого timelimit Duel. Со временем Champions возвращается к более традиционному формату, а Quake Pro League строится уже вокруг Timelimit Duel.




Серия снова совершает круг:




```
«давайте переизобретём Quake»
↓
несколько лет экспериментов
↓
«классический Quake вообще-то был неплохо придуман»
```




---




### Технологически это тоже необычный Quake { #quake_2 }




Champions не становится витриной нового id Tech, как первые части. Разработка идёт совместно с Saber Interactive, используется смешанная технологическая база.




Это символическое изменение роли бренда. Когда-то Quake был названием игры, через которую Кармак показывал новое поколение 3D-engine. Champions уже прежде всего **game design/product experiment**, а не технологический манифест id.




---




### F2P, currencies, Battle Pass { #f2p-currencies-battle-pass }




Champions проходит почти весь набор live-service-механик эпохи:




- free-to-play;

- unlockable Champions;

- premium currency;

- cosmetics;

- progression;

- Battle Pass;

- challenges.





Снаружи кажется, что это должно сделать Quake современнее и доступнее.




Но оно не решает главную проблему Quake:




```
новичок всё ещё встречает человека,
который 20 лет strafe-jump'ит,
считает items,
знает spawn'ы
и попадает Rail
```




Champion не уничтожает skill gap. Он просто добавляет ещё один слой знаний поверх уже сложной игры.




Представим новичка. Он выбрал красивого персонажа, понял ability и даже знает своё оружие. Но против него человек, который:




- движется по карте быстрее;

- слышит каждый pickup;

- знает respawn Mega/Heavy;

- понимает spawn logic;

- заранее контролирует Rocket/Rail/LG;

- читает маршрут по звуку;

- имеет десять лет Duel experience.





Ability не делает эту разницу исчезнувшей. Иногда она даже усложняет объяснение поражения: теперь игроку нужно понимать ещё и matchup, разные hitboxes/stacks/passives.




Вот почему Champions оказался в почти математически неудобной позиции. Чтобы стать намного доступнее, нужно было бы упростить именно фундаментальный Quake. Но тогда старые игроки закономерно спрашивают, зачем им такой Quake, если Quake Live уже существует.




Именно поэтому Champions оказывается одновременно:




- слишком Quake для массовой hero-shooter аудитории;

- недостаточно чистым Quake для части пуристов.





---




### Лор наконец возвращается { #_11 }




Champions очень важен не только gameplay'ем. Он впервые серьёзно пытается придать серии общую метафизику.




Возвращаются:




- Ranger;

- Elder Gods;

- Dreamlands;

- gothic/eldritch visual language;

- старые враги/персонажи первого Quake;

- Strogg;

- Doom Slayer;

- B.J. Blazkowicz.





Ranger получает продолжение собственной истории, а Dire Orb связывается с победой над Shub-Niggurath.




Это не делает Doom, Wolfenstein, Q1 и Q2 одной обычной хронологией. Скорее Arena/Dreamlands становятся **надпространством**, способным соединять разные миры и времена.




---




### Quake Pro League { #quake-pro-league }




Champions не становится массовым хитом, но даёт competitive Quake ещё несколько лет официальной большой жизни.




Quake Pro League возвращает регулярные сезоны, LAN stages, QuakeCon World Championships и поколение игроков, в котором старые легенды пересекаются с новыми.




Это ещё один аргумент, почему Champions нельзя списывать как провал. Он не стал новым Q3, но фактически продлил профессиональную историю Quake на целую эпоху.




---




### Пять лет Early Access { #early-access }




Champions выходит в Early Access в августе 2017, а полноценный 1.0-релиз получает только в августе 2022.




К моменту «релиза» игре уже пять лет, F2P-период давно идёт, meta несколько раз перестроена, а первоначальное представление о Duel изменено.




Это очень характерная судьба live-service эпохи: версия 1.0 становится скорее административной отметкой, чем моментом рождения продукта.

## XX. 2019 — Quake II RTX: Quake снова продаёт видеокарты { #xx-2019-quake-ii-rtx-quake }




Quake II RTX — не definitive edition и не попытка сделать лучшую игровую версию Quake II.




Это технологическая демонстрация.




NVIDIA использует знакомую игру 1997 года как витрину real-time path tracing.




И здесь история красиво замыкается:




```
1997
GLQuake объясняет,
зачем нужен 3D raster accelerator

2019
Quake II RTX объясняет,
зачем нужны RT cores
```




Старая игра хороша для демонстрации именно потому, что пользователь понимает исходный материал. Можно буквально сравнить один и тот же коридор в обычной rasterized версии и в path-traced освещении.




Quake снова становится benchmark-культурой, только спустя два десятилетия.




---




## XXI. 2021 — Quake Enhanced: серия возвращается к самой первой игре { #xxi-2021-quake-enhanced }




На 25-летие выходит современное переиздание первого Quake от Nightdive при участии id и MachineGames.




Главная философия очень отличается от Champions:




> Quake не обязательно переизобретать. Возможно, его надо просто нормально сохранить и снова сделать доступным.




### KEX и сохранение оригинала { #kex }




Nightdive использует KEX как современную платформенную оболочку: renderer, input, audio, современные API и консольные платформы, при этом сама логика игры максимально сохраняет поведение оригинала.




Добавляются:




- widescreen;

- высокий framerate;

- до 4K;

- современные консоли;

- controller support;

- crossplay;

- online multiplayer;

- split-screen;

- bots;

- QoL.





При этом игра не превращается в «Quake с PBR 8K texture pack». Оригинальная низкополигональная, угловатая эстетика сохраняется.




---




### Trent Reznor наконец снова нормальная часть игры { #trent-reznor_1 }




Оригинальный Quake хранил музыку как CD Audio tracks, поэтому многие цифровые версии годами запускались без soundtrack.




Переиздание возвращает музыку как штатный элемент, и это намного важнее, чем кажется. Quake без ambient/industrial soundscape Reznor ощущается как другая игра.




---




### Полный исторический пакет { #_12 }




Внутри сразу доступны:




```
Quake
Scourge of Armagon
Dissolution of Eternity
Dimension of the Past
Dimension of the Machine
```




Позднее через Add-ons добавляется Quake 64 и community-контент.




Ремастер постепенно превращается не просто в новую версию игры, а в **официальную платформу Quake I**.




#### Почему этот подход лучше обычного «ремастера с 4K» { #4k }




Nightdive фактически строит несколько уровней сохранения одновременно.




Для новичка есть современный executable: controller, widescreen, crossplay, нормальное меню.




Для исторического игрока сохранены оригинальные gameplay assumptions и возможность отключать часть визуальных улучшений.




Для community существует отдельный мир source ports и оригинальной PC-версии.




То есть переиздание не пытается уничтожить старую экосистему словами «теперь только наша definitive version правильная». Оно становится удобной официальной точкой входа.




#### Quake 64 и Add-ons { #quake-64-add-ons }




Встроенная Add-ons system превращает ремастер ещё и в музей. Quake 64 получает официальную современную жизнь, а затем Bethesda начинает курировать community maps/mods.




Это очень необычная форма preservation: сохраняется не только то, что выпустила id, но и лучшие вещи, которые выросли вокруг игры.




---




### Dimension of the Past { #dimension-of-the-past }




MachineGames впервые возвращается к Quake ещё в 2016 году, к двадцатилетию, выпуская новый эпизод для оригинальной игры.




В 2021 он становится штатной частью переиздания.




Это очень важный культурный сигнал: современная AAA-студия считает нормальным в XXI веке делать новые BSP-карты для FPS 1996 года.




---




### Dimension of the Machine { #dimension-of-the-machine }




Специально к ремастеру MachineGames делает существенно более крупную новую campaign.




И здесь особенно хорошо видно, что происходит, если оставить Quake gameplay, но снять железные ограничения Pentium 1996 года:




- огромные пространства;

- более сложная архитектура;

- длинные sightlines;

- большая encounter density;

- огромные механические конструкции.





Но оружие, movement и враги остаются в основе теми же.




Это важный эксперимент: **игровая система Quake пережила собственную исходную технологию**.




---




## XXII. Source ports и mapping-сцена — почему Quake I вообще не был мёртвым { #xxii-source-ports-mapping-quake-i }




Между 1999 и 2021 нет двадцатилетней пустоты.




В декабре 1999 id открывает исходники Quake под GPL. Assets остаются коммерческими, но engine можно портировать и расширять.




Оригинальные limits создавались под железо 1996 года. Community постепенно снимает их, и mapping начинает развиваться далеко за пределы того, что могла позволить id.




### QuakeSpasm { #quakespasm }




Философия:




> сохраняем классический Quake, но делаем его нормальным современным приложением.




Современный input, resolutions, music playback, 64-bit, SDL и снятые limits.




### DarkPlaces { #darkplaces }




Другая крайность: намного более агрессивная модернизация renderer и effects, dynamic lighting, shaders и расширенные возможности.




### Ironwail { #ironwail }




Современная faithful-ветка с высокой производительностью и QoL, удобная для огромных новых карт.




---




### Arcane Dimensions { #arcane-dimensions }




Главный символ современной mapping-сцены.




Проект начинается в 2014-м и выходит крупной версией в 2015-м. Он добавляет:




- новых monsters;

- новые варианты старых enemies;

- weapon upgrades;

- новые environmental systems;

- breakables;

- большие нелинейные карты;

- огромные объёмы geometry.





Оригинальный engine уже физически не может запускать такой content без снятия limits.




Arcane Dimensions задаёт тот же вопрос, который позже будет задавать MachineGames:




> каким может быть Quake level design, если игра остаётся Quake, а hardware limits 1996 года больше не существуют?




Именно поэтому официальное возвращение новых Quake I-campaigns в 2021 выглядит естественно. Community двадцать лет уже доказала, что пространство для развития есть.




---




### Add-ons: community возвращается внутрь официального Quake { #add-ons-community-quake }




Nightdive/Bethesda начинает включать знаменитые community-проекты через официальное меню Add-ons. Honey и другие работы получают новую аудиторию внутри штатного переиздания.




Круг замыкается:




```
id создаёт Quake
↓
community двадцать лет развивает его
↓
официальный Quake начинает курировать community
```

## XXIII. 2023 — Quake II Enhanced: ремастер, который позволяет себе исправлять игру { #xxiii-2023-quake-ii-enhanced }




Nightdive возвращается к Quake II, но теперь подход смелее.




Quake I Enhanced в основном говорит:




> оригинал почти идеален, главное ничего не сломать.




Quake II Enhanced говорит:




> оригинал отличный, но некоторые вещи реально можно закончить и улучшить.




Пакет огромный:




```
Quake II
The Reckoning
Ground Zero
Quake II 64
Call of the Machine
```




Плюс оригинальная классическая PC-версия остаётся доступной отдельно.




---




### Улучшенный AI { #ai }




Это одно из самых важных изменений.




В Quake II Strogg по лору — разумная военно-технологическая цивилизация, но AI 1997 года часто ведёт себя как простой monster logic.




Nightdive улучшает navigation и поведение:




- враги лучше преследуют;

- спрыгивают с уступов;

- меняют позицию;

- двигаются во время стрельбы;

- flying enemies получают более нормальную кинематику;

- часть идей Ground Zero распространяется на базовую игру.





То есть gameplay действительно немного меняется, но в сторону того, **какой сама идея Strogg всегда хотела быть**.




---




### Restored mechanics { #restored-mechanics }




Особенно красивый подход — использование старых недоделанных animations/assets.




Berserker получает прыжковую атаку, Parasite — более развитое поведение хобота и промахов. Nightdive не просто придумывает новые способности через 26 лет, а иногда буквально заканчивает идеи, следы которых лежали внутри оригинальных assets.




Это превращает ремастер в форму реставрации незавершённого дизайна.




#### Почему изменения здесь не воспринимаются как святотатство { #_13 }




У первого Quake основная механика почти идеально самодостаточна. Любое глубокое изменение легко ломает характер игры.




Quake II имеет больше вещей, которые очевидно ограничены production 1997 года: AI navigation, отдельные незаконченные attacks, менее удобная ориентация внутри unit'ов.




Поэтому Nightdive может позволить себе более активную реставрацию при важном условии: **оригинальная версия всё ещё лежит рядом**.




Если человеку нужен буквально Quake II 1997 — пожалуйста. Enhanced может быть смелее, потому что не стирает источник.




---




### Компас { #_14 }




Hub/unit-структура Quake II хороша, но игрок после перерыва легко забывает, куда идти. Enhanced добавляет опциональный compass.




Важно, что level design не переписывается и не превращается в GPS-коридор. Если потерялся — нажал кнопку, получил направление, продолжил исследование.




Это очень хороший пример QoL, который уважает структуру оригинала.




---




### Quake II 64 наконец официально выходит из N64 { #quake-ii-64-n64 }




Nightdive включает всю альтернативную N64-campaign в основной пакет с современным renderer/input.




Это превращает старый эксклюзив в полноценную часть истории Quake II.




---




### Call of the Machine { #call-of-the-machine }




MachineGames делает 28 campaign levels и отдельную hub-структуру с несколькими операциями.




В отличие от осторожной Dimension of the Machine, здесь используются элементы разных официальных Q2-expansions. Старые враги, оружие и mechanics превращаются в общую палитру.




Encounter density значительно выше, чем могла выдержать машина 1997 года. Получается почти **Quake II All-Stars**, собранный современными level designers.




И лор Strogg неожиданно расширяется до более странных пространственно-временных концепций — Machine и Strogg-Maker.




---




## XXIV. 2026 — Dawn of the Machine: оригинальный Quake всё ещё получает новые кампании { #xxiv-2026-dawn-of-the-machine-quake }




К 30-летию Quake MachineGames выпускает **Dawn of the Machine** — новый официальный эпизод для игры 1996 года.




Это один из самых показательных фактов всей истории серии.




Не spiritual successor.




Не remake.




Не fan mod.




**Официальный Quake получает новый большой content через 30 лет после релиза.**




Причём MachineGames становится смелее, чем в Dimension of the Machine. Появляются новые варианты врагов, оружия и progression-идеи. Команда сама признаёт, что в 2021 слишком осторожно держалась за исходную палитру.




Dawn экспериментирует с тем, насколько далеко можно расширить Quake, не перестав быть Quake.




И это особенно важно для будущего бренда: в 2020-х именно Q1-линия оказывается самой творчески активной частью серии.




---




## XXV. Странные порты и платформы — Quake как универсальный тест «а на этом запустится?» { #xxv-quake }




После открытия исходников Quake постепенно становится чем-то вроде технологического Hello World для настоящего 3D. Но даже до GPL id и партнёры успевают перенести игру на удивительный набор платформ.




### Macintosh, Amiga и RISC OS { #macintosh-amiga-risc-os }




Mac получает коммерческий порт, включая варианты, работавшие через QuickDraw 3D RAVE и 3dfx. Это прекрасный снимок эпохи до полной стандартизации consumer 3D APIs.




Amiga получает официальный коммерческий Quake уже после банкротства Commodore — на сильно прокачанных 68040/68060-машинах, желательно с RTG-графикой. Сам факт того, что Quake становится причиной апгрейда «мертвой» платформы, хорошо показывает культурный вес игры.




На RISC OS / Acorn появляется ArcQuake и коммерческие пакеты. Quake на ARM в 90-х выглядит абсолютной экзотикой; через десятилетия ARM станет архитектурой огромной части мобильного мира и современных Mac.




---




### Quake Arcade Tournament Edition { #quake-arcade-tournament-edition }




Один из самых странных официальных Quake — аркадный автомат конца 90-х.




Внутри фактически стоит PC:




```
Pentium-class system
Windows 95
Quantum3D accelerator
```




Игрок управляет Quake большим trackball'ом и кнопками.




Некоторые конфигурации имеют redemption mechanics: убийства/награды могут приводить к печати призовых билетов.




То есть технологическая мечта Кармака:




```
BSP
client/server
3D acceleration
```




в аркадной индустрии внезапно превращается в:




> «за убийство Ogre автомат распечатает талончик».




Проект остаётся редчайшей веткой серии, но прекрасно показывает, насколько широким считался потенциал Quake как платформы.




---




### Dreamcast Quake I — порт, который не вышел { #dreamcast-quake-i }




После GPL Titanium Studios делает работающий Quake для Dreamcast через Windows CE/Direct3D. По воспоминаниям команды, базовый порт удалось поднять примерно за девять дней — огромный контраст с многомесячным инженерным насилием Saturn-версии.




Dreamcast уже настолько ближе к обычному современному 3D-компьютеру, что Quake перестаёт быть «невозможным портом» и становится обычной software-engineering задачей.




Коммерческого релиза не происходит. Оригинальный prototype build десятилетиями остаётся почти потерянным и нормально сохраняется только в 2026 году.




---




### GBA Quake — один программист снова пытается сделать невозможное { #gba-quake }




Randy Linden, автор легендарного SNES Doom, в начале 2000-х экспериментирует с собственным 3D-engine для Game Boy Advance.




GBA не имеет нормального hardware 3D accelerator, но Linden пишет огромный объём ARM assembly и получает полноценное polygonal пространство, в котором работает Quake-like E1M1 с врагами, оружием и секретами.




Важно: это не отменённый официальный проект id. Это независимый proof of concept, который потенциально можно было бы показать владельцам Quake.




Он так и не становится commercial product и позднее превращается в другую технологическую линию.




---




### Zeebo { #zeebo }




В 2009 Quake и Quake II выходят на бразильской digital-only консоли Zeebo — ARM-устройстве с мобильным GPU и загрузкой игр через cellular network.




Это ещё один отличный символ: спустя 13 лет после релиза Quake снова используется как доказательство того, что новая дешёвая платформа умеет «настоящее 3D».




---




### После GPL список платформ фактически теряет смысл { #gpl }




Когда source открыт, дальше Quake попадает куда угодно:




- Pocket PC;

- Symbian;

- PSP;

- Nintendo DS;

- Vita;

- Android;

- Rockbox/MP3-плееры;

- Raspberry Pi-derived среды;

- VR-порты;

- современные handhelds.





Начиная с этого момента вопрос «на каких платформах выходил Quake» надо разделять на:




1. официальный коммерческий релиз;

2. официальный/партнёрский tech demo;

3. prototype;

4. community source port.





Иначе список становится практически бесконечным.

## XXVI. Speedrunning и machinima — demo system порождает две культуры { #xxvi-speedrunning-machinima-demo-system }




Quake не изобретает саму идею скоростного прохождения: Doom-сцена уже активно соревнуется по времени. Но Quake даёт идеальную среду для развития явления.




### Demo system { #demo-system }




Quake умеет записывать игровые события в компактный `.dem`, который затем воспроизводит сам engine.




Это не видеофайл. Поэтому в эпоху медленного интернета можно распространять полноценные прохождения и матчи в очень маленьком размере.




Из одной технической функции вырастают две разные культуры.




---




### Quake Done Quick { #quake-done-quick }




В 1997 команда Quake done Quick выпускает полное Nightmare-прохождение игры примерно за двадцать минут, затем ещё быстрее.




Speedrun начинает использовать Quake mechanics не так, как обычная игра:




- rocket jumps;

- grenade jumps;

- bunny/strafe movement;

- пропуск боёв;

- хитрые маршруты;

- эксплуатация геометрии и физики.





Игрок уже не просто «хорошо проходит уровень». Он исследует движок как систему оптимизации времени.




Позднее из этой культуры вырастет Speed Demos Archive и значительно более широкая internet speedrunning-сцена.




---




### Machinima { #machinima }




Другая ветка спрашивает:




> если demo можно воспроизводить внутри 3D-engine, почему бы не использовать game world как съёмочную площадку?




**Diary of a Camper** 1996 года — один из первых широко известных постановочных фильмов внутри 3D-игры.




Игроки становятся актёрами, карты — декорациями, camera tools — операторской работой.




Дальше появляются Quake Movies, монтаж demo-файлов и сама идея machinima.




Таким образом один Quake demo format одновременно поддерживает:




```
«как быстро это можно сделать?»
→ speedrunning

и

«как превратить это в фильм?»
→ machinima
```

## XXVII. Competitive Quake — от Ferrari Кармака до Quake Pro League { #xxvii-competitive-quake-ferrari-quake-pro-league }




Quake — один из самых чистых примеров того, как маленький ruleset может породить несколько разных видов спорта.




### Duel { #duel }




Главная дисциплина:




```
1v1
+
aim
+
movement
+
item control
+
timing
+
positioning
+
psychology
```




Игрок соревнуется не только в перестрелке. Он управляет картой во времени.




MegaHealth и armor — ресурсы с respawn timers. Успешный бой даёт лучшую позицию, лучшая позиция — следующий предмет, предмет — лучший stack, stack — преимущество в следующем бою.




Поэтому небольшая разница в классе игроков может быстро превращаться в разгромный счёт.




---




### TDM { #tdm }




Team Deathmatch превращает item economy уже в командную задачу. Нужно распределять оружие, контролировать ключевые зоны и понимать, кто именно сейчас должен забирать определённый ресурс.




QW TDM особенно развивает клановую культуру Европы.




---




### CTF { #ctf }




Threewave превращает Quake в objective sport. Теперь важны маршруты, скорость перемещения, оборона базы, escort и coordinated attack.




---




### Clan Arena { #clan-arena }




Rocket Arena-lineage выкидывает item economy и оставляет round-based pure combat. Это намного проще для входа, но сохраняет огромное пространство для aim/movement mastery.




---




### DeFRaG { #defrag }




Противника вообще нет. Спортом становится traversal.




---




### Поколения игроков { #_15 }




#### Thresh { #thresh }




Ранняя суперзвезда, Ferrari Кармака, популяризация нового представления о professional gamer и даже стандарта управления.




#### Fatal1ty { #fatal1ty }




Один из первых людей, превращающих pro-gaming в полноценный персональный бренд.




#### Cooller { #cooller }




Архетип стратегического Duel: timing, positioning, чтение противника и состояние карты не менее важны, чем aim.




#### rapha / cYpheR { #rapha-cypher }




Эпоха Quake Live особенно хорошо показывает два стилистических полюса: невероятно яркая механика/скорость против почти шахматного контроля и prediction. Разумеется, оба игрока сильны во всём, но контраст хорошо показывает многомерность Duel.




---




### Почему Quake никогда не стал самым массовым esport { #quake-esport }




Те же качества, которые делают его великолепным спортом, мешают массовости.




Skill gap огромен и непрозрачен. Новичок может проигрывать не только потому, что хуже стреляет, но потому что:




- медленнее перемещается;

- не знает timers;

- не знает маршруты;

- не понимает spawns;

- отдаёт оружие;

- неверно читает звук.





Он видит результат, но не всегда понимает причину.




Counter-Strike или team games могут распределить ответственность между игроками и дать понятные роли. Duel Quake оставляет человека один на один со всеми собственными ошибками.




Поэтому Quake остаётся меньшей, но невероятно стойкой дисциплиной.




---




### Quake Live и Champions продлевают профессиональную линию { #quake-live-champions }




Quake Live собирает разрозненную Q3-сцену и получает крупные IEM, DreamHack, ESWC, QuakeCon и FACEIT-турниры.




Champions позже запускает Quake Pro League и ещё несколько лет поддерживает официальный global circuit.




Даже когда QPL заканчивает эпоху большой лиги, Quake не исчезает: QW, CPMA, DeFRaG, Quake Live и Champions продолжают иметь отдельные community tournaments.




Это редкий случай, когда несколько поколений одной базовой механики одновременно продолжают существовать как самостоятельные дисциплины.

## XXVIII. Лор — три разных Quake и поздняя попытка их склеить { #xxviii-quake }




### Ветка 1: Ranger / eldritch Quake { #1-ranger-eldritch-quake }




Оригинальная линия:




```
Earth
↓
Slipgate experiments
↓
вторжение из иных измерений
↓
Ranger
↓
four Runes
↓
Shub-Niggurath
```




Поздний lore Champions делает судьбу Ranger значительно мрачнее. Он не просто убивает Shub и возвращается к нормальной жизни. Он оказывается фактически потерян среди Dreamlands/чужих измерений, постепенно теряя связь с прошлым.




Dire Orb Champions связывается с победой над Shub. Death Knight становится не просто старым monster, а конкретным существом, выброшенным вместе с Ranger в большую dimensional cosmology.




MachineGames в 2026 продолжает именно эту ветку через тему иллюзорных миров, Outer Gods и бесконечных циклов.

### Ветка 2: Strogg War { #2-strogg-war }




Здесь continuity намного чище:




```
Enemy Territory: Quake Wars
↓
Strogg invade Earth
↓
человечество выживает
↓
Quake II
↓
Bitterman атакует Stroggos
↓
Makron defeated
↓
Quake 4
↓
война продолжается / Matthew Kane
```




The Reckoning, Ground Zero и поздний Call of the Machine расширяют тот же conflict.




Это единственная ветка Quake, где «следующая часть» можно было бы написать почти без метафизики: просто продолжить войну.




---




### Ветка 3: Arena Eternal { #3-arena-eternal }




Quake III решает проблему несовместимых вселенных очень элегантно: Vadrigar вытаскивают лучших воинов **из разных времён и пространств** и заставляют их бесконечно сражаться.




Поэтому рядом могут существовать Ranger, Bitterman, Doom-персонажи и новые гладиаторы без необходимости утверждать, что все их домашние истории происходят в одной обычной timeline.




Arena Eternal изначально — crossover framework.




---




### Quake Champions как надканон { #quake-champions }




Champions расширяет Arena-концепцию через Dreamlands и Elder Gods.




Теперь можно представить:




```
разные миры / времена
        │
        ↓
Dreamlands / dimensional reality
        │
        ↓
Arena / Champions
```




Strogg technology тоже умеет создавать dimensional effects, поэтому Athena/Strogg &amp; Peeker могут попасть в эту систему.




Но отсюда нельзя делать лишние выводы вроде:




> Shub создала Strogg




или




> Doom и Quake происходят на одной обычной Земле.




Правильнее говорить: **Quake Champions создаёт метафизический crossover layer над отдельными continuity**.

## XXX. Коммерческие моды и total conversions 90-х { #xxx-total-conversions-90- }




Вокруг Quake быстро возникает ещё один рынок: модификации начинают продаваться в обычных коробках.




Для первого Quake заметны:




- Malice;

- Shrak;

```




Quake делает все три ступени нормальными буквально одновременно.

## XXXI. Почему Quake так сильно повлиял на индустрию { #xxxi-quake }




### 1\. Настоящий 3D { #1-3d }




Quake делает полноценный polygonal FPS-мир массовым объектом и показывает, как проектировать уровни, управление и combat в настоящем трёхмерном пространстве.




### 2\. Современная PC-модель { #2-pc- }




За три года вокруг одной серии закрепляется почти современная схема игрового компьютера:




```
CPU → simulation
GPU → real-time graphics
mouse → camera/aim
WASD → movement
Internet → multiplayer
```




### 3\. Online architecture { #3-online-architecture }




Quake → client/server.




QuakeWorld → prediction, internet-conscious networking и master-server infrastructure.




Quake III → snapshot/delta model и зрелая competitive client/server architecture.




### 4\. Моддинг как R&amp;D { #4-rd }




Community не просто добавляет карты. Она изобретает новые виды FPS:




```
Threewave CTF
→ objective FPS

Team Fortress
→ class-based FPS

Rocket Arena
→ pure arena combat

Action Quake 2
→ realistic round-based tactical FPS

DeFRaG
→ movement sport
```




### 5\. Моддинг как рынок труда { #5 }




Quake-scene становится школой индустрии:




- Team Fortress creators → Valve;

- Steven Polge/Reaper Bot → Epic/Unreal;

- Minh Le/Action Quake 2 → Counter-Strike;

- mappers/modders → профессиональные level/game designers.





### 6\. Engine licensing { #6-engine-licensing }




Quake нормализует идею «движок — самостоятельный коммерческий продукт». Отсюда GoldSrc, огромное количество id Tech-лицензиатов и дальнейшая middleware-культура.




### 7\. Open source { #7-open-source }




id продаёт cutting-edge technology, а спустя несколько лет открывает исходники старого поколения. Это создаёт source-port культуру, образовательную ценность и вторую жизнь игр.




### 8\. Esports { #8-esports }




Duel Quake помогает сформировать образ профессионального FPS-игрока и один из самых чистых индивидуальных форматов соревнования.




### 9\. Machinima / speedrunning / demo culture { #9-machinima-speedrunning-demo-culture }




Quake demo system становится инфраструктурой сразу для нескольких новых интернетных культур.

## XXXII. Что Quake представляет собой в 2026 году { #xxxii-quake-2026 }




К 2026 году под названием Quake реально существуют три идентичности.

gothic/industrial world
exploration

Именно здесь сегодня происходит наиболее заметное новое творчество.

### 3\. Quake II — отлично сохранённая, но спящая сюжетная сага { #3-quake-ii }

Это самая простая ветка для обычного sequel, но сейчас она развивается значительно меньше Q1.

### Какая идентичность фактически победила { #_16 }




Если смотреть на 2021–2026, ответ довольно очевиден:




**Quake I.**




Не потому что Quake II или arena-наследие забыты. А потому что именно странная смесь первого Quake оказывается самой уникальной в современном рынке.




Military sci-fi shooter можно сравнить с десятками современных игр.




Hero/arena multiplayer конкурирует с огромным live-service рынком.

```
сверхбыстрый precise FPS
+
gothic / eldritch horror
+
industrial technology
+
средневековая архитектура
+
непонятные dimensions
+
пространственный level design
```




до сих пор ощущается необычно.




Именно поэтому MachineGames всё активнее возвращается к Ranger-ветке.

современный hand-crafted single-player
```




Но крайне важно не превратить его просто в ещё один Doom.




Doom Eternal строится вокруг combat arenas и боевой resource economy.




Quake логичнее сделать **пространственным shooter**, где сам уровень является центральной системой:




- вертикальность;

- secrets;

- нелинейные маршруты;

- exploration;

- невозможная архитектура;

- скорость движения через мир;

- encounters как часть пространства, а не отдельные запертые арены.





Тогда combat остаётся быстрым и механически точным, но игра получает собственную идентичность рядом с современным Doom.




MachineGames выглядит естественным кандидатом именно потому, что её Quake Club уже последовательно исследует эту формулу с 2016 по 2026 год. Но на сентябрь 2026 это всё ещё логический вывод, а не официально объявленный Quake 6.

## XXXV. Финальный вывод { #xxxv }




Quake обычно вспоминают как «ту игру id после Doom, которая впервые была по-настоящему трёхмерной».




Это правда, но слишком мало.




За несколько лет вокруг Quake сформировались почти все основные элементы современного PC FPS:




```
настоящее 3D
+
mouse-look / WASD
+
hardware GPU
+
реальные FPS benchmarks
+
client/server networking
+
client-side prediction
+
Internet server ecosystem
+
моддинг как самостоятельная разработка
+
движок как лицензируемый продукт
+
competitive FPS
+
source release / source ports
```




А community практически сразу начала использовать эту платформу для создания новых жанровых форм:




```
Team Fortress
Threewave CTF
Rocket Arena
Action Quake 2
DeFRaG
machinima
speedrunning
```




Некоторые из них оказались важнее коммерчески, чем сам Quake. Из технологической и mod-культуры Quake прямо или косвенно вырастают Half-Life, Counter-Strike, Team Fortress, Unreal-боты, Source и Call of Duty lineage.




При этом сама франшиза так и не нашла одну стабильную идентичность. Quake I, Quake II и Quake III — почти три разные серии.




Иронично, что спустя тридцать лет наиболее живой творческой веткой снова становится первая: Ranger, Slipgates, eldritch dimensions и готический мир, от которого id когда-то почти случайно ушла в 1997 году.




В 1996 Quake был игрой, которая выглядела как будущее.




В 2026 он интересен уже по другой причине: **его базовые идеи оказались достаточно сильными, чтобы пережить собственное будущее**.
