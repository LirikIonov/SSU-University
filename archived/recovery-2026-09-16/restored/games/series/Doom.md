# Doom { #doom }




### DOOM Classic — единая база знаний { #doom-classic }




> Консолидированный справочник по всей обсуждённой классической ветке DOOM: происхождение серии, DOOM/DOOM II, официальные дополнения, консольные версии, DOOM 64, source-port и modding-культура, крупные WAD'ы, мобильные ответвления и современные ремастеры.

>
>
>
> Состояние базы: сентябрь 2026.
>
>
>
>
> Область: **классический DOOM / id Tech 1 / DOOM 64 и прямые ответвления**. DOOM 3, RAGE, отменённый DOOM 4, DOOM (2016), Eternal и The Dark Ages вынесены за пределы этого файла.

Главные выводы:




- **DOOM (1993)** создала грамматику современного FPS.

- **DOOM II** расширила словарь: SSG + лучший классический bestiary.

- **Ultimate Doom / E4** официально делает DOOM для игрока, который уже знает DOOM.

- **Master Levels** превращает моддера в профессионального level designer.

- **Final Doom** показывает, что community способна самостоятельно производить официальный DOOM.

- **Plutonia** демонстрирует более зрелое понимание DOOM II combat, чем большая часть оригинальной кампании.

- **PS1 Doom** доказывает, что порт может быть художественной интерпретацией.

- **DOOM 64** — полноценная альтернативная третья классическая DOOM, а не порт.

- **Source release 1997** превращает DOOM из игры в платформу.

- **Boom/MBF** создают стандартизированный язык расширенного classic mapping/gameplay.

- **ZDoom/GZDoom** превращают id Tech 1 почти в универсальный SDK.

- **Chocolate Doom** сохраняет противоположную крайность: точную историческую DOOM 1.9 вплоть до багов.

- **No Rest for the Living** показывает зрелый профессиональный DOOM II mapping без новых систем.

- **SIGIL/SIGIL II** показывают позднего John Romero как автора, который снова работает через ограничения и плотность, а не feature breadth.

- **Legacy of Rust** впервые за 30 лет официально расширяет classic DOOM новыми пушками и новыми типами врагов.

- **Nightdive/KEX** в 2024 году фактически сшивает официальный продукт, preservation и community ecosystem в одну платформу.





Наша устойчивая оценочная формула:




```
DOOM 1993
→ самая цельная исходная classic-кампания

DOOM II
→ лучший classic ruleset / combat toolkit

Plutonia
→ лучшее раннее официальное использование toolkit

DOOM 64
→ лучшее цельное classic DOOM-приключение

No Rest for the Living
→ один из лучших коротких официальных DOOM II map packs

Legacy of Rust
→ самая сильная официальная эволюция classic vocabulary,
  но местами менее компактная
```

## 1\. До DOOM: как id пришла к формуле { #1-doom-id }




### 1.1. Роли ранней id { #11-id }




```
John Carmack
→ engine / low-level / rendering / optimization

John Romero
→ tools / editors / gameplay / level design / production

Tom Hall
→ world / characters / fiction / humor

Adrian Carmack
→ art / gore / visual identity
```




Главная связка Carmack + Romero:




```
Carmack:
«что компьютер теперь может?»

Romero:
«что игроку интересно делать внутри этого?»
```




Именно эта связка особенно эффективно работала в период Keen → Wolfenstein → DOOM.




### 1.2. Hovertank One { #12-hovertank-one }




Ключевой шаг:
\- очень быстрый first-person;
\- плоские цвета;
\- упрощённая геометрия;
\- демонстрация того, что PC способен на быстрое first-person движение.




### 1.3. Catacomb 3-D { #13-catacomb-3-d }




Следующий шаг:
\- texture-mapped стены;
\- видимая рука/оружие;
\- монстры;
\- first-person начинает ощущаться как место, а не только технодем.




Линия:




```
Hovertank
→ скорость

Catacomb 3-D
→ texture + embodiment

Wolfenstein
→ arcade FPS

DOOM
→ полноценное пространство как система
```




### 1.4. Wolfenstein 3D { #14-wolfenstein-3d }




Ранние идеи stealth/body searching/body dragging были вырезаны, когда оказалось, что бегать и стрелять веселее.




Ключевой принцип ранней id:




> **слушать игру; если механика тормозит fun — выкинуть её.**




Пространство Wolfenstein ещё очень ограничено:
\- grid;
\- 90° стены;
\- одна высота;
\- без настоящей вертикальности.




DOOM рождается как желание снять эти ограничения.

## 2\. DOOM (1993) { #2-doom-1993 }




Дата релиза: **10 декабря 1993**.




### 2.1. Источники { #21 }




Ключевые культурные источники:
\- *Aliens*;
\- *Evil Dead*;
\- heavy metal;
\- D&amp;D компании;
\- демоны как более выразительная тема, чем очередные солдаты.




Кратко рассматривалась лицензия *Aliens*, но id отказалась от неё из-за внешних ограничений.




Название **DOOM** Romero взял из сцены *The Color of Money* с репликой «What’s in the case?» — «Doom».




### 2.2. Doom Bible и Tom Hall { #22-doom-bible-tom-hall }




Hall написал **Doom Bible**.




Его версия содержала:
\- именованных персонажей;
\- больше сюжета;
\- правдоподобную базу;
\- зоны;
\- adventure/RPG-системы;
\- идею места, а не просто уровня.




Конфликт философий:




```
Hall:
«я проектирую место»

Romero:
«я проектирую отличный уровень;
если он похож на место — хорошо»

Carmack:
«технология и gameplay важнее сюжетной надстройки»
```




Hall был не «неправ». Его направление позднее подтвердят Half-Life, Deus Ex и DOOM 3.




Проблема:
\- scope;
\- тип игры;
\- маленькая команда;
\- короткий production cycle.




Hall ушёл летом 1993 года.




### 2.3. Sandy Petersen { #23-sandy-petersen }




После Hall приходит **Sandy Petersen**.




Он быстро делает значительную часть Episodes 2 и 3.




Отсюда заметный стилистический разрыв:




```
Episode 1
→ Romero-school
→ clean / legible / spatial flow

Episode 2
→ страннее

Episode 3
→ ещё абстрактнее / менее ровно
```




### 2.4. DoomEd { #24-doomed }




Carmack построил engine.




Romero написал **DoomEd** для NeXTSTEP.




Критический вклад:
engine сам по себе не производит хорошие уровни.




Romero превращает:
\- vertices;
\- linedefs;
\- sectors;
\- heights;
\- textures;
\- Things;




в рабочий production workflow.




### 2.5. Технология { #25 }




DOOM всё ещё не true 3D в смысле Quake.




Основная модель:
\- sector-based world;
\- произвольные углы стен;
\- разные высоты пола/потолка;
\- окна;
\- лестницы;
\- lifts;
\- освещение;
\- sprites;
\- BSP/preprocessing.




Нет нормального произвольного room-over-room.




### 2.6. E1M1 { #26-e1m1 }




Один из лучших tutorial без текста.




Учит через архитектуру:
\- движение;
\- разные высоты;
\- двери;
\- окно;
\- видимые недоступные пространства;
\- секрет;
\- возвраты.




Ключевой Romero-приём:




```
покажи область заранее
↓
не дай сразу попасть
↓
проведи другим путём
↓
верни туда позже
```




Игрок строит mental map.




### 2.7. Movement { #27-movement }




Одна из причин бессмертия DOOM — мгновенное и очень быстрое управление.




Наша формула:




> **Doomguy — вектор скорости с дробовиком.**




Игрок управляет не реалистичным весом тела, а пространственным импульсом.




### 2.8. Enemy vocabulary { #28-enemy-vocabulary }




#### Zombie / Shotgun Guy { #zombie-shotgun-guy }




Hitscan:
\- cover;
\- priority;
\- LOS awareness.




#### Imp { #imp }




Projectile:
\- движение;
\- dodging.




#### Demon { #demon }




Melee space denial.




#### Cacodemon { #cacodemon }




Flying pressure.




#### Lost Soul { #lost-soul }




Charge/disruption.




#### Baron { #baron }




Tank / живая преграда.




### 2.9. Infighting { #29-infighting }




Враги способны задевать друг друга.




Следствие:




```
enemy
→ threat

и одновременно

enemy
→ resource / weapon
```




Одна из причин, почему простой AI создаёт глубокий combat.




### 2.10. Оружие { #210 }




#### Pistol { #pistol }




Быстро становится почти ненужным.




#### Shotgun { #shotgun }




Одна из лучших пушек FPS:
\- ясный диапазон;
\- точный ритм;
\- хорошая отдача;
\- полезен почти всегда.




#### Chaingun { #chaingun }




Контроль, stunlock, hitscan.




#### Rocket Launcher { #rocket-launcher }




Высокий damage + positional self-risk.




#### Plasma Rifle { #plasma-rifle }




Высокий DPS.




#### BFG9000 { #bfg9000 }




Сложнее визуального впечатления из-за вторичных damage traces.




### 2.11. Secrets { #211-secrets }




Лучшие secrets интегрированы в геометрию:
\- видишь предмет/область;
\- понимаешь, что туда можно попасть;
\- ищешь пространственную связь.




### 2.12. Automap { #212-automap }




Поддерживает:
\- исследование;
\- mental mapping;
\- понимание пространства.




### 2.13. Атмосфера { #213 }




Миф:




> DOOM \= бесконечный heavy metal power fantasy.




На деле много:
\- тишины;
\- странных треков;
\- звуков монстров за стенами;
\- тёмных помещений;
\- ожидания угрозы.




Bobby Prince сочетает metal-like MIDI и ambient.




### 2.14. Bosses { #214-bosses }




Bosses в целом слабее обычного encounter system.




- Cyberdemon — иконичен, но механически прост;

- Spider Mastermind — слабый final exam.





Поздняя история серии постоянно подтверждает:




> high-tier monster лучше работает как часть обычного пространства, чем как отдельная gimmick-арена.




### 2.15. Multiplayer { #215-multiplayer }




DOOM популяризирует:
\- co-op;
\- deathmatch;
\- LAN play.




Romero — главный evangelist deathmatch culture.




### 2.16. WAD architecture { #216-wad-architecture }




```
DOOM.EXE
→ engine / logic

DOOM.WAD
→ maps / textures / sprites / sounds / music
```




Это подготавливает будущую modding culture.




### 2.17. Shareware { #217-shareware }




Episode 1 распространяется бесплатно.




Эффект:
\- огромный охват;
\- люди сами копируют игру;
\- бесплатный episode \= marketing;
\- Doom распространяется вирусно.




### 2.18. Итог { #218 }




Сильнейшая черта:
**цельность.**




```
Episode 1
→ почти идеальный

Episode 2
→ хороший, страннее

Episode 3
→ менее ровный
```




> **DOOM 1993 создала грамматику современного FPS.**

## 3\. DOOM II: Hell on Earth (1994) { #3-doom-ii-hell-on-earth-1994 }




Дата релиза: **30 сентября 1994**.




### 3.1. Главное изменение { #31 }




Не новая engine revolution, а:




## combat vocabulary. { #combat-vocabulary }




```
DOOM
→ grammar

DOOM II
→ vocabulary
```




### 3.2. Super Shotgun { #32-super-shotgun }




Заполняет нишу:




```
Shotgun
→ мало burst

Rocket Launcher
→ много positional risk

SSG
→ сильный close-range burst
  + reload rhythm
```




Практически идеальная новая пушка.




### 3.3. Новые враги { #33 }




#### Chaingunner { #chaingunner }




Hitscan DPS, priority, LOS.




#### Hell Knight { #hell-knight }




Baron-lite.




#### Revenant { #revenant }




Быстрый, melee + projectile + homing.
Очень мобильное pressure.




#### Mancubus { #mancubus }




Area denial через широкий projectile pattern.




#### Arachnotron { #arachnotron }




Continuous lane pressure.




#### Pain Elemental { #pain-elemental }




Создаёт Lost Souls.
Проблема растёт, если его игнорировать.




#### Arch-vile { #arch-vile }




Один из лучших FPS-врагов:
\- timed LOS attack;
\- высокий damage;
\- resurrection;
\- мгновенно меняет priority.




Особенно важно:




> атакует уже выполненную игроком работу.




### 3.4. Кампания { #34 }




32 карты подряд.




Проблема:
Doom II engine плохо изображает Earth/city realism.




MAP13 Downtown — концептуально город, визуально коричневые коробки.




Кампания значительно менее цельная, чем DOOM I.




### 3.5. Ключевые карты { #35 }




#### MAP07 — Dead Simple { #map07-dead-simple }




Encounter-as-level.
Special triggers Mancubi/Arachnotrons.




#### MAP08 — Tricks and Traps { #map08-tricks-and-traps }




Лаборатория механик и infighting.




#### MAP13 — Downtown { #map13-downtown }




Неудачная попытка убедительного города.




#### MAP15 — Industrial Zone { #map15-industrial-zone }




Сильнее работает как большая нелинейная карта.




#### MAP23 — Barrels o’ Fun { #map23-barrels-o-fun }




Одна mechanic превращена в уровень.




#### MAP24 — The Chasm { #map24-the-chasm }




Запоминающаяся идея, мучительный platforming.




#### MAP29 — The Living End { #map29-the-living-end }




Сильная вертикальная spatial illusion Romero.




#### MAP30 — Icon of Sin { #map30-icon-of-sin }




Иконично, но плохой final exam:
gimmick вместо mastery.




### 3.6. DOOM II как платформа { #36-doom-ii }




Именно DOOM II становится главной базой WAD'ов:
\- полный classic arsenal;
\- SSG;
\- расширенный bestiary.




Итог:




```
DOOM I
→ лучшая классическая цельная кампания

DOOM II
→ лучший классический конструктор
```

## 5\. Master Levels for Doom II { #5-master-levels-for-doom-ii }




Дата: **26 декабря 1995**.




### 5.1. Контекст { #51 }




К 1995 BBS/Internet/CompuServe завалены WAD'ами.




Shovelware companies:
\- скачивают бесплатные WAD;
\- записывают на CD;
\- продают «900 LEVELS FOR DOOM».




id отвечает:
\- специально заказанными профессиональными картами;
\- бонусным огромным архивом Maximum Doom.




### 5.2. Shawn Green как scout { #52-shawn-green-scout }




Green просматривает примерно **500 community maps**.




Модель:




```
fan mapper
↓
id замечает
↓
contract
↓
official Doom
```




### 5.3. Авторы { #53 }




- Tim Willits;

- Christen Klie;

- John `Dr. Sleep` Anderson;

- Jim Flynn;

- Tom Mustaine;

- Sverre André `Cranium` Kvernmo.





### 5.4. 20 WAD, 21 карта { #54-20-wad-21 }




`TEETH.WAD`:
\- The Express Elevator to Hell;
\- secret `Bad Dream`.




Итого 21 playable map.




### 5.5. Это не кампания { #55 }




Карты создавались независимо:
\- разные authors;
\- map slots;
\- difficulty;
\- styles;
\- pistol-start balance.




Современные stitched campaigns удобны, но не соответствуют исходной структуре.




### 5.6. Авторы и школы { #56 }




#### Tim Willits { #tim-willits }




- Attack;

- Canyon.





Исторически особенно важен как modder → id employee.




#### Christen Klie { #christen-klie }




6 компактных карт.
Ближе к «ещё хорошие Doom II maps».




#### Tom Mustaine { #tom-mustaine }




- Paradox.
    Первая версия была отклонена как слишком близкая к MAP14 American McGee.





#### Jim Flynn { #jim-flynn }




- Titan Manor;

- Trapped on Titan.





Puzzle/system-heavy.
Позже важен для Boom.




#### John Anderson { #john-anderson }




5 карт своей Dante-inspired серии Inferno:
\- Virgil's Lead;
\- Minos' Judgement;
\- Nessus;
\- Geryon;
\- Vesperas.




#### Sverre Kvernmo { #sverre-kvernmo }




Сильнейший набор:
\- Bloodsea Keep;
\- The Express Elevator to Hell;
\- Bad Dream;
\- Mephisto's Maosoleum;
\- Black Tower.




### 5.7. Black Tower { #57-black-tower }




Главная концептуальная карта набора.




Огромная башня при отсутствии настоящего room-over-room.




Используются:
\- lifts;
\- teleport tricks;
\- heights;
\- route changes;
\- visual relationships.




Почти попытка построить Quake внутри Doom.




### 5.8. Express Elevator to Hell { #58-express-elevator-to-hell }




Центральный elevator как progression gimmick:
этаж → encounter → следующий этаж.




Очень сильная идея уровня.




### 5.9. Bad Dream { #59-bad-dream }




Короткий Cyberdemon challenge-joke.
Предвестник challenge/slaughter culture.




### 5.10. Bloodsea Keep { #510-bloodsea-keep }




Крепость в море крови.
Хорошая location fantasy.
Community уже лучше учится заставлять секторный engine изображать место.




### 5.11. Maximum Doom { #511-maximum-doom }




Примерно:
\- 1830 PWAD;
\- \~3487 levels.




Не curated quality set, а snapshot Internet/BBS-культуры 1995:
\- хорошие карты;
\- плохие карты;
\- первые работы;
\- conversions;
\- дубли;
\- нелицензированные звуки.




Исторически очень ценно.




### 5.12. Главное наследие { #512 }




Master Levels важнее людьми, чем кампанией.




```
Tim Willits → id
John Anderson → Blood / Unreal / Kingpin / Daikatana
Sverre Kvernmo → Xatrix / Redneck Rampage / Ion Storm
Tom Mustaine → Hipnotic / Ritual / SiN
Christen Klie → LucasArts
Jim Flynn → TeamTNT / Boom
```

## 7\. TNT: Evilution { #7-tnt-evilution }




TeamTNT готовит бесплатный 32-map megawad.




Незадолго до релиза Romero связывается с Ty Halderman.




id покупает проект.




### Сильные стороны { #_1 }




- 32 карты;

- новая музыка;

- новые textures;

- adventure feeling;

- большие пространства;

- попытки строить места.





### Слабые { #_2 }




- затянутость;

- switch hunting;

- низкая плотность отдельных больших карт.





TNT интереснее как adventure, чем как чистый combat package.

## 14\. PlayStation DOOM { #14-playstation-doom }




1995.

### 14.1. Технология { #141 }




Ключевой programmer:
Aaron Seeler.




Он работал рядом с Carmack и учился rendering.




PS1 affine texture mapping плохо подходит большим Doom-стенам.




Один из трюков:
стены дробятся на узкие vertical strips, уменьшая warping.




Renderer серьёзно переработан.




### 14.2. Память и CD { #142-cd }




Большой CD ≠ большая runtime RAM.




Level-specific assets загружаются отдельно.




Отсутствие Arch-vile связано именно с дорогим runtime animation footprint.




### 14.3. Содержание { #143 }




**59 карт**.




Смесь:
\- DOOM;
\- часть E4;
\- DOOM II;
\- Jaguar-derived maps;

### 14.4. Doom II vocabulary в старых картах { #144-doom-ii-vocabulary }




В старых Doom maps появляются:
\- SSG;
\- часть DOOM II monsters.




Официальный remix старой campaign.




### 14.5. Colored lighting { #145-colored-lighting }




Главная художественная победа.




Старые пространства получают новый эмоциональный смысл через цвет и затемнение.




### 14.6. Aubrey Hodges { #146-aubrey-hodges }




Вместо Bobby Prince — dark ambient.




Используются:
\- pitch shifting;
\- drones;
\- metallic noises;
\- PlayStation reverb;
\- score, похожий на environmental sound.




Игра становится заметно страшнее, не меняя core mechanics.




### 14.7. Особенные карты { #147 }




- Twilight Descends;

Усиленная вариация Spectre.




### 14.9. Redemption Denied { #149-redemption-denied }

### 14.10. Итог { #1410 }




PS1 Doom доказывает:




> старые mechanics можно оставить, а lighting/audio/presentation способны превратить игру в другой эмоциональный опыт.




Это непосредственная художественная предыстория DOOM 64.

## 16\. DOOM 64 { #16-doom-64 }




Дата: **31 марта 1997**.




Главный тезис:




## DOOM 64 — новая DOOM, а не порт. { #doom-64-doom }




Практически альтернативная DOOM III классической эпохи.




### 16.1. Происхождение { #161 }




PS1 Doom служит R&amp;D/production school для N64.




Williams/Midway получает creative freedom.




Рабочее название:
**Project Absolution**.




`Doom 3` id оставляла за собой, поэтому финальное название — Doom 64.




### 16.2. Команда { #162 }




Ключевые:
\- Aaron Seeler — lead programmer;
\- Sukru Gilman — art/3D;
\- Laurent Bezault — animation;
\- Aubrey Hodges — music/sound;
\- Midway/Williams level designers.




### 16.3. Технология { #163 }




Всё ещё sector-based, не Quake true 3D.




Но сильно расширена:
\- macros;
\- chained triggers;
\- transforming levels;
\- развитое colored lighting.




### 16.4. Новый art { #164-art }




Полностью новая identity:
\- textures;
\- weapons;
\- monster sprites;
\- gothic/horror style.




Монстров моделируют в 3D и рендерят в sprites.




### 16.5. Вырезанные DOOM II monsters { #165-doom-ii-monsters }




Нет:
\- Chaingunner;
\- Revenant;
\- Arch-vile;
\- Spider Mastermind.




Это уменьшает combat vocabulary.




### 16.6. Новые существа { #166 }




#### Nightmare Imp { #nightmare-imp }




Усиленный Imp.




#### Mother Demon { #mother-demon }




Новый final boss.




### 16.7. Unmaker { #167-unmaker }




Новая energy weapon.




Усиливается через Demon Keys.




### 16.8. Demon Keys { #168-demon-keys }




Находятся в secret maps.




Двойная награда:
1\. усиливают Unmaker;
2\. позволяют отключать monster portals на финальном MAP28.




Очень сильная интеграция exploration и campaign progression.




### 16.9. Ключевые карты { #169 }




- Staging Area;

- The Terraformer;

- Even Simpler;

- Dark Citadel;

- Hectic;

- The Absolution.





`The Terraformer` особенно хорошо показывает transforming geometry.




### 16.10. Adventure structure { #1610-adventure-structure }




Doom 64 сильнее Doom II ощущается как единое путешествие.




Плюсы:
\- compact maps;
\- location identity;
\- atmosphere;
\- environmental puzzles.




Минус:
иногда слишком любит switch hunting.




### 16.11. Aubrey Hodges { #1611-aubrey-hodges }




PS1 dark ambient развивается дальше.




Новая музыка уже пишется непосредственно под новые карты.




Формула:




```
classic Doom combat
+
gothic/horror atmosphere
```




### 16.12. Финал { #1612 }




Doom Marine решает остаться в Hell, чтобы предотвращать новые вторжения.




Очень удобный мост к будущей Slayer mythology.




### 16.13. Multiplayer { #1613-multiplayer }




В original N64 release отсутствует.




Для консоли с четырьмя controller ports — большая потерянная возможность.




### 16.14. Итог { #1614 }




По сочетанию:
\- classic gameplay;
\- цельная кампания;
\- atmosphere;
\- art direction;
\- adventure arc;
\- compactness;




**DOOM 64 реально может считаться лучшей classic DOOM как цельная игра.**

### 19.3. Главное наследие { #193 }

**Boom-compatible map**.




Boom становится договором между mapper и port.

## 22\. ZDoom → GZDoom { #22-zdoom-gzdoom }

## 23\. UDMF { #23-udmf }




Universal Doom Map Format.




Текстовый и расширяемый формат карт.




Причина:
старый binary Doom/Hexen format уже не способен нормально выражать количество свойств современных ports.




UDMF позволяет:
\- задавать свойства явно;
\- использовать namespaces;
\- расширять формат без очередных binary hacks.

## 41\. No Rest for the Living { #41-no-rest-for-the-living }




2010.




Nerve Software.




Основные mapper:
\- Russell Meakim / TheCastle;
\- Richard Heath / Arya Iwakura.




8 основных карт + 1 secret.




### 41.1. Философия { #411 }




Никаких новых:
\- enemies;
\- guns;
\- mechanics.




Только:
**DOOM II toolkit + 16 лет развития mapping culture.**




Это почти демонстрация идеи:




> DOOM II не нуждалась в новых системах; ей нужны были более зрелые карты.




### 41.2. Secrets { #412-secrets }




Одна из сильнейших сторон.




Secret часто:
\- большой optional route;
\- дополнительный encounter;
\- важное оружие;
\- armor/resources.




Это не closet с четырьмя health bonus.




Secrets \= optional gameplay.




### 41.3. Resource economy { #413-resource-economy }




Backpack почти отсутствует.




Это удерживает ammo pressure и не позволяет накопить огромный стратегический запас.




Doom снова становится игрой про локальные ресурсы конкретной карты.




### 41.4. Ключевые карты { #414 }




- The Earth Base;

- Canyon of the Dead;

- Hell Mountain;

- March of the Demons;

- Baron's Banquet;

- Tomb of Malevolence.





#### The Earth Base { #the-earth-base }




Уже первая карта показывает философию:
можно быстро уйти, но exploration даёт SSG, armor, ресурсы и дополнительные fights.




#### Canyon of the Dead { #canyon-of-the-dead }




Хороший пример того, насколько зрелее к 2010 году стал environmental mapping на том же engine.




#### March of the Demons { #march-of-the-demons }




Secret map как escalating combat lab.
Spider Mastermind работает лучше именно как часть encounter, а не отдельный boss.




#### Tomb of Malevolence { #tomb-of-malevolence }




Финальный Cyberdemon-level:
обычный DOOM combat вместо Icon-of-Sin gimmick.




### 41.5. Difficulty { #415-difficulty }




Проект ориентировался на опытную аудиторию.




UV — полноценная серьёзная classic Doom difficulty, но не постоянная Plutonia-style ненависть и не modern slaughter.




### 41.6. Cacoward { #416-cacoward }




Особенно символично:
официальный Doom add-on оценивается community как WAD и получает Cacoward.




Цикл замыкается:




```
official Doom
↓
создаёт community

community
↓
развивает Doom

official add-on
↓
должен пройти экзамен community
```




### 41.7. Итог { #417 }




По среднему quality карты No Rest вполне может быть лучше оригинальной DOOM II campaign.




Сильные стороны:
\- компактность;
\- mature enemy placement;
\- хорошие secrets;
\- полный Doom II toolkit;
\- почти нет слабого filler.




Недостаток:
меньше собственной world identity, чем у DOOM 64.

2024.




id Software + Nightdive + MachineGames + Doom-community.

Заменяет BFG.




Charge weapon.

BFG глубже как mastery weapon.
Calamity Blade визуально и механически проще читать, но отлично соответствует scale поздних encounters Legacy of Rust.




### 45.4. Fuel { #454-fuel }




Общий ресурс нового high-tier arsenal.

\- тратить на постепенный Incinerator damage;

## 52\. DOOM RPG { #52-doom-rpg }




2005.




Fountainhead Entertainment + id.




John Carmack:
\- producer;
\- programmer.




Katherine Anna Kang:
\- producer / ключевой человек Fountainhead.




### 52.1. Происхождение идеи { #521 }




Carmack увидел плохие Java-games на новом телефоне и начал разбираться, почему они плохие.




Главное наблюдение:




> телефонная цифровая клавиатура плохо подходит realtime FPS.




Вместо плохого FPS:




## меняем жанр. { #_11 }




Формула Carmack:




> **Bard's Tale meets Doom.**




### 52.2. Gameplay { #522-gameplay }




First-person grid-based turn-based dungeon crawler.




Каждый:
\- шаг;
\- shot;
\- item use;




тратит turn.




Время не идёт, пока игрок думает.




Это полностью меняет фундамент:




```
classic Doom:
real-time spatial mastery

DOOM RPG:
turn economy + weapon/resource choice
```




### 52.3. Weapon weaknesses { #523-weapon-weaknesses }




Enemy type влияет на оптимальное оружие.




Возникает:
\- enemy recognition;
\- правильный weapon choice;
\- ammo economy.




### 52.4. Необычные предметы { #524 }

## 61\. Unity launch problems { #61-unity-launch-problems }




Стартовая версия имела:
\- Bethesda.net login requirement;
\- неправильный aspect/scaling;
\- lighting differences;
\- audio/music issues;
\- 35 FPS presentation на 60 Hz;
\- неприятный judder.




### 61.1. 35 FPS / 60 Hz { #611-35-fps-60-hz }




Оригинальная Doom logic:
**35 tics/sec**.




На старом \~70 Hz output:




```
70 / 35
=
ровно 2 refresh на game frame
```




На 60 Hz:




```
60 / 35
=
нецелое число
```




Получается uneven frame persistence → judder.




Правильное решение:
оставить simulation 35 Hz, а renderer интерполировать до modern refresh.




Позднее Unity-port именно к этому приходит.




### 61.2. Bethesda.net scandal { #612-bethesdanet-scandal }




Запуск DOOM 1993 внезапно требовал account login.




После негативной реакции Bethesda быстро переводит его в optional.




Символически особенно нелепо для игры с открытым с 1997 года source.




### 61.3. Aspect / scaling { #613-aspect-scaling }




Стартовая presentation не давала ни корректного исторического 4:3, ни хорошего современного widescreen.




Это было одной из самых заметных проблем launch build.




### 61.4. Lighting/audio { #614-lightingaudio }




Часть lighting была слишком яркой/неточной.




Музыка и звуки тоже имели speed/quality differences.




Для Doom это важно:
lighting и sound — часть level readability/atmosphere, а не просто косметика.

## 79\. Главные дизайнерские принципы всей classic DOOM { #79-classic-doom }

### 79.3. Enemy role важнее сложного AI { #793-enemy-role-ai }




Doom monsters просты по отдельности.

### 79.4. Лучший enemy — threat и system component одновременно { #794-enemy-threat-system-component }

### 79.6. Mastery принадлежит игроку { #796-mastery }

```
↓

↓
```

### 79.8. Больше контента ≠ лучше { #798 }




DOOM II, TNT, Alien Vendetta, Legacy of Rust местами показывают:

```
+
тот же shotgun
+
другой light/audio direction
=

```
